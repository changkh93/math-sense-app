# 다크매터 정제소 설계 메모

> 실무 콘텐츠 구축 절차는 `docs/DARK_MATTER_REFINERY_CONTENT_MANUAL.md`를 우선한다. 이 문서는 초기 설계 방향을 남긴 메모다.

## 방향

기존 다크매터는 유지한다. 학생들이 해설과 힌트를 통해 풀이 방법을 익히는 학습장 역할을 계속 담당한다.

새로운 다크매터 정제소는 별도 흐름으로 둔다. 정제소는 이미 익힌 풀이 방법을 바탕으로 변형 조건을 해석하고, 힌트 없이 다시 증명하는 회복 미션이다.

## 역할 분리

### 다크매터 영역
- 목적: 풀이 방법 학습
- 허용: 힌트, AI 설명, 자세한 해설
- 효과: 모르는 문제를 이해하는 진입점

### 다크매터 정제소
- 목적: 이해 증명과 정화
- 제한: 정답/해설 직접 노출 없음
- 출제: 반복 오답과 재검토 문항을 우선순위로 정렬
- 정화: 힌트 없이 맞힌 문항만 오답 목록에서 해소

## 변형문항 운영 원칙

이미지는 그대로 사용할 수 있다. 다만 정제소 문항은 항상 다음 안내를 붙인다.

> 아래 이미지는 참고용입니다. 이미지 안의 숫자나 표시와 다를 수 있으니, 반드시 문제 글에 제시된 조건과 숫자를 기준으로 풀어주세요.

이 방식이면 이미지 안에 숫자가 박힌 기하 문항도 일단 변형 출제가 가능하다. 운영 중 어색한 문항은 관리자 도구에서 정제소용 이미지를 별도로 지정해 점진적으로 개선한다.

## 데이터 필드

기존 `quizzes` 문서에 선택 필드를 추가한다.

- `refineryPrompt`: 정제소에서 사용할 변형 조건 문장
- `refineryImageUrl`: 정제소에서 사용할 참고 이미지 URL
- `variantPrompt`: 기존 변형 필드가 있다면 호환용으로 사용
- `variantImageUrl`: 기존 변형 이미지 필드가 있다면 호환용으로 사용

정제소 출제 우선순위는 사용자별 `incorrect_questions`와 `review_marks`를 합쳐 산정한다.

- `failCount`가 높을수록 우선
- 최근 오답일수록 우선
- 재검토 마크가 있으면 우선

## 구현 상태

- 학생 대시보드에 기존 다크매터와 별도 정제소 진입점을 분리했다.
- 정제소 전용 화면은 반복 오류 우선순위와 오늘의 정화 작전을 보여준다.
- 정제소 문제는 원본 이미지 또는 `refineryImageUrl`을 사용하고, 텍스트 조건 우선 안내를 자동으로 붙인다.
- 관리자 다크매터 탭에서 문항별 `refineryImageUrl`을 저장할 수 있다.
