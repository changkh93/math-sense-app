# 🌌 감각 우주(Math Sense Universe) 보상 시스템 개선안

2,000개가 넘는 방대한 퀴즈 데이터를 기반으로, **'단순 반복'을 방지하고 '신중한 풀이'를 유도**하기 위한 새로운 자원 관리 및 보상 시스템입니다.

---

## 1. 💎 광석 획득 로직: '자원 관리 시스템'

무분별한 클릭을 방지하기 위해 틀렸을 때의 **리스크(Risk)**를 강화하며, **성적 경신(Improvement)** 시에만 보상을 지급하여 무한 반복 학습을 통한 광석 수집(Abuse)을 제한합니다.

| 구분 | 보상 (Ore) | 우주 탐사 컨셉 설명 | 비고 |
| :--- | :--- | :--- | :--- |
| **정답 (+)** | **문제당 +2** | 행성에서 성공적으로 자원을 채굴함 | **최고 점수 경신 시**에만 누적 지급 |
| **오답 (-)** | **문제당 -2** | 궤도 수정으로 인한 **에너지 손실** 발생 | 광석이 0개 미만으로 내려가지는 않음 |
| **연속 정답** | **3연속 정답 시 +5** | 안정적인 비행 궤도 진입으로 보너스 획득 | 콤보 보너스 |
| **백점 (100점)** | **+10 보너스** | 행성 탐사 완벽 성공 (Planet Clear) | **단원별 최초 1회만** 지급 |
| **오답 복구** | **문제당 +2** | 혜성에서 유실된 광석을 다시 수거함 | **오답 복구 행성** 전용 |
| **답변 채택** | **+20 (답변자)** | 다른 대원의 탐사를 도와 연구 성과 공유 | 아고라(명예의 전당) 순위 반영 |
| **해결 기여** | **+5 (질문자)** | 탐사를 성공적으로 마무리한 보상 | 질문 해결 시 지급 |
| **선생님 인증** | **+10 (추가)** | 우수 답변으로 선생님께 인정받음 | 인증 마크 획득 |
| **스스로 해결** | **+3 (질문자)** | 자기 주도적 문제 해결 역량 증명 | 자가 해결 보너스 |

> [!IMPORTANT]
> **성적 경신 기반 보상 (Anti-Grinding)**: 동일한 단원을 반복해서 풀더라도, 기존의 최고 점수(Best Score)보다 높은 점수를 얻었을 때만 추가적인 광석이 지급됩니다. 점수가 같거나 낮을 경우 광석 보상은 0개입니다.

---

## 2. � 보상 오남용 및 보안 장치 (Reward Security)

부당한 보상 획득을 방지하고 시스템의 안정성을 유지하기 위한 기술적 장치입니다.

*   **제출 잠금 (Submission Lock)**: 보상 받기 또는 결과 제출 버튼을 클릭하는 즉시 시스템이 '제출 중' 상태로 전환되며 추가 클릭을 차단합니다. (이중 클릭으로 인한 다중 보상 수령 방지)
*   **즉시 궤도 이탈 (Immediate Dismissal)**: 3D 모드에서 보상을 수령하는 즉시 퀴즈 인터페이스를 파기하여, 보상 모달 뒤에서 배경 UI를 재조작하는 행위를 물리적으로 차단합니다.
*   **시스템 복구 대기 시간 (System Reboot)**: 틀렸을 경우 약 **3초간** 조작이 차단되어 '찍기' 식의 무분별한 클릭 속도를 제어합니다.

---

## 3. 🛡️ '신중한 탐사'를 위한 게임 플레이 요소

선생님의 피드백을 반영하여 게임 플레이 도중에도 학습 태도를 유도하는 장치를 활용합니다.

*   **광자 실드 (Photon Shield) 활용**: 보유 장비 중 '광자 실드'를 소모하여 오답 시의 광석 차감을 방어할 수 있습니다. 장비 획득이 단순한 장식이 아닌 전략적 요소가 됩니다.

---

## 3. 🚀 보상 확장: '커스터마이징 스토어'

수집한 광석을 가치 있게 소비할 수 있는 요소를 추가합니다.

*   **우주선 스킨**: 무지개 엔진 불꽃, 투명 선체 등 (수집욕 자극)
*   **행성 테마**: 퀴즈 배경을 '용암 행성', '얼음 행성' 등으로 변경

---

## 🏅 배지 시스템 (Badges): '태도 중심의 명예'

단순 참여를 넘어 진지한 학습 태도를 보인 대원에게 수여하는 훈장 시스템입니다.

### 📍 기존 배지 기준 강화
| 배지 이름 | 획득 조건 | 탐사 의미 |
| :--- | :--- | :--- |
| **코스모스 입문** | 첫 퀴즈 세트(20문제) 완료 | 탐사의 시작 |
| **광석 수집가** | 보유 광석 **500개** 달성 | 중급 대원 (약 35세트 완료 시점) |
| **은하 학자** | 평균 정답률 **95% 이상** 유지 | 엘리트 대원 (높은 정밀도) |
| **우주 비행사** | 총 퀴즈 완료 **30세트 이상** | 숙련된 비행사 (전체 25% 공정) |
| **행성 개척자** | 총 퀴즈 완료 **70세트 이상** | 위대한 탐험가 (전체 50% 공정) |
| **태양계 마스터** | **132개 모든 세트** 완료 & **평균 100%** | 최종 단계인 전설의 마스터 |

### 🌟 신규 배지 (학습 태도 중심)
*   **무결점 궤도**: 연속 10세트 동안 정답률 90% 이상 유지
*   **슈퍼노바(초신성)**: 하루에 5세트 이상 완수 (폭발적 에너지)
*   **심우주 항해사**: 누적 퀴즈 100세트 돌파
*   **수학의 수호자**: 광자 실드 등으로 광석 차감을 200개 이상 방어
*   **완벽한 도약**: 백점 보너스(+10)를 20회 달성 (신중함의 증표)
