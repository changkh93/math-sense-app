# 크루 모함·궤도기지 시스템

## 제품 원칙

- 개인 탐사선은 학생 한 명의 아바타, 크루 모함은 함께 쌓은 성취의 아바타다.
- 모함의 기본 크기는 정식 멤버 수로 결정한다. 광석만 많은 소수 크루가 거대 기지를 바로 살 수는 없다.
- 시설은 `성취 해금 + 공동 광석 건설`의 두 단계를 모두 거친다.
- 개인별 기부 순위는 만들지 않되, 현재 프로젝트에서 누가 얼마를 지원했는지는 모든 정식 멤버가 확인할 수 있다.
- 구입한 시설은 크루 상세, 상단 NAV, 3D 행성 지도의 하단 원경을 항해하는 같은 SVG 모함에 즉시 반영한다.

## 모함 레벨

| 레벨 | 정식 멤버 | 외형 |
|---|---:|---|
| 1 | 1명 | 크루 탐사정 |
| 2 | 10명 | 궤도 탐사선, 양측 모듈 베이 |
| 3 | 20명 | 성간 연구모함, 다중 격납고 |
| 4 | 40명 | 궤도 연구기지, 외곽 링 |
| 5 | 80명 | 은하 수도함, 워프 구조물 |

멤버 수는 시설을 연출할 수 있는 선체 조건일 뿐이다. 실제 시설은 아래 공동 건설을 완료해야 나타난다.

## 출시 시설

| 시설 | 광석 | 기본 조건 | 추가 성취 |
|---|---:|---:|---|
| 시안 도킹 라이트 | 150 | Lv.1 | 없음 |
| 황금 광석 저장고 | 300 | Lv.1 | 없음 |
| 아고라 통신 배열 | 450 | Lv.2 | 없음 |
| 다크 매터 연구소 | 700 | Lv.2 | 팀 미션 5회 |
| 황금 항해 기록소 | 900 | Lv.3 | 크루 광석 상자 3회 |
| 아틀라스 궤도 링 | 1,500 | Lv.4 | 팀 미션 15회 |
| 공동 워프 게이트 | 3,000 | Lv.5 | 팀 미션 30회 |

## 건설 흐름

1. 리더가 해금된 시설 하나를 다음 공동 목표로 선택한다.
2. 정식 멤버는 5·10·20·50광석 중 하나를 지원한다. 개인 일일 한도는 100광석이다.
3. 서버 트랜잭션이 멤버 자격, 보유 광석, 일일 한도, 프로젝트 잔량을 동시에 검증한다.
4. 마지막 지원은 선택 금액보다 잔량이 작으면 잔량만 차감한다.
5. 목표액에 도달하면 시설을 소유·장착하고 전 멤버에게 완성 알림을 보낸다.

요청마다 사용자별 작업 ID를 저장해 재전송·더블클릭에도 한 번만 차감한다. 지원 취소와 환불은 제공하지 않는다.

## 성취 연동

- 크루 오늘의 팀 미션 완성: `missionsCompleted +1`, 모함 XP `+20`
- 크루 광석 상자 완성: `chestCycles` 갱신, 모함 XP `+20`
- 시설 공동 건설 완성: `completedProjects +1`, 모함 XP `+50`

모함 XP는 현재 상태를 설명하고 다음 업데이트의 시즌 보상 기반으로 사용할 수 있지만, 현 버전의 선체 레벨을 직접 올리지는 않는다.

## Firestore 핵심 필드

```text
crews/{crewId}
  mothershipXP
  mothershipStats
  currentMothershipProject
  ownedMothershipModules[]
  equippedMothershipModules{slot:itemId}
  mothershipOperations/{uid_operationId}

users/{uid}
  crystals
  crewMothershipContributionDate
  crewMothershipContributionAmount
  crystal_transactions/{transactionId}
```

광석 차감과 모함 필드는 callable function만 변경한다. 클라이언트는 크루 문서를 실시간 구독해 상세 페이지와 NAV에 같은 상태를 표시한다.
