# 메타센스 숏폼 개선판: 부모님 리모컨 고장

## 1. 개선된 30초 영상 스크립트

길이: 33초  
비율: 9:16 세로형  
컨셉: 부모가 리모컨으로 아이 공부를 조종하려다 실패하고, "냅둬유" 반전 뒤 메타센스가 스스로 학습을 작동시키는 밈형 광고

0-4초: 부모가 진지하게 리모컨을 든다.  
자막: "아이 공부시키는 비밀병기?"  
리모컨 버튼: 공부 시작, 집중, 오답 확인, 문제 하나 더, 핸드폰 끄기, 시험 잘 보기  
부모: "자, 공부 시작 버튼!"  
효과음: 큰 삑!

4-10초: 부모가 리모컨을 연타한다. 아이 표정은 점점 굳는다.  
부모: "집중!" "오답 다시 봐!" "한 문제 더!"  
자막: "학습 의욕 -10" "집중력 오류" "잔소리 감지" "강제 종료 위기"  
아이: "아... 더 하기 싫어졌어."

10-14초: 화면이 멈추고 소리가 끊긴다.  
큰 자막: "냅둬유."  
자막: "아이 공부는 리모컨으로 안 됩니다."  
자막: "냅둬유, 스스로 알아서 하게."  
내레이션: "진짜 공부는 조종이 아니라, 스스로 움직일 때 시작됩니다."

14-22초: 메타센스 화면 등장. 아이가 힌트, 오답 피드백, 다시 도전을 스스로 누른다.  
자막: "그래서, 메타센스."  
아이: "어? 왜 틀렸지?" "힌트 한번 볼까?" "아하, 이거였네." "한 문제만 더."  
자막: "정답만 알려주는 공부 말고, 생각하게 만드는 공부"

22-28초: 부모가 리모컨을 내려놓고 놀란다.  
부모: "어? 내가 안 눌렀는데?"  
아이: "쉿. 지금 내가 하는 중이야."  
자막: "시키지 않았는데" "다시 보고" "생각하고" "도전한다"

28-33초: 부모가 조용히 물러난다.  
부모: "그럼... 진짜 냅둬유?"  
아이: "응. 메타센스 켜놔유."  
자막: "냅둬유." "스스로 알아서 하게."  
엔딩: "조종하지 말고, 작동하게." "메타센스" "msense.me"  
마지막 스위치: "공부 잔소리 OFF" "생각 스위치 ON"

## 5. 효과음 지시

- 10초: 테이프 스톱처럼 소리 급정지

- 22-28초: 부모 충격 컷에 코믹 팝업음

## 9. FFmpeg 렌더링 명령어

Remotion 원본 렌더:

```bash
npm run video:render:remote
```

SNS 업로드용 최종 압축:

```bash
ffmpeg -y -i out/metasense-remote-promo-raw.mp4 -vf "scale=1080:1920:flags=lanczos,fps=30" -c:v libx264 -profile:v high -level 4.1 -pix_fmt yuv420p -crf 17 -preset medium -movflags +faststart -c:a aac -b:a 192k out/metasense-remote-promo-final.mp4
```

썸네일 추출:

```bash
ffmpeg -y -ss 00:00:11 -i out/metasense-remote-promo-final.mp4 -frames:v 1 out/metasense-remote-thumbnail-final.png
```
