# 법정 공휴일 (및 휴일) 관리 가이드

이 문서는 수학감각 스페이스(Math Sense App) 시스템에서 **학생들의 연속 학습일(Streak) 유지 및 휴일 보너스(광석 1.5배)**를 위한 휴일 데이터를 관리하는 방법을 안내합니다.

## 개요
시스템은 기본적으로 **토요일과 일요일**을 휴일(Rest Day)로 자동 인식합니다.
하지만 법정 공휴일(설날, 추석, 한글날 등), 대체 공휴일, 혹은 원장님 재량 휴원일 등은 자동으로 알 수 없으므로, 소스 코드 내에 날짜를 직접 기입하여 관리합니다.

## 휴일 목록 수정 방법

휴일 목록은 아래 파일에 위치해 있습니다.
👉 **파일 위치**: `src/utils/holidayUtils.js`

1. 에디터(또는 GitHub)에서 위 파일을 엽니다.
2. 파일 윗부분에 있는 `KOREAN_HOLIDAYS` 배열을 찾습니다.
3. 새로운 휴일을 추가하거나 삭제할 때, **반드시 `YYYY-MM-DD` 형식**(예: `2027-10-09`)으로 작성해야 합니다.

### 작성 예시
```javascript
const KOREAN_HOLIDAYS = new Set([
  // ... 기존 휴일들 ...
  '2028-01-01', // 신정 추가
  '2028-10-04', // 학원 가을 휴가 (이처럼 법정 공휴일이 아니더라도 학원 재량 휴가를 추가할 수 있습니다)
]);
```

## 업데이트 주기
*   연말(예: 11월 ~ 12월)에 다음 연도의 주요 공휴일 달력을 보고 한 번만 업데이트해 두시면 1년 내내 별도 조작 없이 자동으로 적용됩니다.
*   학원 방학이나 갑작스러운 임시 공휴일이 생길 경우, 해당 날짜를 추가하고 새 버전을 배포(Deploy)하면 즉시 적용됩니다.

## 기능 효과
이 파일에 등록된 날짜와 주말(토/일)에는 다음 두 가지 효과가 발생합니다:
1. **연속일(Streak) 보호**: 학생이 해당 날짜에 학습하지 않고 건너뛰더라도, 크라이오 코어(Freeze) 아이템이 차감되지 않으며 연속일이 초기화(0)되지 않습니다.
2. **보상 증폭**: 학생이 해당 날짜에 퀴즈를 풀거나 영상 학습 데이터 로그를 남기면 획득하는 광석 보상량이 **1.5배**로 증폭되어 지급됩니다. (소수점 발생 시 올림 처리)
