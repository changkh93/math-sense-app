# Astra Frontier — 가벼운 크루 항로

## 적용한 흐름

`항로 메뉴 / 바다·하늘 게이트 → 크루 성도에서 목적지 선택 → 출항 확인 → 서버 방문 허가 → 목적지 착륙 → 시설 돕기 / 귀환 기록`

- 기존 `neighbors` 화면을 크루 성도로 교체했다. 선택은 로컬 상태만 바꾸며, 출항 버튼을 눌러야 기존 `openGalaxyHome`을 한 번 호출한다.
- 동쪽 바다 `(worldRadius + 9, -2, 0)`, 북쪽 하늘 `(0, 10, -worldRadius - 6)`에 단순 메시 게이트를 배치했다. 기존 3D 근접 판정 및 E/터치 상호작용을 재사용한다. 지도의 항로 표시는 섬 바깥 방향을 나타내며 실제 거리를 축척으로 표시하지는 않는다.
- 장비나 입장권 없이도 항로 메뉴에서 같은 목적지를 선택할 수 있다. 기존 호버팩/잠수복 구매 가격은 바꾸지 않는다.
- 출항 중 기존 장면을 멈추고 연결 화면을 표시한다. 성공한 경우에만 목적지를 교체하고 월드 컴포넌트를 초기화해 기존 착륙 지점에서 시작한다. 실패·취소 시 이전 장면을 유지한다. 동일 프레임 중복 입력, 계정/세션 변경, 언마운트 후 늦은 응답을 무시한다.
- 취소는 클라이언트 화면 전환을 취소하는 기능이다. 이미 실행 중인 서버 호출 자체를 취소하거나 서버의 기존 방문/스토리 기록을 되돌리지 않는다. 자동 재시도하지 않는다.
- 도착하면 실제 배치된 온실·별꽃 정원·관측소·비콘·신호 광장에서 할 수 있는 도움을 안내하고 기존 시설 정보 창에 연결한다. 도움 실행, 한도, 보상, 친구에게 남는 기록은 기존 서버 동작 그대로다. 자신의 귀환 기록과 무료 귀환 버튼도 제공한다.
- 기존 릴레이 파트너 선택과 45초 탐사의 공동 기록 흐름을 유지했다. 동시 접속 강제 대신 친구가 나중에 확인할 수 있는 비동기 협업을 우선한다.
- 게스트 항로는 계속 로컬 훈련 시뮬레이션이며 실제 학생 방문으로 표현하지 않도록 출항 버튼을 ‘훈련 항로 연습하기’로 구분했다.

## 의도적으로 추가하지 않은 것

- **비크루 공개 탐색/관전자 권한**: 현재 서버는 같은 승인 크루와 양방향 차단 여부를 확인하고, 비공개 행성 방문을 거절한다. 학생 전체 목록을 공개하거나 새로운 관전자 권한을 도입하지 않았다.
- **패스·비자 화폐**: 기존 탐험가 패스포트와 혼동되는 두 번째 화폐/입장권 원장, 학습 보상 트리거를 만들지 않았다.
- **다중 월드 로딩/스트리밍**: 다른 행성은 HTML 목적지 표시만 사용한다. 실제 3D 월드는 한 곳뿐이며 게이트는 목적지 데이터를 미리 가져오지 않는다.
- **실시간 동시 버튼 퍼즐/공동 편집**: 새로운 서버 방, 잠금, 동기화 루프 없이 기존 시설 도움과 릴레이를 연결했다. 친구 건물 편집 권한은 추가하지 않았다.

## 비용 및 운영

- 신규 패키지, 외부 유료 API, 이미지 생성, 저장소 컬렉션, 실시간 구독, 예약 작업, 서버 함수 없음.
- 성도 선택/게이트 접근/게이트 열기에는 기능 자체의 추가 요청 없음. 출항 확정 시에만 기존 방문 호출이 발생한다. 기존 방문 호출에는 학습 상태·행성·이웃 등의 읽기/쓰기가 포함되므로 무료 서버 작업이라는 뜻은 아니다.
- 기존 30초 플레이 체크포인트, 위치 델타 전송, 정지 시 하트비트, 룸 만료 정책을 유지한다. 게이트는 2개, 정적 메시 6개이며 별도 프레임 루프나 동적 조명을 추가하지 않는다.
- 실제 청구액과 학생별 장기 사용량은 측정하지 않았다. 절감률이나 협업 학습 효과를 단정하지 않는다.
- 변경은 웹 클라이언트 중심이며 기존 서버/규칙과 호환된다. 운영 배포는 하지 않았다.

## 검증

- `npm run test:frontier-crew`: 접근 가능 목적지/게이트 범위/시설 선택, 실제 React StrictMode에서 중복·취소·실패·세션 변경·언마운트·새 요청과 오래된 응답의 경쟁, 목적지 선택과 출항 구분, 차단/신고 및 시설 정보 연결. 서버 통신은 합성 테스트 응답이다.
- 기존 비용, 탐험, 내비게이션, 서버 근접 대화 및 월드 객체 테스트 통과.
- Chrome 로컬 `/dev/frontier-crew`: 바다 게이트 클릭으로 성도 열림, 호버팩 고도 10.1에서 하늘 게이트 상호작용 표시, 합성 방문 완료와 도착 안내, 착륙 지점 초기화, 390px/1280px 화면 확인. `/dev/frontier-crew?guest=1`은 실제 MetaGalaxy 게스트 화면으로 항로 메뉴 통합을 확인한다.
- 실제 학생 두 계정의 운영 방문/보상 지급, 모바일 실기기, 청구 내역은 검증하지 않았다. 기존 서버 권한 검증 코드는 수정하지 않았다.
- QA 경로는 개발 빌드에만 등록된다. 배포 빌드에는 합성 사용자/QA 화면이 포함되지 않는다.
