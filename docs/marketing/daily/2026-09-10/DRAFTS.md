## 금요일 파이썬 영상 — W01-YT02 초안

제목: 숫자 하나를 바꾸면, 별은 몇 개가 될까요?
목표: 코드를 실행하기 전에 결과를 예상하고, 바꾼 부분과 결과를 설명하기.

```python
stars = 3
print("★" * stars)
```

예상 출력: ★★★. stars를5로 바꾸면 ★★★★★. 입력값은 양의 정수3과5만 다룬다.

0~4초: “이 숫자를3에서5로 바꾸면 무엇이 달라질까요?”
4~12초: 코드3줄 이내를 크게 보여주고3의 결과를 실행.
12~20초:3을5로 바꾸고 잠깐 멈춤. “먼저 예상해 보세요.”
20~28초: 실행 결과5개를 보여주며 “별을 반복하는 횟수가 바뀌었네요.”
28~35초: “이번에는4로 바꿔 설명해 볼까요?” 메타센스 · msense.me.

실제 학생 장면·서비스 내 시연이라고 주장하지 않는 독립 예시. 로컬 Python 결과만 검증하며 서비스 실행 화면 촬영·자막·음량·세로 표지·3플랫폼 발행은 별도 남음. 원본1개를 릴스·쇼츠·클립에 재사용한다.
