# 학습 노트 첫 세트 SNS 재활용 원고

상태: 원고 준비. 외부 게시 미실행. 기본10편 모두 홈페이지에 모으고 SNS에서는 한 번에 하나의 질문을 소개한다.

## 첫 순서: 사각형 코드

원본: https://msense.me/python/guides/first-turtle-drawing/
블로그 제목: 초등 파이썬 첫 그림, 숫자 하나를 바꾸면 어떻게 될까요?
본문 방향: 사각형 코드 → 80을40으로 바꿔 실행 전 예상 → 실행 결과 비교 → 원본에서 코드 보기. 부모 경험이나 실제 학생 반응을 지어내지 않음.

인스타 카드 4장: ①아이에게 코드를 외우게 하기 전에 ②앞으로80, 왼쪽90도를 네 번 ③80을40으로 바꾸면? ④답보다 먼저, 아이의 예상을 들어보세요.
캡션: “선의 길이만 바꾸면 모양도 바뀔까요? 처음에는 숫자 하나만 바꿔 보세요. 실행 전 예상하고, 화면에서 달라진 부분을 찾는 짧은 활동입니다. 코드와 실행 화면은 메타센스 파이썬 학습 노트에 담았습니다. 프로필의 파이썬 안내에서 확인할 수 있어요.”

쇼츠/릴스/클립 20초: 0~4초 사각형 결과 /4~8초 앞으로80·왼쪽90 코드 /8~13초 80을40으로 변경 /13~17초 작은 사각형 /17~20초 ‘어느 숫자가 무엇을 바꿨을까?’ 원본 링크.
실제 두 실행 화면 촬영 완료 전 영상 제작/발행 완료로 표시하지 않음.

카카오 소식: “파이썬 첫 코드는 사각형 하나로 시작해도 좋습니다. 아이와 숫자 하나를 바꾸기 전에 결과를 예상해 보세요. 코드와 실제 실행 화면을 학습 노트에서 볼 수 있습니다.” 링크: 원본.
