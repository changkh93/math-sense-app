## 촬영 직전 확인

9/15 촬영안의 80→40 비교를 유지한다. 같은 화면 배율에서 한 변의 길이 변화를 보여주고, ‘한 변의 길이가 절반’이라고 설명한다. 첫 장면 질문 하나 외의 새 홍보 실험은 추가하지 않는다. 실제 캡처에는 활동을 정확히 설명하며 가상의 학생 경험이나 성과를 넣지 않는다.

## 독자 질문 응답 초안

**“처음 배우는데 부모가 코드를 알아야 하나요?”**
“부모님이 먼저 코드를 공부해 정답을 알려주기보다, 바꾸기 전 예상과 실행 결과를 아이가 설명하도록 물어보세요. 짧은 안내를 읽거나 실행을 시작할 때 어느 정도 도움이 필요한지는 체험에서 함께 확인하면 좋겠습니다.”

**“질문하면 하루 안에 답해주시나요?”**
“1일 이내 연락은 체험 신청 뒤 첫 안내 기준입니다. 과제 피드백 전체의 응답 시간이나 실시간 수업을 뜻하지는 않습니다. 질문을 남길 위치와 피드백 확인 방법은 시작 안내에서 확인해 주세요.”
