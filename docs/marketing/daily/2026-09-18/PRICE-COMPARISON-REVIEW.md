## 요청과 결론
사용자: 네이버 스마트스토어에서 가격비교 서비스 등록 검토. 기존 광고 보류 유지. 이번에는 현황·조건·신청 경로를 검토했으며 신규 계약·유료 연동·카탈로그 매칭 신청은 실행하지 않았다.

네이버쇼핑 상품 연동, 네이버 가격비교 카탈로그 매칭, 에누리/다나와 외부 연동을 구분한다. ‘스토어관리 > 가격비교 서비스 연결’은 에누리·다나와 메뉴다. 해당 계정에서 두 서비스 모두 ‘연결 가능합니다 / 사용안함’ 확인. 이 표시는 개별 상품 심사·노출 승인 완료를 뜻하지 않는다.

## 외부 연동 비용과 신청 구조
- 현재 스마트스토어 화면: 각 경유 판매의 판매금액2%(VAT포함), 정산 시 차감. 네이버쇼핑 판매수수료 별도.
- 공식FAQ5315: Npay 수수료 외 가격비교 수수료2%; 판매자마케팅수수료도 추가 과금될 수 있음. 예시는0.91~1.87%(VAT별도). 해당 계정의 적용등급/실제 합계수수료는 별도 확인해야 함.
- 따라서 ‘총수수료2%’ 또는 ‘무료 노출’로 안내하지 않는다.
- 상품 판매금액만으로 계산한 추가2% 예시: 수세기12,000원→240원, 19,600원 도서→392원, 분수카드 포함세트32,600원→652원. 기존 수수료·배송비·원가·쿠폰 제외 계산이다.
- 공식FAQ3674: 국내 사업자, 스토어 계정 단위 신청. 입점 완료 후 상품별 노출채널의 가격비교 사이트 등록에서 에누리/다나와 선택. 다나와는 판매중/전시중 필요.
- 에누리 승인 후 스마트스토어 연동은3일 이내 안내. 실제 승인 소요기간으로 해석하지 않는다.
- 공식FAQ6151: 연동 해지는 각 업체에 별도 요청. 단순 체크 해제로 계약 해지까지 끝난다고 안내하지 않는다.

## 추천 실행안
1. 네이버: 수세기·덧뺄셈처럼 구성과 ISBN이 명확한 단권부터 도서 카탈로그 생성/매칭 가능 여부 확인. 네이버쇼핑 등록 자체를 중복 신청하지 않는다.
2. 분수세트·비와비례식세트: 세트/단권/카드 포함 여부와 서지정보가 정확히 일치하는 카탈로그에만 연결. 비와비례식 세트와 II단권에 동일ISBN9791195678297이 표시되어 있으므로 세트 매칭 전 서지·구성 확인 필요. ISBN만 같다고 자동으로 동일상품 취급하지 않는다.
3. 외부 가격비교: 종이책 소수 품목부터 2주 시험 운영 권장. 입점/취급 승인 후 수세기·덧뺄셈·분수세트를 우선 후보로 선정. 매체별 유입·주문·추가 수수료·남는 금액을 비교하고 확대한다. 도서 취급/개별 승인 여부는 현재 미확인.
4. PDF3종은 전자책 취급·전달 방식이 허용되는지 확인한 뒤 확대. 자체ISBN 없는 영상강의는 등록유형 정정 전 외부 연동 후보에서 보류.
5. 유입 확대와 네이버 순위진단0 해결은 별도 목표다. 외부 노출이 네이버 검색순위 상승을 보장하지 않는다.
