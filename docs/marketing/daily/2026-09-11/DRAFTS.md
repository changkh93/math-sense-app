# 9/11 질문 수집·후속 콘텐츠 초안

상태: 로컬 초안, 미발행. 실제 입문 과정 화면·지원 수준 확인 전 구체적인 수강 조건이나 첫 수업 성과를 단정하지 않는다.

## Instagram 스토리 질문

첫 화면: “게임은 좋아하는데, 코딩은 처음이에요.”
어제 게임 영상을 보며 이런 생각이 드셨나요?

질문 스티커: 아이의 코딩 첫걸음, 무엇이 가장 궁금하세요?
보조 문구: 시작 수준 / 혼자 하는 방법 / 막혔을 때 도움
안내: 수업 완성 예제와 처음 배우는 활동은 다릅니다. 궁금한 점을 남겨주세요.

기존 게임 릴스를 공유할 수 있으면 그 게시물과 연결. 같은 영상을 신규 릴스로 다시 올리지 않는다. 실제 스티커 기능·게시 미확인.

## 답변 초안 — 실제 질문이 있을 때만

“코딩이 처음인 아이는 어디서 시작하나요?”
처음부터 완성 게임을 만드는 것처럼 보였다면 시작 과정을 더 설명드려야겠네요. 아이가 전에 해 본 코딩 활동이 있는지, 학년은 어떻게 되는지 알려주세요. 현재 과정의 시작 활동과 준비 수준을 확인해 안내드리겠습니다.

“AI가 코드를 만들어 주는데, 배울 필요가 있나요?”
코드가 나오는 것과 그 코드가 왜 그렇게 움직이는지 아는 것은 다른 경험입니다. 숫자 하나를 바꾸기 전에 결과를 예상하고, 실행한 뒤 예상과 비교해 보는 질문부터 해 볼 수 있어요. 메타센스의 실제 활동에서도 어떤 장면으로 연결되는지 확인해 소개하겠습니다.

## 후속 짧은 시연 구성 — 촬영 전 기획

0~4초: ‘완성 게임을 만들기 전, 첫걸음은 어디일까요?’
4~14초: 실제 처음 파이썬 시작 활동 화면. 화면 확인 전 예제를 임의로 첫 수업이라고 붙이지 않음.
14~24초: 한 값 변경→결과 예상→실행 비교. 아이/학부모 개인정보 제거.
24~32초: ‘무엇을 바꿨고, 왜 결과가 달라졌을까?’
32~36초: ‘과정 안내 msense.me’ / 둘시네가 운영하는 메타센스.

실제 교재·첫 활동·게임 진입 조건 확인 후 문구 확정. 기존 별 그리기 초안은 일반 예시로 보존, 현재 입문 커리큘럼이라고 주장하지 않음.
