## 이번 주 후보 목록의 출발점

- 우선 추가 조사: k-12lab, 80milk, twoyumom_with. 최신 글, 교육 대상, 실제 공개 협업 창구, 협찬 표시 방식 확인 후 제안 여부 결정.
- 참고 계정: 나머지 교육 서비스·학원. 경쟁 계정을 곧바로 제휴 후보 실적으로 집계하지 않음.
- 이번 주 40계정·20제휴 후보 목표는 아직 달성하지 않음. 오늘 조사 10곳과 탐색 후보 3곳을 시작 기록으로 남김.
- 공통 기획 적용: 부모의 구체적인 질문으로 시작 → 학습 활동 하나 → 도움받는 과정 → 행동 요청 하나.
- 다음 제작에서 직접 시연할 주제: 첫 활동 찾기, 질문 남기기, 부모 학습 기록 확인. 공개 가능한 화면만 사용하며 학생 개인정보를 노출하지 않음.
