## 20초 영상 제작 큐

0~4초: 80 길이 사각형과 질문 →4~8초: 이동/회전/4회 코드 →8~13초: 80을40으로 변경 →13~17초: 실제 재실행 결과 비교 →17~20초: “어떤 숫자가 무엇을 바꿨을까?”와 학습노트 안내.
80코드 실제 실행 캡처는 기존 자산으로 확보. 40코드 새 실행 촬영과 완성 영상은 미완료. 기존 영상이나 캡처를 새 학생 과제로 표현하지 않는다.
