# SEO + AEO/GEO + SNS 운영 전략

적용: 2026-09-13 사용자 결정. 이전 100일 계획의 발행량·댓글 수 할당보다 이 문서의 품질·측정 기준을 우선한다. 기존 일지는 수정하여 성과를 소급하지 않는다.

## 목적과 경로

학부모의 실제 질문에 답하는 원본 콘텐츠를 msense.me/python/guides/에 축적한다. 검색·AI 답변·SNS에서 이 글을 발견 → 과정 안내 /python → 체험 신청 → 1일 이내 연락 → 첫 학습 → 정규 수강으로 연결한다. 파이썬 확정 조건: 초3부터, 자율 학습, 월15만 원, 기본7일 체험, 자동 결제 없음.

- SEO: 고유한 검색 의도, 정적 HTML, 관련 글과 내부 링크, 출처와 실질적 수정일.
- AEO/GEO: 질문에 바로 답하는 짧은 요약과 구체적 설명, 조건·예외, 동일 본문에서 생성하는 FAQ 데이터, 확인 가능한 실제 자료.
- SNS: 원본 한 편에서 질문 카드·짧은 실행 영상·대화용 요약을 만든다. 전체 문장을 그대로 복제하지 않고 채널 독자에게 필요한 한 장면을 보여준다.

## 기본 10편과 발행 원칙

기본 세트는 시작 학년, 스크래치 전환, 첫 그림, 게임과 개념, 오류 읽기, AI 시대 사고, 자율학습 피드백, 과제 제출, 학부모 기록, 체험 조건의 열 가지 의도를 분리한다. 같은 날 공개하는 수량 자체에 대한 금지 규칙은 확인되지 않았다. 중복·무가치한 대량 페이지가 문제이므로 게시일을 꾸며 분산하지 않는다. 이후 기본 목표는 신규 원본 주2편과 기존 글 주1편 실질 개선. 100편은 구조의 수용 목표이며 무조건 채워야 하는 발행 할당량이 아니다.

## 매일 할 일

1. 문의/댓글에서 새 질문을 확인하고 기존 글로 답할 수 있는지 판단한다. 답할 자료가 없다면 편집 후보에 기록한다.
2. 실제 계정에서 확인 가능한 검색 노출·클릭·유입 경로·신청을 기록한다. 데이터 미연결은 미확인으로 쓴다.
3. 요일별 핵심 작업 하나를 수행한다. 발행에는 제목/본문/코드/화면/개인정보/모바일/링크 검수를 포함한다.
4. SNS 확산과 공개 교류는 상대 질문에 도움이 되는 범위로 한다. 수량을 채우기 위한 댓글·링크 삽입을 하지 않는다.
5. 게시 URL, 수정 이유, 확인 증거, 다음 점검일을 일지에 남긴다.

## 측정

검색: 페이지별 노출·클릭·검색어·색인 상태(출처와 조회일). AI: 동일 질문과 날짜/서비스/응답 URL을 남겨 실제 인용된 경우만 기록. 개인화된 한 번의 답변을 전체 노출로 일반화하지 않는다. SNS: 조회·저장·프로필/링크 행동·문의. 최종: 체험 신청과 첫학습, 정규 전환.
현재 dataLayer 이벤트만 준비된 상태. GA/GTM 수집·수신 확인은 미완료이며 대시보드 연결 완료로 기록하지 않는다. llms.txt는 보조 목차일 뿐 필수 표준·인용 보장 수단으로 설명하지 않는다.

## 이미지와 학생 기록

실제 제품 캡처는 있는 그대로 설명하고 실제 학생 과제라고 부르지 않는다. AI 삽화와 실제 캡처를 구분한다. 학생 이름/닉네임 마스킹만으로 익명성이 보장된다고 보지 않는다. 동의 없이 검토하려면 원본이 아니라 식별 가능한 정보가 제거된 최종 공개물을 기준으로 판단한다. 개인정보 없는 교사 소유 자료·코드·실행 화면을 우선한다. 학생 창작물 이용권한은 익명성과 별도 확인한다. 실제 캡처에 ‘시연용 예시’라는 일괄 문구를 넣지 않는다. 내용을 재구성했다면 실제 기록처럼 표시하지 않는다.
