## 영상 한 편의 작업 순서와 완료 기준

1. 영상 ID를 정하고 학부모 질문 하나, 아이가 실제 해 볼 행동 하나를 고른다. AI 시대 기대·걱정은 구체적인 학습 장면에 연결한다.
2. 대본은 질문 → 시연 → 관찰 포인트 → 다음 행동으로 구성한다. 초기 제작 기준은 세로9:16, 25~50초이며 플랫폼의 최대 길이 규정이라는 뜻이 아니다.
3. 수학은 풀이·용어·그림 수량을 확인한다. 파이썬은 코드를 실제 실행하고 출력 결과를 대조한다. 예시를 실제 학생 사례처럼 소개하지 않는다.
4. 원본·대본·자막·표지·채널별 문구를 daily/YYYY-MM-DD/videos/영상ID/에 보관한다. 기존 브랜드 로고를 사용하고 작은 화면에서도 글자를 읽을 수 있는지 본다.
5. 저자 소개는 짧게 넣는다: ‘수학감각 시리즈 저자가 운영하는 메타센스’. 교재 페이지 사용 범위·이미지·음원의 사용 가능 여부를 확인한다. 사용자 목소리나 실제 촬영이 필요한 경우 구체적인 대본·촬영 분량을 먼저 준비하여 요청한다.
6. 업로드 시 제목·설명·자막·표지·해당 재생목록·실제 시청 대상에 맞는 아동용 설정을 확인한다. 수학/파이썬 재생목록은 첫 해당 영상과 함께 구성하고 공개 확인 후 완료로 바꾼다.
7. 공개 후 재생·잘림·오탈자·음량·안내 경로를 확인하고 URL·시각을 기록한다. 업로드 창 완료만으로 공개 검증을 대신하지 않는다.
8. 릴스는 워터마크 없는 공통 원본으로 발행하고 문구를 맞춘다. 블로그는 풀이·코드 설명과 영상을 연결하고, 카카오는 상담에 도움이 되는 영상만 요약 소식으로 선별한다. 같은 날 중복 소식을 자동으로 추가하지 않는다.
9. 다음 날과7일 후 성과를 확인한다. 제작 완료·공개 완료·다른 채널 재활용 완료를 각각 기록한다.
