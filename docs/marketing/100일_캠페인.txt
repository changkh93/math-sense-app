이번 100일은 **“콘텐츠를 꾸준히 올리는 기간”이 아니라, 새로운 학부모를 만날 경로를 만들고 매주 확대하는 캠페인**으로 운영하는 것을 제안합니다.

맞팔과 이웃 교류도 포함하겠습니다. 다만 핵심은 **무조건 숫자를 교환하는 활동이 아니라, 메타센스의 교육에 관심을 가질 사람에게 발견되고 계속 볼 이유를 주는 것**입니다. 여기에 공동 콘텐츠, 커뮤니티 제휴, 무료 자료, 설명회, 유료 광고를 결합합니다.

**기간은 2026년 9월 8일~12월 16일, 총 100일**로 잡았습니다. 아래 계획과 함께 실제로 체크하며 사용할 수 있는 실행표도 만들었습니다.

### [메타센스 100일 성장 실행표 다운로드](sandbox:/mnt/data/MetaSense_100day_Growth_Plan_20260908.xlsx)

실행표에는 **주차별 계획, 100일 일별 할 일, 블로그·영상 주제, 광고 예산, 실제 성과 기록, 제휴 관리, 연락 문구, 근거 자료**가 들어 있습니다. 현재 팔로워·이웃·친구 수는 확인되지 않았으므로, 실제 수치를 입력하도록 비워 두었습니다.

# 1. 목표와 투입량부터 정하겠습니다

## 100일의 임시 도전목표

현재 숫자를 기준으로 다음과 같은 **순증 목표**를 제안합니다.

| 채널         |               100일 순증 목표 | 함께 확인할 지표                 |
| ---------- | -----------------------: | ------------------------- |
| 인스타그램      |          **팔로워 +1,000명** | 프로필 방문, 자료 요청, 관심 과정 문의   |
| 네이버 공식 블로그 | **나를 이웃으로 추가한 독자 +300명** | 검색 유입, 실제 수업 안내 조회, 상담 연결 |
| 카카오톡 채널    |             **친구 +500명** | 첫 채팅, 자료 요청, 체험 시작, 차단 추이 |

이 숫자는 **검증된 예상 실적이 아니라, 운영량과 실험을 설계하기 위한 도전목표**입니다. 첫 2주 데이터로 조정해야 합니다. 반응이 좋으면 상향하고, 부족하면 단순히 게시물 수를 늘리기보다 유입 경로와 제안을 바꿉니다.

특히 블로그에서는 **내가 추가한 이웃 수가 아니라, 나를 추가한 독자 수**를 관리해야 합니다. 네이버의 사용자 분석에서도 이웃 추가 관련 변화를 확인할 수 있습니다. ([Naver Help][1])

세 채널 목표를 더한 1,800명을 고유 학부모 1,800명으로 계산해서는 안 됩니다. 같은 가정이 여러 채널을 이용할 수 있기 때문입니다.

시간이 부족해지면 가장 먼저 줄일 것은 새 채널 개설과 장식적인 디자인 작업입니다. 상담과 체험 지원을 줄이면서 홍보량만 늘리지는 않겠습니다.

# 2. 무엇이 검증되었고, 무엇을 실험해야 하는가

“검증된 방법”은 **플랫폼이 지원하는 기능**과 **메타센스에서도 성과가 입증된 방법**을 구분해야 합니다.

| 방법               | 확인된 근거                                     | 메타센스에서의 적용                         |
| ---------------- | ------------------------------------------ | ---------------------------------- |
| **인스타그램 공동 게시**  | 공동 작성자가 수락하면 각 계정의 프로필에 표시되고 각 독자에게 연결됩니다. | 개인 계정·교육 계정·학부모 콘텐츠 제작자와 공동 콘텐츠 제작 |
| **체험 릴스**        | 비팔로워에게 먼저 콘텐츠를 보여주며 반응을 시험하는 기능입니다.        | 계정에 제공된다면 새로운 첫 문장·영상 형식 시험        |
| **네이버 클립 → 블로그** | 클립에 자기 블로그 글을 콘텐츠 링크로 첨부할 수 있습니다.          | 영상에서 관심을 만든 뒤 자세한 글과 이웃 추가로 연결     |
| **네이버 파워컨텐츠**    | 구매 가능한 지정 키워드에 블로그·카페 콘텐츠를 광고하는 상품입니다.     | 좋은 수업 안내글·학부모 가이드의 검색 유입 확대        |
| **카카오 채널 확보 광고** | 카카오 광고에서 친구 확보 대상 채널을 선택하는 설정을 제공합니다.      | 자료 요청·과정 상담을 이유로 채널 추가 유도          |

각 기능은 공식 안내로 확인했습니다. 하지만 **기능이 존재한다는 사실이 팔로워 증가나 수강 등록을 보장하지는 않습니다.** ([About Facebook][2])

예를 들어 Meta는 체험 릴스 도입 전후의 창작자 데이터를 분석해 비팔로워 도달이 증가한 사례를 공개했습니다. 다만 이는 **Meta의 내부 관찰 분석이며, 한국 교육 브랜드를 대상으로 한 무작위 실험은 아닙니다.** 따라서 시험해 볼 근거는 되지만 메타센스의 성장률로 가져오지는 않겠습니다. ([About Facebook][3])

반대로 **“하루 댓글 30개면 상위 노출”, “서로이웃을 몇 명 만들면 검색 순위 상승”, “맞팔하면 알고리즘이 좋아진다”** 같은 주장은 이 계획의 근거로 사용하지 않습니다.

# 3. 매주 반복할 기본 활동: 게시 외 활동에 시간을 따로 배정합니다

## 주간 실행량

아래 수량은 **운영시간 배분을 위한 제안**이지, 플랫폼이 보장한 노출 공식이나 계정의 안전 한도가 아닙니다.

| 활동            |             주간 기준 | 실행 방식                               |
| ------------- | ----------------: | ----------------------------------- |
| 네이버 블로그       |            **2편** | 검색 질문에 답하는 글 1편 + 실제 수업·사례·이용 안내 1편 |
| 인스타그램 릴스      |            **3편** | 선생님 설명, 실제 학습 장면, 학부모 질문            |
| 인스타그램 카드형 게시물 |            **1편** | 블로그·영상 내용을 정리한 저장용 자료               |
| 인스타그램 스토리     |         **평일 중심** | 질문, 제작 과정, 자료 안내, 실제 수업의 작은 장면      |
| 네이버 클립·유튜브 쇼츠 |          **각 3편** | 릴스의 원본을 재사용하되 연결 안내는 채널에 맞게 변경      |
| 카카오 채널 소식     |            **1편** | 가장 도움이 되는 글·영상 하나를 짧게 소개            |
| 카카오 홍보 메시지    |  **격주 1회 이내로 시작** | 적법한 수신 대상에게 관련 있는 내용만 발송            |
| 관련 계정·블로그 읽기  |  **평일 하루 10개 정도** | 블로그 5개, 인스타그램 5개를 실제로 읽기            |
| 의미 있는 댓글      | **평일 하루 총 6개 이내** | 덧붙일 의견이 있을 때만 작성                    |
| 신규 제휴 제안      |          **주 5곳** | 협업을 받는다고 밝힌 창구에 맞춤 제안               |
| 성과 검토         |     **주 1회, 40분** | 순증·자료 요청·문의·체험·지출을 보고 다음 주 결정       |

### 제작은 ‘주제 하나를 여러 형식으로’ 진행합니다

예를 들어 **“나눗셈을 맞히지만 설명하지 못하는 아이”**를 중심 주제로 잡으면 다음처럼 만듭니다.

> 선생님의 짧은 설명 촬영 → 릴스 → 자세한 블로그 글 → 질문 카드 → 카카오 소식 → 클립에서 블로그 연결

모든 채널을 위해 새로운 원고를 따로 만들지 않습니다. 대신 **교류와 제휴는 별도의 시간으로 반드시 실행**합니다.

# 4. 맞팔·서로이웃·댓글은 이렇게 운영하십시오

## 4-1. 네이버: ‘관련 독자와의 교류’를 목적으로 서로이웃을 활용합니다

**서로이웃 자체를 피할 필요는 없습니다.** 다만 서로의 글을 볼 이유가 있는 사람에게 신청해야 합니다.

첫 주에는 다음 기준으로 **블로그 20곳**을 선정하십시오.

| 선정할 대상          | 선정 기준                 |
| --------------- | --------------------- |
| 초등 학부모의 교육 기록   | 실제 학습 고민과 경험이 있는가     |
| 엄마표 수학·독서 운영자   | 메타센스의 주제와 연결되는가       |
| 홈스쿨·자기주도학습 블로그  | 질문·설명·학습 과정에 관심이 있는가  |
| 교육자·작은 독서모임 운영자 | 이후 공동 콘텐츠를 만들 여지가 있는가 |

방문할 때는 최신 글만 훑지 말고, 관련 글을 읽고 구체적인 의견을 남깁니다. 교류할 이유가 생겼다면 이웃 신청을 합니다.

**이웃 신청 문구 예시**

> 안녕하세요. 초등수학과 파이썬을 가르치는 메타센스 운영자입니다.
> 올려주신 「○○」에서 아이가 스스로 설명하도록 기다려주신 부분이 인상 깊었습니다. 관련 이야기를 계속 읽고 싶어 이웃으로 신청드립니다.

**“소통해요, 맞공감해요, 방문 와주세요”를 반복해서 붙이는 방식은 사용하지 않겠습니다.** 네이버도 스팸성·반복적인 홍보 등 검색 품질을 해치는 게시물에 대한 제한 기준을 안내하고 있습니다. ([Naver Help][4])

그리고 공식 글 마지막에는 독자가 이웃을 추가할 이유를 구체적으로 넣습니다.

> 다음 글에서는 분수의 크기를 아이의 말로 확인하는 질문을 소개합니다. 이어서 읽으실 분은 메타센스를 이웃으로 추가해 주세요.

단순한 “이웃 추가 부탁드립니다”보다 **다음에 받을 콘텐츠가 무엇인지 알려주는 문구**를 시험하는 것입니다.

## 4-2. 인스타그램: 맞팔보다 ‘관심 계정 교류 → 공동 콘텐츠’를 우선합니다

인스타그램에서도 교육 관심이 맞는 계정을 먼저 팔로우해도 됩니다. 그러나 **선팔 후 언팔을 반복하거나, 상대에게 맞팔을 요구하는 전략은 제외**하겠습니다.

처음에는 공개 교육 계정 20곳을 선정하고, 다음처럼 접근합니다.

**관련 게시물을 실제로 읽기 → 도움이 되는 의견 남기기 → 반복적으로 교류하기 → 서로에게 유용한 공동 콘텐츠 제안하기**

예를 들어 독서 계정과는 **“책을 읽은 뒤 질문을 만드는 방법”**, 엄마표 학습 계정과는 **“답을 알려주기 전에 물어볼 질문”**을 함께 만들 수 있습니다.

Instagram은 인위적인 팔로워·좋아요 수집, 반복 댓글, 동의 없는 반복적인 영리 목적 접촉을 지양하도록 안내합니다. 따라서 무작위 대량 댓글·영업 메시지·맞팔방은 사용하지 않습니다. ([Facebook][5])

**교류가 성장의 출발점이고, 공동 콘텐츠가 그 관계를 더 많은 독자에게 연결하는 단계**가 되도록 설계하십시오.

# 5. 큰 유입을 만들 활동: 자료·제휴·설명회

## 5-1. 팔로우할 이유가 되는 대표 자료를 만듭니다

무료 자료를 많이 만들기보다, 실제 교육과 연결되는 자료를 순서대로 제작합니다.

| 제작 시기       | 자료                          | 연결할 다음 행동                    |
| ----------- | --------------------------- | ---------------------------- |
| **2주차**     | **집에서 확인하는 수학 질문 5개 + 기록지** | 다음 수학 콘텐츠 구독, 관련 과정 문의       |
| **5주차**     | **블록코딩 이후 파이썬 시작 로드맵**      | 준비 수준·기기 확인, 입문 과정 문의        |
| **6주차**     | **가족 독서 대화 질문 7개**          | 질문 교육 콘텐츠 구독, 대상에 맞는 고전읽기 안내 |
| **8주차**     | **7일 설명하기 활동표**             | 실제 참여와 학습 방식 경험              |
| **10~11주차** | **겨울방학 학습 계획·점검표**          | 겨울 과정 관심 등록, 공개 수업 참여        |

자료는 **일부를 공개해 먼저 가치를 보여주고**, 더 필요한 사람이 요청하도록 합니다.

세 채널을 모두 추가하고 인증해야 받을 수 있도록 만들지는 않겠습니다. 각 채널에서 한 번에 요구하는 행동을 줄입니다.

**인스타그램은 다음 편 팔로우, 블로그는 관련 글·이웃 추가, 카카오는 필요한 자료 요청**을 중심으로 잡습니다.

### 자료 안내 문구 예시

> “개념을 아는지 확인해 보세요”라는 말만으로는 어렵습니다.
> 집에서 바로 써볼 수 있는 질문 5개와 기록지를 준비했습니다. 샘플을 먼저 보시고, 전체 자료가 필요한 분은 카카오 채널에서 **‘수학질문’**이라고 남겨주세요.

자료 요청은 이후 모든 홍보에 동의했다는 뜻으로 처리해서는 안 됩니다. KISA는 광고 수신동의를 받을 때 ‘혜택 알림’, ‘정보제공’처럼 광고 여부를 모호하게 하는 표현을 사용하지 않도록 안내합니다. ([KISA][6])

## 5-2. 네이버 카페·교육 계정과의 제휴

첫 주에 **제휴 후보 20곳**을 정리하고, 이후 주 5곳씩 적합한 제안을 보냅니다. 실제 협업 목표는 **100일 동안 6~8건**으로 잡겠습니다.

후보는 회원 수나 팔로워 수만 보지 말고 다음을 확인합니다.

| 평가 항목  | 확인할 내용                           |
| ------ | -------------------------------- |
| 대상 적합성 | 초등 학부모·파이썬 입문·독서 교육에 관심이 있는가     |
| 실제 반응  | 최근 관련 글에 구체적인 질문과 대화가 있는가        |
| 광고 과밀도 | 광고 게시물이 지나치게 많지는 않은가             |
| 협업 방식  | 자료 제공·설명회·공동 게시를 허용하는가           |
| 비용과 조건 | 게시 기간, 수정, 광고 표시, 결과 확인 범위가 명확한가 |

처음부터 “체험단 모집 글을 올려주세요”보다는 다음처럼 제안하십시오.

> 메타센스를 운영하며 초등수학과 파이썬을 가르치고 있습니다.
> 회원님들이 자주 질문하시는 ‘○○’와 연결되는 질문 자료와 짧은 시연을 준비했습니다.
> 자료 소개 또는 학부모 설명회를 함께 진행하는 협업을 제안드립니다. 게시 위치, 운영자 승인, 광고 표시와 비용은 사전에 협의하겠습니다.

공개적으로 협업 제안을 받는 창구를 사용하고, 학부모 개인에게 무작위 영업 메시지를 보내지 않습니다.

무료 수강이나 제작비 등을 제공받은 협업 후기에는 실제 경제적 관계를 표시해야 합니다. **좋은 평가를 조건으로 요구하지 않고**, 체험의 장단점을 사실대로 말하도록 해야 합니다. ([연합뉴스][7])

## 5-3. 설명회는 4회, 짧게 반복합니다

| 회차 | 제안 날짜           | 주제                       |
| -- | --------------- | ------------------------ |
| 1회 | **10월 1일 목요일**  | 초등수학 온라인 수업, 체험할 때 확인할 것 |
| 2회 | **10월 22일 목요일** | 블록코딩 다음, 파이썬을 어떻게 시작할까   |
| 3회 | **11월 12일 목요일** | 부모와 아이가 함께 만드는 학습 계획표    |
| 4회 | **12월 3일 목요일**  | 겨울방학 공개 수업과 과정 선택        |

시간은 **오후 8시, 40분**을 계획안으로 넣었습니다. 실제 수업 일정에 맞게 확정하면 됩니다.

구성은 **20분 교육 내용 → 10분 실제 학습 화면 → 10분 질문**으로 단순화합니다. 광고만 하는 설명회가 아니라, 참여한 것만으로도 도움이 되는 시간이 되어야 합니다.

# 6. 광고는 세 채널에 무작정 나누지 않고 순차적으로 시험합니다

## 100일 예산 배분안

| 항목             |      배정 상한 |
| -------------- | ---------: |
| 인스타그램 광고       |  **86만 원** |
| 네이버 검색·콘텐츠 광고  |  **63만 원** |
| 카카오 채널 확보 광고   |  **29만 원** |
| 커뮤니티 제휴·공동 콘텐츠 |  **71만 원** |
| 자료·메시지·운영 비용   |  **21만 원** |
| 미집행 예비비        |  **30만 원** |
| **합계**         | **300만 원** |

실제 견적이 아니라 **지출 배분안**입니다. 부가세·수수료가 발생하면 이 총액 안에서 매체 집행액을 줄이고, 제휴 조건이 맞지 않으면 돈을 쓰지 않습니다.

## 인스타그램 광고: 먼저 프로필에 방문할 이유를 시험합니다

첫 시험은 **2주차, 약 10만 원을 7일에 나누어 운영하는 안**입니다.

같은 주제로 다음 두 소재를 비교합니다.

| 소재 A                             | 소재 B                             |
| -------------------------------- | -------------------------------- |
| 선생님이 문제 하나를 직접 설명                | 학부모 질문을 먼저 보여준 뒤 답변              |
| “24÷6을 맞혔다면, 이번에는 그림으로 설명해 볼까요?” | “계산은 하는데 설명은 어려워한다면, 무엇을 확인할까요?” |

광고 세트는 하나로 시작하고, 소재는 두 개 정도로 제한합니다. 우선 **한국의 성인 학부모를 고려한 범위**에서 시작하되, 어머니만 대상으로 단정하지 않습니다.

Meta는 인스타그램 프로필 방문을 유도하는 광고를 지원합니다. 다만 **프로필 방문 최적화가 팔로워 확보를 보장하는 것은 아니므로**, 방문 후 실제로 팔로우·자료 요청이 일어나는지 따로 보아야 합니다. ([Facebook][8])

## 네이버 광고: 좋은 글을 확대하는 경로와 체험 신청 경로를 구분합니다

첫 후보 키워드는 다음처럼 실제 수업과 연결되는 표현으로 잡습니다.

**초등수학 온라인 수업, 초등수학 개념, 초등학생 파이썬, 블록코딩 다음, 파이썬 입문 수업** 등입니다.

이것들은 검색량이 검증된 추천 순위가 아니라 **조사할 후보**입니다. 네이버 키워드 도구에서 검색량과 관련 키워드를 확인한 뒤 선택합니다. ([Naver Ads][9])

광고 연결은 두 가지로 나눕니다.

| 광고 목적     | 연결                                     |
| --------- | -------------------------------------- |
| 블로그 독자 확보 | 학부모의 질문에 충분히 답하는 글 → 관련 글 → 다음 편·이웃 추가 |
| 체험·상담 확보  | 과목별 안내 페이지 → 대상·조건 확인 → 신청 또는 상담       |

파워컨텐츠는 **구매 가능한 지정 키워드와 심사 조건**이 있으므로, 모든 후보 키워드로 광고할 수 있다고 가정하지 않습니다. 적합하지 않다면 파워링크와 실제 안내 페이지 조합을 검토합니다. ([Naver Ads][10])

## 카카오 광고: ‘친구 추가’보다 먼저 추가할 이유를 제시합니다

6주차부터 소액 시험합니다.

> **집에서 써보는 수학 질문 5개**
> 샘플을 보고, 필요한 자료는 메타센스 채널에서 요청하세요.

“메타센스 채널 친구가 되어주세요”라는 광고보다, **어떤 도움을 받을 수 있는지 보여주는 제안**을 먼저 시험하는 것입니다.

친구 추가 클릭, 실제 친구 추가, 첫 채팅, 자료 요청을 나누어 확인하십시오. 광고에서 선택하는 채널 확보 설정과 결과 보고 지표도 구분해야 합니다. ([Kakao Business][11])

**처음부터 세 광고 플랫폼을 동시에 켜지 않습니다.** 실행표는 주로 주당 1~2개 매체만 운영하도록 배분했습니다.

**게시 외 활동:** 협력처 2곳이 같은 활동표를 소개하도록 제안합니다. 참여 목표는 30가정으로 시작합니다. 참여는 보호자 중심으로 받고, 학생 얼굴·이름·공개 인증·친구 태그는 요구하지 않습니다.

**운영 방식:** 카카오 광고 메시지를 매일 7번 보내는 방식으로 운영하지 않습니다. 자료를 한 번에 확인할 수 있게 하고 필요한 참여 안내만 구분합니다.

**측정:** 첫 활동, 3일 참여, 완료를 각각 기록합니다. **지출 상한 25만 원.**

**콘텐츠:** 「7일 설명하기에서 나온 질문」, 「시작했지만 이어가지 못한 이유」를 발행합니다.

**게시 외 활동:** 참여 가정에 기록 재배포 허락을 구합니다. 만족도나 공개 후기 여부를 다음 혜택의 조건으로 삼지 않습니다. 잘 맞았던 협력처에는 후속 콘텐츠를 제안합니다.

**광고·측정:** 공개 가능한 실제 사례와 교사의 시연 중 어떤 방식이 유효 문의로 연결되는지 시험합니다. 실제 효과를 확인하지 않고 “자기주도학습이 완성됐다”고 표현하지 않습니다. **지출 상한 20만 원.**

# 8. 네이버 플랫폼은 이렇게 연결합니다

네이버를 블로그 하나로만 쓰지 않되, 서비스마다 새 일을 만들지는 않겠습니다.

| 네이버 서비스        | 이번 100일에서의 역할                              |
| -------------- | ------------------------------------------ |
| **블로그**        | 검색 유입·실제 수업 검토·이웃 관계의 중심                   |
| **클립**         | 릴스 원본을 재사용하고 관련 블로그 글로 연결                  |
| **기존 카페**      | 운영자 승인을 받은 자료·설명회·공동홍보                     |
| **지식iN**       | 실제 답할 수 있는 교육 질문이 있을 때만 답변. 답변 자체가 완결되게 작성 |
| **톡톡**         | 네이버에서 들어온 문의에 그 자리에서 답변                    |
| **키워드 도구**     | 매월 콘텐츠·광고 주제 후보 검토                         |
| **파워컨텐츠·파워링크** | 좋은 글과 실제 과정 안내의 유입 확대                      |
| **스마트플레이스·예약** | 실제 사업 형태와 등록 조건이 맞을 때만 검토                  |

스마트플레이스는 지역과 관련된 위치·전화 정보 등이 의미 있는지 등을 등록 기준으로 봅니다. **온라인 서비스에 지역 검색 노출을 붙이기 위해 허위 장소를 만드는 방식은 사용하지 않습니다.** ([Naver Smart Place][13])

**새 네이버 카페 개설은 이번 100일의 필수 과제에서 제외**합니다. 먼저 기존 학부모가 있는 곳과 협업하는 데 집중하십시오.

Blogger도 매주 별도 운영하지 않습니다. 반응이 확인된 가이드를 장기 자료로 확장하는 작업만 후순위로 두겠습니다.

# 9. 숫자가 안 늘어날 때 무엇을 바꿀 것인가

이 부분이 중요합니다. 계획을 성실히 실행했다는 것과 실제 효과가 있다는 것은 다릅니다.

## 단계별 수정 기준

아래 기준은 통계적으로 보장된 기준값이 아니라, **실무에서 원인을 찾기 위한 점검 기준**입니다.

| 나타나는 현상                  | 먼저 수정할 것                     |
| ------------------------ | ---------------------------- |
| 콘텐츠 조회·도달 자체가 적음         | 주제, 첫 질문, 공동 배포 경로           |
| 프로필 방문은 있는데 팔로우가 적음      | 소개 문구, 대표 게시물, 앞으로 볼 콘텐츠의 약속 |
| 블로그 검색 유입은 있는데 이웃이 늘지 않음 | 관련 글 연결, 시리즈 구성, 다음 편 예고     |
| 카카오 친구는 늘지만 첫 채팅이 없음     | 웰컴메시지와 자료 요청 방법              |
| 자료 요청은 많지만 체험 관심이 없음     | 자료와 실제 수업의 연결, 대상 적합성        |
| 체험 신청은 있지만 첫 학습을 하지 않음   | 가입·자녀 등록·기기·난이도·첫 활동 안내      |
| 제휴 노출은 있었지만 문의가 없음       | 제휴 대상, 전달한 자료, 연결 페이지        |
| 친구·팔로워 증가 후 해제·차단이 많음    | 모집 당시의 기대와 이후 콘텐츠·발송 내용의 불일치 |

### 광고 중단·수정 규칙

**링크 오류, 신청 오류, 무관한 문의가 반복되는 광고는 즉시 수정하거나 중단합니다.**

반면 하루나 이틀, 문의 한두 건만 보고 승자를 정하지 않습니다. 기본적으로 **5~7일 단위로 비교**하고, 가능하면 충분한 방문과 행동이 모인 뒤 판단합니다.

예를 들어 자료 안내 페이지에 실제 방문이 100회 정도 발생했는데 요청이 전혀 없다면, 광고비를 늘리기보다 페이지·자료·대상을 먼저 점검하겠습니다. 다만 이 숫자는 절대적인 성공·실패 판정선이 아닙니다.

또한 **광고비를 전체 팔로워 순증으로 나눈 값이 광고만의 효과는 아닙니다.** 같은 기간의 자연 유입과 공동 게시 영향을 받기 때문입니다. 광고관리자에서 제공하는 지표, 고유 연결 코드, 상담에서 확인한 유입 경로를 함께 사용하십시오.

# 10. 첫 2주에 가장 집중해야 할 일

100일 계획이 길어도, 출발점은 단순해야 합니다.

**첫째, 수학 질문 자료 하나를 제대로 만듭니다.**
학부모가 샘플만 읽어도 도움이 되고, 다른 학부모에게 전달할 이유가 있는 자료여야 합니다.

**둘째, 관심이 맞는 계정·블로그·커뮤니티를 직접 만납니다.**
공식 계정 안에서 게시물을 만드는 시간과 밖에서 독자를 만나는 시간을 분리해 확보합니다.

**셋째, 인스타그램 광고를 작게 시험하고 실제 행동을 확인합니다.**
조회수만이 아니라 프로필 방문, 팔로우, 자료 요청으로 연결되는지를 봅니다.

메타센스에는 직접 만든 교재, 실제 수업 화면, 학생의 질문에 답하는 경험이라는 재료가 있습니다. 이번 캠페인은 그것을 반복해서 홍보 문구로 바꾸는 것이 아니라, **학부모가 써볼 자료와 확인할 장면으로 바꾸고, 다른 사람의 독자에게까지 전달하는 작업**에 집중하는 것이 좋겠습니다.

**100일 동안 가장 엄격하게 지킬 원칙은 이것입니다. “게시했으니 끝”이 아니라, “이번 주에는 어디에서 새로운 학부모를 만났는가”를 매주 확인하십시오.**
