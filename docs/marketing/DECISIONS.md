## 원본 간 차이의 처리

- 초기 PDF의 90일/주6~8시간안에서 후속 100일 TXT·Excel(9/8~12/16, 주18~22시간)으로 확장. 후속안을 일정 기준으로 한다.
- 초기 소개 원고보다 POSITIONING과 이후 일지가 현재 소개 상태에 가깝다. 옛 초안은 이력으로 보존한다.
- Excel의 첫 주 일반 광고 점검 문구보다 광고_예산의 매체 배정0원을 우선. 비용 상한을 자동 승인으로 해석하지 않는다.
- 오늘 카카오 소식을 선발행했으므로 목요일에 같은 소식을 다시 올리지 않는다. 새로운 글과 실제 유용성을 보고 주간 운영량을 조정한다.
- 추천 체험 기간은 옛 문서의 1개월과 현행 페이지의 4주가 다르므로 공개 문구 작성 전 실제 정책을 확인한다.

- 예약 범위 확정: 자동 승인 검토 결과에 따라 로컬 계획·초안·일지 갱신만 활성화. 무인 외부 실행은 별도 허가 전에는 수행하지 않는다.

- 2026-09-08 추가: 기존 유튜브를 메타센스 공식 수학·파이썬 쇼츠 채널로 전환. 네 채널에 수학감각 시리즈 저자 운영 사실을 신뢰 근거로 연결. 실제 설정과 남은 모바일 링크는 official-channels/YOUTUBE-AND-AUTHOR.md에 기록.

## 2026-09-08 — 유튜브를 상시 할 일에 통합

사용자는 유튜브 업무도 MD에 정리하여 빠지지 않도록 요청했다. 기존 원본에도 쇼츠 재배포는 있었으나 채널별 절차가 부족하여 YOUTUBE-PLAN.md를 신설했다. 기존 영상 주3회 슬롯을 공동 사용하고 수학·파이썬을 모두 포함하도록 운영 배분을 추가했다. 설정 완료와 첫 쇼츠 미발행을 구분하고 매일 제작·연결·반응, 주간 개선을 기록한다. 예약 외부 활동 허용 범위는 변경하지 않았다.
