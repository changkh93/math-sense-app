## 동의 없는 활용을 검토하는 범위

- 가장 먼저 교사 소유 문제·코드와 실제 도구 실행 화면을 사용한다. 학생 창작물과 평가를 임의로 교사 소유라고 취급하지 않는다.
- 개인 기록은 이름/닉네임만 블러 처리했다고 익명정보로 확정하지 않는다. 최종 이미지에서 계정/프로필/날짜/URL/파일명/독특한 서술/평가 맥락/EXIF/대체텍스트도 확인한다.
- 불투명 마스킹 또는 화면 잘라내기로 불필요한 정보 제거. 블러가 복원 불가능하다고 약속하지 않는다. 원본 학생 기록을 public 또는 배포 디렉터리에 복사하지 않는다.
- 코드·작품 자체가 학생 창작물이라면 이용권한 검토를 별도로 한다. 마케팅 목적을 가명정보 연구 특례로 정당화하지 않는다.
- 캡처는 '코드 스튜디오 실행 화면', '과제 제출 화면'처럼 실제 확인한 대상을 설명한다. 후자의 실제 학생 자료는 이번에 공개하지 않았다.
- 재구성된 기록은 실제라고 표시하지 않는다. 단순히 이름만 ***로 바꾼 원본 기록의 공개는 이번 작업에서 실행하지 않았다.

## 2026-09-14 — 실제 화면 표기와 추가 동의 없이 활용할 경로

사용자는 닉네임도 가리고, 날짜·내용으로 학생을 식별할 수 없다고 설명했다. 이 설명은 작업 전제로 기록하되, 구체적인 최종 이미지의 익명성 검토 완료를 뜻하지 않는다. 실제 화면에 ‘시연용 예시’를 일괄 표기하지 않는다. 현재 가이드 원고·생성 HTML·PythonEducation 소스에서 해당 문구는 발견되지 않았다.

| 자료 | 실행 방식 | 공개 캡션 |
|---|---|---|
| 메타센스 소유 코드·교재와 도구 화면 | 개인 계정 영역을 제외하고 실제 실행 결과를 캡처. 학생에게서 가져온 창작물로 대체하지 않음 | 메타센스 코드 스튜디오에서 사각형을 그리는 과정 |
| 교사 작성 과제 안내·피드백 방법 | 학생 답안·성적·인용 없이 교사 소유 설명과 도구 기능을 보여줌 | 코드를 제출하고 풀이 과정을 기록하는 화면 |
| 실제 학습 활동의 집계 | 접근 권한과 처리 근거가 있는 기록에 한해 검토. 소수 집단·특이 사례·개별 날짜 조합으로 개인이 드러나면 범위를 넓히거나 해당 항목 제외. 수치를 만들지 않음 | 실제 집계 기간·대상·활동 지표를 명시 |
| 실제 학생 기록 일부 | 아래 익명성 및 이용권한 검토를 모두 통과한 부분만 사용. 통과하면 실제 기록이라는 사실을 유지 | 파이썬 과제 제출 기록 일부 · 개인정보 삭제 |

검토 절차:
1. 이름·닉네임은 삭제, 불투명 가림 또는 잘라내기로 제거한다. 텍스트 인용에서 이름은 `***`로 바꾼다. 블러 사용 시에도 최종 공개 크기와 확대 상태에서 읽히지 않는지 확인한다.
2. 날짜·내용을 무조건 지우지는 않는다. 계정·URL·원본 기록·기존 공개 게시물 등과 합리적으로 연결했을 때 개인을 알아볼 수 있는지를 검토한다. 원본을 보유한 운영자 측 연결 가능성도 포함한다. 필요한 학습 내용만 남긴다.
3. 파일명·메타데이터·대체텍스트·썸네일에도 식별자가 없는지 확인하고, 공개 파일에는 원본이나 편집 레이어를 넣지 않는다.
4. 학생의 창작 코드·글·그림을 사용하는 경우, 개인정보 익명성과 별도로 기존 이용허락 등 공개 이용 근거를 확인한다. 익명 처리가 저작권까지 없애지는 않는다.
5. 실제 화면은 활동을 그대로 설명한다. 재구성 자료는 ‘과제 작성 방법’, ‘제출 형식’처럼 정확히 이름 붙이며, 실제 학생의 말·성과처럼 제시하지 않는다.

법적 기준: [개인정보 보호법 제58조의2](https://law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1022694479)는 시간·비용·기술과 다른 정보의 사용을 고려해도 개인을 알아볼 수 없는 정보를 적용 제외 대상으로 규정한다. 따라서 닉네임 가림만으로 모든 자료를 동의 없이 홍보에 사용할 수 있다고 확정하지 않는다. [저작권법 제10조](https://law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1025058269)는 창작 시 저작권 발생을 규정한다. 실제 자료의 이용 가능 여부는 개별 검토가 필요하다.

이번 변경은 운영 기준·표기 확인이다. 새 학생 원본 조회, 익명화 이미지 제작, 외부 게시 또는 배포는 수행하지 않았다.
