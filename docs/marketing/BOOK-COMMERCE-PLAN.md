## 스토어 내부 실행

1. 등록 적합성: 종이책/전자책/영상 분리. 전자책 정식 ISBN/발행일 수정은 기존 완료 증거 유지. 영상강의 ISBN 없음·오디오북 등록은9/21 담당자 확인 후 올바른 경로로 조정. 임의 ISBN/허위 카테고리로 노출 우회 금지.
2. 대표 이미지: 실물 표지·구성 한눈에 확인, PDF는 종이책 배송 없음 표기. 추가 이미지는 실제 내지1장→사용순서1장→구성비교. 포스터 문구로 표지를 덮지 않는다. 기존 실물 자산부터 사용.
3. 상세 상단: 누구에게 필요한가, 무엇이 오는가, 첫날 어떻게 쓰는가. 세트/책만/PDF/온라인 수강권을 구분한다. 모바일 글간격 유지.
4. 후기: 출처가 구상품이면 원상품명·작성일·관측일 표시. 기존 평점/건수를 새상품 실적으로 표시하지 않는다. 좋았던 점과 어려웠던 점을 함께 소개한다. 실제 캡처 이미지 확보가 안 되면 원문 인용을 캡처 완료라고 기록하지 않는다.
5. 검색: 9/19~20 업데이트 집계 후 브랜드+정확한 상품명/ISBN을 먼저 확인. 네이버 도서 서비스Y, 공개 도서검색, 순위 진단을 각각 기록. 데이터분석의 실제 유입검색어로 이후 제목/태그를 결정한다.
6. 배송/CS: 기존 대시보드 발송 지표80.3은 지연 원인 점검 대상. 주문 처리 현황을 실제 신규매출로 해석하지 않는다. 재고/발송 가능일 확인 없이 당일배송 약속 금지.

## 정직한 리뷰 확보와 활용

- 배송물 동봉용 활용 안내에 중립적 후기 요청: 사용 기간, 이해하기 쉬웠던 장면, 막힌 부분. 별점/긍정평가 조건, 지인구매·대리작성·보상형 리뷰 없음.
- PDF에는 제공 파일/메일 템플릿의 활용법과 문의 창구를 먼저 개선한다. 새 고객별 이메일 발송 자동화나 기존 구매자 일괄 메시지는 이번 계획만으로 실행하지 않는다.
- 질문/낮은별점 포함 실제 후기는 구체적 도움으로 응답. 매주 월·목 답글 여부/미해결 사용문제 확인.
- 베스트리뷰는 상세한 실제 사용정보를 기준으로 비용 없이 선정. 이미 선정된 분수/소수2건 유지, 짧은 칭찬만 있는 후기를 무리하게 추가 선정하지 않는다.
- 한달사용 후기는 강요하지 않는다. “사용 뒤 달라진 점이 있다면 다시 알려주세요” 정도로 선택권을 준다.
