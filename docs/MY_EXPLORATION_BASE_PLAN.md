# 나의 탐험기지 설계안

## 결론

`나의 탐험기지`는 단순 프로필 페이지가 아니라 학생이 매일 돌아와 확인하는 개인 학습 본부로 설계한다. 핵심은 광석 소비처를 많이 늘리는 것이 아니라, 광석으로 산 것들이 학생의 정체성, 아고라 답변, 랭킹, 크루, 학습 기록 화면에 반복 노출되게 만드는 것이다.

현재 코드베이스에는 이미 다음 자산이 있다.

- 프로필 편집: `src/components/Space/ProfileEditView.jsx`
- 상점과 구매 트랜잭션: `src/components/Space/SpaceStore.jsx`
- 공개 프로필 프레임/칭호/시그니처 모델: `src/utils/socialUtils.js`
- 도감/배지: `src/components/Space/SpaceCollection.jsx`, `src/utils/badgeUtils.js`
- 성장 기록/히트맵/랭킹성 화면: `src/components/Space/SpaceDashboard.jsx`
- 광석 거래 내역: `src/components/Space/CrystalLedger.jsx`
- 아고라 social economy 설계: `docs/AGORA_SOCIAL_PHASE_PLAN.md`

따라서 가장 효율적인 전략은 새 경제 시스템을 따로 만들지 않고, 기존 기능을 `나의 탐험기지`라는 한 화면에 재배치한 뒤, 광석 소비가 보이는 표면을 단계적으로 늘리는 것이다.

## 설계 원칙

1. 광석으로 실력을 사게 하면 안 된다.
   - 구매 가능: 표현, 전시, 질문 현상금, 크루 운영, 보호/편의 아이템.
   - 구매 불가: 점수, 도움 수, 배지 획득 조건, 선생님 인증, 랭킹 순위.

2. 아이템은 “구매 순간”보다 “보이는 빈도”가 중요하다.
   - 프로필 프레임을 샀다면 프로필 편집 화면에서만 보이면 약하다.
   - 아고라 답변 카드, 랭킹 행, 크루 멤버 카드, 기지 상단, 명예의 전당에 반복 노출돼야 한다.

3. 학생에게는 누적 자산보다 “나의 변화”가 더 강한 동기다.
   - 총 광석, 총 시간만 보여주면 오래 한 학생만 유리하다.
   - 이번 주 학습일, 오답 재도전, 질문 해결, 새로 정복한 개념을 상단에 둔다.

4. 개발은 2D 중심으로 간다.
   - 3D 아바타/방 꾸미기는 비용이 크고 모바일/성능 리스크가 있다.
   - 현재 앱의 우주 HUD 스타일과 카드 UI를 살려 2D 기지 화면을 먼저 만든다.

## 화면 구조

### 1. 상단: 기지 지휘실

목적: 학생이 들어오자마자 “내가 어떤 학습자이고, 이번 주 무엇을 했는지”를 본다.

구성:

- 아바타 또는 이니셜 캡슐
- 공개 표시 이름
- 현재 대표 칭호
- 장착 중인 프로필 프레임
- 보유 광석
- 연속 학습일
- 이번 주 요약
  - 이번 주 학습일 수
  - 퀴즈/영상/과제 활동 수
  - 오답 재도전 수
  - 아고라 질문/답변 수
- 대표 배지 3개
- 빠른 행동 버튼
  - 기지 꾸미기
  - 상점 가기
  - 오답 정제소
  - 아고라 질문하기

표현 예시:

> 왕새우님  
> 오답을 두려워하지 않는 탐험가  
> 이번 주 4일 학습 · 오답 12개 재도전 · 질문 2개 등록

### 2. 중앙: 나의 개념 지도

목적: 학생이 수학/파이썬 전체 세계에서 자신이 어디를 지나왔는지 본다.

현재 가능한 데이터:

- `users/{uid}/history`
- region/chapter/unit 구조
- 퀴즈 점수
- 영상/데이터 로그 완료 기록
- 오답/재검토 문항

MVP 표현:

- 개념 카드를 region/chapter 단위로 묶는다.
- 각 개념은 상태를 가진다.
  - 미탐사
  - 학습 중
  - 정복
  - 재정제 필요
- 카드에는 최근 최고 점수, 완료 횟수, 오답 잔여 수를 표시한다.

예시:

| 개념 | 상태 | 기준 |
| --- | --- | --- |
| 정수와 유리수 | 정복 | 퀴즈 90점 이상 또는 영상/로그 완료 |
| 일차방정식 | 재정제 필요 | 오답/재검토 문항 존재 |
| 파이썬 조건문 | 학습 중 | 일부 transmission 완료 |

중요한 점:

- 처음부터 복잡한 그래프 시각화로 가지 않는다.
- 모바일에서 읽기 쉬운 `개념 타일 + 필터`로 시작한다.
- 나중에만 별자리형 지도나 radial map으로 확장한다.

### 3. 하단: 전시와 소비

목적: 광석을 쓸 이유를 만든다.

구성:

- 배지 전시대
  - 기본 3칸 무료
  - 4번째/5번째 슬롯 광석 구매
- 명함 스킨
  - 현재 `PROFILE_FRAMES`를 확장
  - 아고라 답변 카드와 랭킹 카드에도 적용
- 대표 답변 고정
  - 채택/인증된 답변만 고정 가능
  - 슬롯 해금은 광석 구매
- 기지 배경
  - 2D 배경 카드, HUD 색상, header skin
  - 실력과 무관한 표현 소비처
- 주간 회고 카드
  - “이번 주 가장 오래 집중한 날”, “가장 많이 복구한 개념” 같은 자동 생성 카드
  - 카드 테마 구매 가능

## 광석 소비처 우선순위

### A. 바로 해야 할 소비처

#### 1. 프로필/기지 꾸미기

효과가 즉시 보이고 구현 비용이 낮다.

구매 항목:

| 항목 | 가격 제안 | 구현 난이도 | 비고 |
| --- | ---: | --- | --- |
| 프로필 프레임 basic | 50 | 낮음 | 이미 프레임 구조 있음 |
| 프로필 프레임 premium | 150 | 낮음 | `PROFILE_FRAMES` 확장 |
| 한 줄 시그니처 | 30 | 구현됨 | 현재 구조 유지 |
| 배지 전시 4번째 슬롯 | 80 | 중간 | `pinnedBadgeIds` 필요 |
| 배지 전시 5번째 슬롯 | 150 | 중간 | 과시성 소비 |
| 기지 배경 카드 | 100~300 | 중간 | `explorationBaseTheme` |
| 주간 회고 카드 스킨 | 40 | 중간 | 저가 반복 소비 |

#### 2. 아고라 현상금 질문

학생이 광석을 관계 형성에 쓰게 만드는 가장 강력한 장치다.

규칙:

- 질문자는 공개적으로 익명.
- 현상금은 10/30/50/100 광석.
- 답변이 채택되면 답변자에게 지급.
- 답변이 없으면 일정 시간 후 환불.
- 답변자는 공개 프로필 명함으로 노출.

이 기능은 `docs/AGORA_SOCIAL_PHASE_PLAN.md`의 방향과 일치한다.

#### 3. 크루 운영권

이미 `SpaceStore.jsx`에 크루 창설권/참여권이 있다. 다만 학생이 왜 사야 하는지 화면에서 약할 수 있다.

강화 방향:

- `나의 탐험기지` 상단에 내 크루 배지를 표시.
- 크루 멤버 카드에 내 프레임/칭호 표시.
- 크루 주간 목표 달성 시 “크루 기지 배너”를 전원에게 노출.

### B. 조심해서 해야 할 소비처

#### 1. 보호 아이템

광자 실드, 크라이오 코어는 이미 좋다. 다만 너무 강해지면 성실함의 의미가 흐려진다.

운영 원칙:

- 실드: 오답 페널티 방어까지만 허용.
- 코어: 스트릭 보존까지만 허용.
- 점수, 배지, 선생님 인증에는 영향 없음.

#### 2. 기간제 스캐너

기간제라 경제 회전에는 좋다. 하지만 보상 증폭이 과하면 광석 인플레이션이 생긴다.

권장:

- 7일 기간 유지.
- 하루 보너스 상한 명확화.
- 구매 화면에 “활성 남은 기간”을 크게 표시.

### C. 하지 않는 편이 좋은 소비처

다음은 개발 비용 대비 리스크가 크다.

- 랜덤 뽑기형 가챠
- 점수 부스트
- 오답 제거권
- 선생님 인증 구매
- 랭킹 가산점 구매
- 3D 방 꾸미기 풀 시스템
- 너무 많은 아이템 등급과 희귀도

특히 가챠와 점수 부스트는 교육 서비스 신뢰도를 해친다.

## 획기적인 핵심 아이디어

### 1. 광석을 “물건”이 아니라 “공개 표면”으로 바꾼다

학생은 아이템을 사는 것보다 “다른 곳에서 보이는 나”에 더 반응한다.

따라서 모든 꾸미기 아이템은 최소 3곳 이상에 노출한다.

- 나의 탐험기지
- 아고라 답변 카드
- 랭킹/전당 카드
- 크루 멤버 카드
- 쪽지/공부 초대 카드

이 원칙이 있으면 아이템 수가 적어도 가치가 커진다.

### 2. “자격은 학습으로, 전시는 광석으로”

칭호와 배지는 사면 안 된다. 대신 전시 칸을 산다.

예:

- `방정식 정복자` 칭호: 실제 방정식 단원 조건 달성 시 획득
- 대표 칭호 2개 동시 노출: 광석으로 슬롯 구매
- 배지: 조건 달성으로 획득
- 배지 핀 슬롯: 광석으로 확장

이 구조가 교육적 공정성과 소비 욕구를 동시에 만족시킨다.

### 3. 오답을 “약점”이 아니라 “정제 가능한 광맥”으로 보여준다

기지 안에 `정제소 상태판`을 둔다.

표현:

- 오늘 정제 가능한 문항 5개
- 반복 오답 광맥 3개
- 정제 완료율 62%
- 이번 주 복구한 개념 4개

광석 소비 연결:

- 정제소 입장권을 팔지는 않는다. 오답 복구는 학습권이므로 무료가 맞다.
- 대신 정제 성공 후 회고 카드, 배지 전시, 정제소 테마를 구매 가능하게 한다.

### 4. “주간 회고 카드”를 만든다

학생에게 매주 자동으로 작은 기록 카드를 발급한다.

예:

- 이번 주 최고 집중일: 2026-06-03 · 1시간 30분
- 가장 많이 정제한 개념: 일차방정식
- 새로 정복한 개념: 함수의 그래프
- 나의 탐험 스타일: 꾸준형 / 몰입형 / 질문형 / 복구형

광석 소비:

- 회고 카드 스킨
- 회고 카드 프로필 고정권
- 명예의 전당 전시 연장권

이 기능은 첨부 이미지의 집중 시간 그래프, 1년 히트맵, 월간 요약 데이터를 그대로 활용할 수 있다.

### 5. “기지 방문 카드”를 만든다

공개 범위를 제한한 소셜 표면이다.

- 질문자는 익명 유지.
- 답변자/크루 멤버/랭킹에서는 공개 프로필만 노출.
- 다른 학생이 볼 수 있는 것은 공개 명함, 대표 칭호, 대표 배지, 도움 수, 대표 답변 정도로 제한.
- 개인 전화번호, 실제 학교/회사, 상세 학습 로그는 노출하지 않는다.

## 데이터 모델 제안

`users/{uid}`에 직접 붙일 수 있는 필드:

```ts
{
  publicDisplayName: string,
  publicTitle: string,
  publicSignature: string,
  publicProfileEnabled: boolean,
  selectedProfileFrame: string,
  ownedProfileFrames: string[],
  profileSignatureUnlocked: boolean,

  explorationBaseTheme: string,
  ownedBaseThemes: string[],
  pinnedBadgeIds: string[],
  badgeSlotCount: number,
  pinnedAnswerId: string | null,
  pinnedReflectionCardIds: string[],

  hallShowcaseCredits: number,
  crewCreationPasses: number,
  crewJoinPasses: number
}
```

`users/{uid}/weekly_reflections/{weekKey}`:

```ts
{
  weekKey: string, // YYYY-MM-DD, Monday key
  activeDays: number,
  focusMinutes: number,
  quizAttempts: number,
  videoMinutes: number,
  recoveredMistakes: number,
  questionsAsked: number,
  answersAccepted: number,
  masteredConcepts: string[],
  weakConcepts: string[],
  styleLabel: string,
  generatedAt: Timestamp
}
```

`users/{uid}/base_purchases/{purchaseId}`는 필수는 아니다. 현재 `crystal_transactions`가 있으므로 MVP에서는 거래 내역 metadata로 충분하다.

추가 transaction type:

- `base_theme_purchase`
- `badge_slot_purchase`
- `reflection_card_pin`
- `answer_pin_purchase`
- `agora_bounty_lock`
- `agora_bounty_award`
- `agora_bounty_refund`

## 구현 단계

### Phase 1. 나의 탐험기지 MVP

목표: 기존 데이터와 기존 상점 자산만으로 “프로필보다 강한 허브”를 만든다.

작업:

1. `ProfileEditView`와 별도인 `ExplorationBaseView.jsx` 생성.
2. 네비게이션의 `프로필 수정`을 `나의 탐험기지`로 변경.
3. 기지 상단에 공개 프로필, 프레임, 칭호, 광석, 스트릭, 이번 주 요약 표시.
4. 현재 `SpaceCollection`의 배지 일부를 기지 전시대로 가져온다.
5. 현재 `SpaceDashboard`의 월간/히트맵 요약 일부를 기지 카드로 가져온다.
6. `프로필 편집`은 기지 안의 설정 버튼으로 이동.

개발 효율:

- 신규 데이터 모델 최소.
- 화면 조합 중심.
- 기존 `history`, `userData`, `transactions`, `badgeUtils` 재사용.

### Phase 2. 기지 꾸미기 상점

목표: 광석 소비처를 체감 가능한 형태로 늘린다.

작업:

1. `SOCIAL_STORE_ITEMS`에 base/profile 아이템 확장.
2. `PROFILE_FRAMES`를 5~8개로 확장.
3. `BASE_THEMES` 추가.
4. 구매 처리에 `base_theme_purchase`, `badge_slot_purchase` 추가.
5. 기지 화면에서 보유 테마와 전시 슬롯 선택 UI 제공.

권장 초기 아이템:

- 오로라 관측소 배경
- 심해 연구소 배경
- 태양 관측 기지 배경
- 고전 수학 서재 배경
- 방정식 정복자 프레임
- 파이썬 터미널 프레임
- 배지 전시 4번째 슬롯
- 배지 전시 5번째 슬롯

### Phase 3. 개념 지도

목표: 학습 기록을 학생이 이해할 수 있는 성장 지도로 바꾼다.

작업:

1. `history`, `units`, `chapters`, `regions`, `incorrect_questions`, `review_marks`를 통합해 concept status 계산.
2. `ConceptMapPanel` 생성.
3. 필터: 전체 / 정복 / 학습 중 / 정제 필요.
4. 개념 클릭 시 해당 단원 또는 정제소로 이동.

판정 예시:

```ts
if (incorrectCount > 0 || reviewMarkCount > 0) return "needs_refinery";
if (bestScore >= 90 || completedTransmission || completedDataLog) return "mastered";
if (attemptCount > 0 || partialVideoProgress > 0) return "in_progress";
return "unexplored";
```

### Phase 4. 아고라 현상금 + 답변자 명함

목표: 광석을 사회적 관계와 공개 인정으로 연결한다.

작업:

1. 질문 생성 시 현상금 선택.
2. 채택 시 현상금 지급 transaction.
3. 질문자는 익명 표시.
4. 답변자는 공개 명함 표시.
5. 답변 카드에 기지 프레임/대표 배지/시그니처 노출.

### Phase 5. 주간 회고 카드

목표: 학생이 매주 자신의 성장을 소장하게 한다.

작업:

1. 클라이언트 계산 MVP로 시작.
2. 이후 Cloud Function 또는 관리자 배치로 주간 카드 생성.
3. 기지에 최근 4주 회고 카드 표시.
4. 카드 고정/스킨 구매 추가.

## 화면 명칭 정리

권장 IA:

- 기존 `프로필 수정` → `나의 탐험기지`
- 기지 내부 탭
  - 지휘실
  - 개념 지도
  - 전시대
  - 꾸미기
  - 공개 명함 설정

기존 `데이터베이스` 메뉴는 학생에게 의미가 약하다. 가능하면 `우주 도감` 또는 `배지 도감`으로 바꾸는 편이 낫다.

기존 `스토어`는 `광석 상점` 또는 `기지 보급소`가 더 명확하다.

## 성공 지표

정량 지표:

- 광석 순소비량 증가
- 상점 구매 전환율
- 프로필/기지 방문 빈도
- 아고라 질문 등록 수
- 답변 채택 수
- 오답 재도전 수
- 주간 재방문율

정성 지표:

- 학생이 자신의 칭호/배지를 말로 언급하는가
- 질문자가 현상금을 걸고 질문 품질을 높이는가
- 답변자가 공개 프로필을 꾸미고 싶어 하는가
- 학부모/선생님이 학생의 학습 흐름을 설명하기 쉬워지는가

## 최우선 추천

첫 개발은 `나의 탐험기지 MVP + 기지 꾸미기 상점 일부`가 맞다.

이유:

- 지금 가장 큰 문제는 광석을 쓸 무대가 부족한 것이다.
- 이미 프로필 편집과 상점, 프레임, 배지, 학습 기록이 구현되어 있다.
- 새 시스템보다 기존 시스템의 노출면을 늘리는 것이 빠르고 효과가 크다.
- 이후 아고라 현상금, 개념 지도, 주간 회고 카드가 자연스럽게 붙는다.

실행 순서는 다음이 가장 좋다.

1. `나의 탐험기지` 화면 신설.
2. 현재 프로필 수정 진입점을 기지로 교체.
3. 상단 지휘실, 대표 배지, 이번 주 요약, 최근 활동을 먼저 표시.
4. 프로필 프레임과 기지 테마 구매/장착을 붙인다.
5. 개념 지도와 아고라 현상금을 붙인다.
