# 화성 탐사대 — Zombie Knight 커리큘럼 계약

원래요청: MetaSense Python > 게임 프로젝트 하위, Section10 Advanced Pygame Tutorial~Section13 Zombie Knight Part3의전체31강. Space Invaders와동일하게영상없이Data Log/Code Trace/Field Test/Quiz Battle,상세제작문서,단계코드모달,시작/비교/완성백업,전체에셋을제공한다. 학생은게임스튜디오만사용한다. VSCode,터미널,pip,로컬Python설치나외부코드편집기절차를넣지않는다.

## 제작순서/문서

강의별실제내부작성순서를소스로확인한뒤독립적인한국어교육자료를작성한다. 완성소스순서로역추정하거나앞단원에완성기능을미리넣지않는다. 자동자막을전문복제하거나번역해대체문서로만들지않는다. 소스는개념/순서/실행관찰근거로활용한다.

각단계: 선행완료조건 →이번에만들것 →왜필요한지 →파일/클래스/메서드별정확한추가·교체위치 →생략없는입력코드 →핵심줄의쉬운설명 →여기서실행 →눈으로확인할화면/숫자/조작 →아직안되는것중정상인것 →증상별해결 →임시실험과삭제/복원 →누적코드링크. 모르는변수/함수/경로를갑자기등장시키지않는다. 부정확한전역문자열치환을피하고모델/AST/메서드범위의검증가능한편집을사용한다.

61~68은기초플랫포머실습이고69이후는별도최종게임으로명확히전환한다. 구분과소스재사용시점을원강의근거로정한다. 강의수가31이라고모든학습단원을억지로같은길이로맞추지않되전체강의대응표를유지한다.

각단원은2~5개의2~8줄Code Trace와10개의4지선다(정답1개/해설포함)를기본으로한다. 운영코드/관찰결과와문항을대조하고Field Test와현재유닛만Quiz Battle이같은문제은행을사용하도록한다.

## 화성테마

가칭: 화성 탐사대 - 신호 복구 (Zombie Knight). 사용자가우주탐험/화성테마의새에셋을명시했다. 참고숲/흙/잔디/기사/물/소년이미지는재배포에사용하지않는다.

역할대응안: 기사/소년→동일디자인탐사대원; 흙→화성암석; 잔디→안전착지발판; 물→위험분화구/에너지균열; zombie→오작동탐사로봇; ruby→신호결정/에너지셀; ruby maker→결정발생장치; portal→전송게이트. 실제공격/회복/수집/생성규칙을강의에서확인하기전스토리때문에임의로바꾸지않는다. 화성물리시뮬레이터라고주장하지않는다.

Codex가imagegen원본,파생프레임,효과음,폰트와출처를담당한다. 배경은먼풍경만; 충돌지형과구별. 투명PNG프레임의셀크기/발기준점/몸통축/좌우방향통일. idle/run/jump/attack/hurt등필요상태수는조사후확정. 좌측은가능하면flip으로생성. 충돌마스크는바뀐image와일치해야한다. 원본프레임을디버그그림으로오염시키지않는다.

전체학생프로젝트6MiB,단일파일5MiB한도. 원본큰atlas는작업자료에보관하고게임용에셋은별도최적화하여실제decodedbytes로검증한다. 이전DoHyeon폰트/OFL은재사용가능하나한글문자누락을시각검수한다. 모든경로assets/아래; 신규공개루트는public/mars-expedition/예정. 아직앱/DB미등록이다.
