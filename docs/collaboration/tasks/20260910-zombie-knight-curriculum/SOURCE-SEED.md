## 62 Designing a Level — 27613356

이전파일실행은빈창 → 먼저 전체타일/잔디/물Sprite그룹 선언 → 그 위에Tile(Sprite)클래스와생성자 작성 → x,y,타일번호,주그룹,선택그룹 인자 →super초기화 →종류별image로드·선택그룹등록 →주그룹등록 →get_rect/top-left →지도 아래중첩for(range/len) →행i/열j를x=j×32,y=i×32에연결 →번호별Tile생성 →loop배경색fill·전체그룹draw →실행 →image가없다는오류에서 == 대신 = 수정 →실행으로지도확인 →마지막에루프밖background로드·rect,루프fill을blit로변경 →실행 →지도에발판을추가해결과확인.

원강의의 오타 재현은 정상 코드에 영구 보존하지 않는다. 잘못된 부분은 별도 짧은 비교/실험으로 보고 반드시 복원한다.
