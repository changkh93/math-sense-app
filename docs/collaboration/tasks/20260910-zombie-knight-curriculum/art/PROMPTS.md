## explorer-run-atlas-master.png

Use case: stylized-concept. Asset type: a SINGLE transparent PNG sprite atlas for an original 2D side-view Mars exploration platform game. Create exactly EIGHT animation frames, arranged as a strict uniform 4-column by 2-row grid, wide 2:1 canvas, ideally 2048x1024, each cell square with equal padding. Each cell shows the SAME small Mars explorer in a consecutive frame of one smooth right-facing RUN cycle, read left-to-right then next row. Compact ivory pressure suit, teal chest light, rounded helmet with amber glass visor obscuring the face, burnt-orange compact life-support backpack, charcoal gloves and boots. Friendly capable explorer, no weapon for this movement atlas. Crisp professional hand-painted cartoon sprite with a clear silhouette readable at 64x64. Exact same body/helmet scale in every frame, side profile facing RIGHT throughout. Alternating legs and counter-swinging arms form eight clearly different run poses. Same pelvis anchor centered in each cell, soles along a consistent baseline, no camera changes, no perspective rotation, no shrinking or changing design. Actual transparent background and fully transparent padding between frames; no colored background, no floor, no shadows outside the character, no grid lines, no labels, no numbers, no UI, no watermark. Keep all limbs fully inside their cells without overlaps. The atlas will be sliced into animation frames in game code; it must be a usable sprite sheet rather than a promotional concept image.
