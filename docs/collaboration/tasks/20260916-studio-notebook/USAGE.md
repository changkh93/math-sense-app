# 코드 스튜디오 — 노트북 모드

1. 위쪽 **노트북 모드**를 누르면 같은 프로젝트에 빈 **notebook.ipynb**가 만들어집니다. 기존 노트북이 있으면 다시 엽니다. `main.py`는 그대로 남습니다. 이전 버전에서 `# %%` 셀로 작성한 Python 파일은 처음 전환할 때 코드·설명 셀을 복사해 보존합니다.
2. **+ 코드 셀**로 나누어 작성하고, **셀 실행** 또는 **Shift+Enter**로 실행합니다. 마지막 식은 `print()` 없이도 결과가 나옵니다.
3. 앞 셀의 변수·함수·객체는 실행한 순서대로 이어집니다. 왼쪽 `[숫자]`가 실제 실행 순서입니다. 코드를 바꿨다면 해당 셀과 영향을 받는 뒤 셀을 다시 실행하세요.
4. **전체 실행**은 위에서 아래로 실행하고 오류에서 멈춥니다. **세션 초기화**를 누르면 변수와 출력이 지워집니다. 깨끗한 상태로 검증하려면 초기화 후 전체 실행하세요.
5. 실행 결과·출력·오류와 `input()` 입력창은 **실행한 셀 바로 아래**에 나타납니다. 오른쪽 별도 패널 없이 셀을 넓게 사용합니다. turtle·Matplotlib 그림, pygame의 키보드·마우스, tkinter 버튼도 셀 아래에서 보고 조작합니다. **크게 보기**로 확대하고 **실행 화면 원래 크기로**로 돌아올 수 있습니다. 새 그림을 실행하면 이전 turtle·Matplotlib·pygame 그림은 미리보기로 남고, 마지막 실행 화면은 직접 조작할 수 있습니다. 이전 tkinter 화면을 다시 조작하려면 해당 셀을 실행하세요.
6. **파일 모드**는 `.py`, **노트북 모드**는 `.ipynb`를 편집합니다. 서로 독립된 파일이며 내용을 자동으로 덮어쓰지 않습니다. 탐색기에서 파일을 누르면 알맞은 편집기로 열리고, 모드 버튼은 마지막으로 열었던 해당 종류의 파일로 돌아갑니다. 모드 전환 자체는 변수를 지우지 않습니다. 파일 전체 실행은 새 실행이므로 기존 노트북 변수는 초기화됩니다.
7. **Colab 노트북 가져오기**로 `.ipynb`의 코드·설명을 가져옵니다. 실제 `.ipynb` 파일로 보관합니다. 파일 올리기·폴더 가져오기·프로젝트 백업 복원에서도 `.ipynb`를 지원합니다. 이미지·폰트·CSV·사운드는 기존 파일 올리기로 추가합니다.
8. **.ipynb 저장**은 코드·설명을 Colab/Jupyter 형식으로 내려받습니다. 기존 외부 HTML/스크립트 출력은 가져오지 않고, 실행 출력은 내보내지 않습니다.

9. 노트북 모드에서 탐색기의 **+**를 누르면 새 `.ipynb`를 만들 수 있습니다. 선택한 하위 폴더에도 만들 수 있고, 이름 변경·이동·삭제·개별 다운로드가 가능합니다.
10. 과제 기록소의 **코드 스튜디오에서 추가 → 목록 새로고침**에서 제출할 `.py`와 `.ipynb`를 선택하세요. 첨부 시점의 코드·설명이 사본으로 추가되고, 과제 전송을 누를 때 업로드됩니다.

코드·설명·프로젝트 파일은 기존처럼 이 브라우저에 자동 저장됩니다. 변수·셀 출력은 현재 방문 중에만 유지되며 새로고침 후 첫 셀부터 다시 실행해야 합니다. 마지막 편집 모드와 열린 파일은 복원합니다. 무한 게임 루프는 정지한 후 다음 셀을 실행하세요. 정지는 실행 세션을 정리하므로 앞 셀부터 다시 실행합니다.

기존 코드 스튜디오가 제공하는 수업 범위의 ColabTurtlePlus/turtle, pygame, tkinter, csv, pandas, NumPy, Matplotlib, itertools, fractions 등을 같은 실행기로 제공합니다. 임의 pip 설치나 Colab 전용 외부 서비스까지 제공하는 것은 아닙니다. pandas/tkinter는 기존 스튜디오의 수업용 호환 API 범위입니다.
