## 순서와 개선의 경계

- 완료 코드의 맨 위에 Game 클래스가 있어도 Game 구현 수업을 맨 앞에 놓지 않는다.
- 10유닛 내부도 reset → collision → round 순서다. 완성 파일의 메서드 나열 순서로 재배치하지 않는다.
- 강의 중의 일시적인 버그는 필요하면 증상-예측-수정으로 학습하되, 단계 끝에 오류를 숨기거나 남겨놓지 않는다.
- 브라우저 런타임 때문에 09의 중첩 대기 루프는 최상위 루프 + state로 개선한다. **같은 시점**에 가르치며 웹 버전의 차이로 명시한다.
- 05는 실제 편대 생성 전이다. 작성한 클래스가 왜 화면에 아직 나타나지 않는지 설명하고, 06에서 임시 편대를 처음 연결한다. 필요한 진단용 print는 별도 잠깐 테스트로 표시하고 제거 위치를 설명한다.
- 08/09의 아직 미구현된 처리는 학습 안내에 명시하고, 코드가 영구 멈추거나 닫히지 않는 상태는 허용하지 않는다.
