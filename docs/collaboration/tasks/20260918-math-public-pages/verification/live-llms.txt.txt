# 메타센스

> 둘시네가 운영하는 수학·파이썬·고전읽기 온라인 교육. 공개 학습 안내 링크 목록입니다.

## 과정
- [파이썬](https://msense.me/python): 초3부터, 자율 학습, 월15만 원, 기본 7일 무료체험, 신청 후 1일 이내 연락.

## 학습 노트
- [초등 파이썬, 몇 학년부터 시작하면 좋을까요?](https://msense.me/python/guides/first-python-age/): 메타센스 파이썬은 초등 3학년부터 권장합니다. 학년과 함께 짧은 안내를 따라가고 숫자 하나를 바꾸어 실행할 수 있는지 체험에서 확인하세요.
- [스크래치 다음 파이썬, 무엇을 이어서 배우나요?](https://msense.me/python/guides/scratch-to-python/): 블록에서 익힌 변수·조건·반복을 텍스트 코드로 옮겨 봅니다. 완성 게임 전체보다 점수 계산 같은 작은 기능부터 확인하면 전환 부담을 줄일 수 있습니다.
- [파이썬 첫 그림: 거북이로 사각형을 그려 보세요](https://msense.me/python/guides/first-turtle-drawing/): 앞으로 이동하고 90도 회전하는 명령을 네 번 반복하면 사각형을 그릴 수 있습니다. 거리와 각도 중 하나만 바꾸며 결과를 비교해 보세요.
- [게임 만들기에서 변수·조건문·반복문은 어디에 쓰일까요?](https://msense.me/python/guides/game-and-programming/): 체력과 점수는 변수로 저장하고, 조건문으로 규칙을 판단하며, 반복으로 동작을 이어갑니다. 작은 규칙을 실행해 본 뒤 그림과 조작을 연결합니다.
- [파이썬 오류가 났을 때, 마지막 줄부터 읽어 보세요](https://msense.me/python/guides/read-python-errors/): 오류 종류와 마지막 설명을 읽고 표시된 줄 주변을 확인합니다. 이름·기호·들여쓰기 중 원인을 좁혀 한 부분만 고친 뒤 다시 실행하세요.
- [AI가 코드를 쓰는데, 아이는 파이썬에서 무엇을 배울까요?](https://msense.me/python/guides/ai-and-child-thinking/): 무엇을 만들지 정하고, 코드를 작은 부분으로 나누어 이해하고, 결과가 예상과 맞는지 확인하는 힘을 배웁니다. 실행 여부만으로 이해를 판단하지 않습니다.
- [파이썬 자율 학습, 아이가 막히면 어떻게 하나요?](https://msense.me/python/guides/self-paced-feedback/): 아이가 “모르겠어요”라고 할 때 정리할 네 가지 질문, 코드 스튜디오 오류 안내와 과제 피드백의 차이, 부모의 도움 범위를 살펴봅니다.
- [파이썬 과제, 코드 파일과 생각을 함께 남기는 법](https://msense.me/python/guides/submit-code-and-thinking/): 코드 파일과 실행 결과에 하려던 일·바꾼 부분·남은 질문을 함께 남기세요. 결과 이미지 하나보다 다시 실행하고 피드백을 주고받기 좋은 기록이 됩니다.
- [학부모 학습 기록, 접속 시간보다 먼저 볼 것은?](https://msense.me/python/guides/parent-learning-records/): 접속과 제출 기록에 아이의 설명, 코드 수정, 피드백 이후 행동을 함께 보세요. 접속 시간 하나만으로 이해도나 학습 성과를 판단할 수는 없습니다.
- [메타센스 파이썬 7일 무료체험, 신청 전 확인할 것](https://msense.me/python/guides/python-trial-checklist/): 초3부터 참여하는 자율 학습이며 기본 체험은 7일, 정규 수강은 월15만 원입니다. 컴퓨터를 준비하고 신청하면 1일 이내 시작 안내를 받습니다.
