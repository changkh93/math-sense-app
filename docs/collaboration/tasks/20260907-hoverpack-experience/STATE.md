# Hoverpack experience upgrade

- ID: 20260907-hoverpack-experience
- Phase: DONE (local, revised); updated 2026-09-07. 운영 배포·사용자 재평가는 아직 하지 않았다.
- Revision request: 직전 구현의 추종 입자·식별 불가능한 비행체·구체 구름·과장된 고리 때문에 하늘 경험이 좋지 않다는 사용자 평가. 이전 기술 검증은 시각 품질의 합격 근거가 아니므로 완료 판정을 철회한다. 새 기준은 추종 입자/모호한 생물 제거, 부드러운 세계 좌표 구름, 간결한 표식, 절제된 비행 카메라, 해양 회귀 없음이다.
- Original goal: 참고 아이디어를 프로젝트에 맞게 선별해 초보적으로 보이는 호버팩 비행의 시각·탐사 경험을 대폭 개선하되 개발 및 운영 비용을 억제한다.
- Coordinator/owner: Codex, shared checkout의 단독 로컬 구현. 외부 앱 전송 없음.
- Baseline: `440b4a2` (`main`). 시작 시 다른 작업의 미커밋 변경(`functions/`, 크루 UI, 마케팅/협업 문서, `tmp/`)이 있었으며 모두 보존하고 프론티어 관련 파일과 이 기록만 수정한다.
- Acceptance: 호버팩 선택 즉시 이륙; 고도에 따른 명확한 시각/상태 변화; 세 링이 짧은 완결형 항로가 되고 통과가 자동 기록됨; 장비와 추진 불꽃이 기존보다 정교함; 저사양 프리셋을 존중함; 새 유료 에셋·패키지·서버 읽기/쓰기 없음; 탐험/성능 테스트와 브라우저 QA 및 빌드 통과.
- Scope: `frontierExploration.js`, `FrontierExplorationHud.jsx/.css`, `FrontierSkyWorld.jsx`, 신규 순수 모델 `frontierSkyModel.js`, 제한적인 `GalaxyWorld3D.jsx`, 관련 QA/테스트 및 구현 기록.
- Excluded: 태양계 전체 자유비행, 신규 서버 XP/보상 경제, 학습 자격 정책 변경, 친구 흔적/랭킹/멀티플레이 동기화, 운영 배포.
- Revised implementation: 플레이어 추종 입자, 삼각형 SkyRay, 공중 Sparkles, 구체 구름, 추종 지평선, 가이드 리본, 장식용 정거장/워프 게이트를 제거했다. 명암과 네 가지 실루엣을 가진 절차형 구름 텍스처를 세계 좌표의 인스턴스 카드에 적용했다. 대기 그라데이션을 고도에 따라 부드럽게 바꾸고 원경 천체는 하나로 정리했다. 세 항로 표식은 작은 금속 테두리와 얇은 발광선으로 단순화했다.
- Flight/HUD: 호버팩 본체는 유지하면서 추진통 링 방향을 수정하고, 정지/이동/상승에 따라 짧은 주황색 불꽃 출력을 보간한다. 3인칭 FOV는 지상 48 / 공중 정지 52 / 이동 54 / 가속 57로 완만하게 전환한다. 사용자의 줌·회전과 1인칭 FOV는 유지한다. HUD는 실제 높이와 다음 목표를 표시하며 알림은 5초 후 사라진다. 실제로 없는 궤도 시설·해금을 암시하던 안내를 정정했다. 발견 중복 저장과 일시정지 중 발견도 방지한다.
- Cost/development: 외부 이미지/3D 모델, 신규 패키지, 서버 API, Firestore 읽기·쓰기, 신규 XP/보상 원장 없음. 구름은 저사양/균형/고화질 12/18/24 카드, 24/36/48 삼각형, 전체 1 draw call이다. 텍스처는 저사양·균형 128 KiB / 고화질 512 KiB, 최초 한 번 생성하고 해제한다. 로컬 Node 표본 생성 시간은 작은 텍스처 31ms, 큰 텍스처 83ms였으며 실제 저사양 PC 성능 보장이 아니다. 프레임마다 노이즈 생성·React 상태 갱신은 하지 않는다.
- Verification: 탐험, 캐릭터 동작, 성능, 포인터락, 해양 테스트 통과. 구름 아틀라스의 결정성/투명 경계/밀도와 프리셋 개수, 카메라 상태별 FOV, 잘못된 고도 입력 회귀 테스트 추가. 관련 ESLint 오류 0(기존 seed 경고 1개), 프로덕션 빌드 통과. 브라우저에서 균형 고도 7/15, 저사양 고공 좌우 이동, 즉시 이륙, V 전환, 안전 귀환, 일시정지, 1인칭 잠수와 해양 생물 화면을 확인했다. 수중에서 구름이 보이던 회귀를 발견해 전체 하늘 그룹을 수중 카메라에서 숨기고 재확인했다. 최종 QA 세션 오류 로그 없음. 전체 FPS·GPU 비용 전후 수치는 측정하지 않았다.
- Decision: 참고안의 태양계 전체 자유비행·서버 XP·랭킹은 비용과 정책 복잡도가 커서 제외했다. 현재 Explorer XP는 학습 누적 원장에서 파생되므로 클라이언트 비행 행동으로 임의 증가시키지 않았다.
- Remaining limits: 운영 배포 및 실제 학생 계정/저사양 물리 기기 장시간 측정은 하지 않았다. 음향의 고도별 재믹스와 서버 보상/학습 해금은 별도 정책 설계가 필요하다.
- Next: 사용자 승인 범위의 운영 배포 전 실제 기기 점검. 사용자에게 필요한 외부 결과 없음.
