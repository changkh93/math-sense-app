## 상품군별 역할과 구매 이유

### 종이책·카드: 신뢰와 주력 매출

우선상품 분수세트. 분수편 리뷰를 분수세트의 리뷰처럼 옮겨 쓰지 않는다. 동일 시리즈 리뷰를 인용할 경우 해당 상품/출처를 명확히 구분한다.

첫 화면은 실제 구성(책2권+카드), 추천 학습 상황, 활용방법을 보여준다. 예: ‘분수 계산 전에, 그림과 카드로 분수의 뜻부터.’ 대상 학년은 실제 내용과 맞춰 확인하고 확정한다. 실제 내지2~3장과 카드활동30~60초 시연, 2주 활용표를 제시한다. 계산속도/성적 향상을 입증 없이 보장하지 않는다.

분수편 단독과 카드포함 세트 비교표를 넣고 상품간 이동을 돕는다. 기존 확인가격은 분수편19,600원/배송3,000원/20,000원 이상무료, 세트32,600원이다. 단독책 결제총액22,600원과 세트 결제총액을 최신 배송조건으로 확인해 선택을 설명한다. 가격·배송 변경은 이 계획에서 실행하지 않는다.

### PDF전자책: 형식의 편리함과 구체적인 학습 용도

첫 화면에 ‘PDF파일·종이책 배송 없음’을 표시하고, 실제 샘플3쪽으로 글씨크기·문제/활동형태를 확인하게 한다. 곱셈을 첫 시험상품으로 선정한다. 활용 제안은 ‘구구단을 외우기 전에 같은 수 묶기와 배열을 살펴보는 활동’처럼 실제 내용과 맞춰 쓴다.

페이지수, 권장 출력방식, 태블릿 사용가능여부, 전달시간을 파일검증 후 표시한다. 개인/가정 이용과 교실 복사권은 구분하며 교실용 라이선스는 새 상품 제안일 뿐 아직 제공하거나 가격을 정하지 않았다. 샘플→단품→필요하면 묶음의 순서로 시험한다. 묶음이 실제로 유리한지 현재 단품가격과 구성부터 확인한다.

### 고전 영상: 깊이를 체험하고 완주를 돕는 수업

우선 오뒷세이아1개에 집중. ‘영화에서 생긴 궁금증을 원작 읽기로 이어가는18강+워크북’이라는 소구를 사용한다. 국내최고/최장시간 등 비교검증 안 된 최상급 표현은 쓰지 않는다. 영화공식제휴로 오해시키는 표현도 쓰지 않는다.

기존 강의 중 자체 권리를 가진 구간으로5~10분 샘플1개, 30~60초 짧은영상2개, 워크북 샘플3쪽을 준비한다. 35시간은 깊이의 근거지만 학습부담도 있으므로 ‘첫 주 읽을 범위/영상 구간/질문1개’를 알려준다. 총 학습량을 숨기거나 짧게 완강된다고 약속하지 않는다. 현재9,900원은 입문판매시험으로 평가하고 다른 영상7개까지 일괄할인하지 않는다.

수학과 고전 고객은 관심이 다르므로 같은 홍보글·광고그룹에 섞지 않는다. 수학고객에게는 다음 학습주제, 고전고객에게는 다음 작품을 제안한다.

## 검색과 광고

상품정보의 일관성, 실제 검색연동 상태, 검색어별 노출·방문을 먼저 확인한다. 제목은 실제 상품명+주제+형식+핵심구성으로 간결하게 쓰며 관련 없는 인기어를 나열하지 않는다. 태그는 내용과 맞는 보조정보로 사용한다. 광고노출과 자연검색순위를 분리 측정하고 광고지출로 자연순위가 보장된다고 말하지 않는다.

네이버 공식FAQ1310은 도서 카테고리가 일반 쇼핑검색광고-쇼핑몰 상품형 등록 제한 대상이라고 명시한다. ADVoost 쇼핑 경로는 별도 가능성을 안내하지만 계정·상품심사·예산조건 확인이 필요하다. FAQ1082는 스마트스토어를 파워링크 연결페이지로 사용할 수 있다고 안내한다. 개별영상의 등록정합성과 심사통과까지 보장하는 내용은 아니다.

현재30,000원은 오뒷세이아7일시험 전용 승인 예산. 다른상품으로 전용하거나 증액하지 않는다. 실제 시작일 기준7일, 일3500원, 수동100원, 일치검색으로 시험하되 시작 전 기존캠페인/그룹 저장상태·중복·기간·자동충전·연결URL·심사상태 확인 필요. 7일일예산 합24,500원, VAT별도 보수계산26,950원. 일예산은 절대상한이 아니므로 누적총과금과 지연과금까지 확인하는 운영이 필요하다. 자동감시는 설정하지 않았다.

광고가 승인·노출된 뒤 판단한다. 노출없음은 기간/심사/검색수요/입찰 문제부터, 클릭없음은 검색어/문구부터, 클릭후구매없음은 샘플/가격/상세/전달조건부터 점검한다. 각각을 혼동해 곧바로 가격을 내리지 않는다.
