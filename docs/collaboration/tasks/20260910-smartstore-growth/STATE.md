- 이름·이메일·휴대폰 입력 재시도 정상 성공(이번 자동검토 차단 없음). 인증 요청 버튼 활성화 확인. 비밀번호/인증번호 입력 및 가입 제출 안함. 사용자가 영문숫자8자이상 새 비밀번호2회, 휴대폰 인증 요청/확인, 필수약관 동의 후 다음을 진행하도록 안내. 선택 마케팅 동의 불필요.
- 본인 인증 후 쇼핑몰 정보 및 지정3개 상품 설정 재개 필요. 실제 구독 결제/배너 적용은 아직 미완료.
