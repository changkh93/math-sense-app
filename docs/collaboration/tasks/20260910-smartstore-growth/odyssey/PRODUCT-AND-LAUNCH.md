배송·인쇄비0원이라도 매출 전액이 광고 손익분기액은 아니다. 할인 후 실제 정산액에서 결제/플랫폼수수료, 해당되는 세금과 주문당 추가비용을 차감해 공헌이익을 확정한다. 첫 시험은 전환1건의 정확한 유입 확인을 우선하며, 소수 주문만으로 광고효과를 확정하지 않는다. 원래구매/광고유입/귀속주문을 혼동하지 않는다.

## 이번 단계의 남은 입력

1. Chrome 수정 화면 연결 복구. 현재 브라우저목록 시간초과, native 앱은 화면캡처 불가 상태.
2. 광고예산/할인제안 승인 여부. 질문 발송했지만 아직 답변 없음.
3. 영상 이메일 전달 기한·수강기간·실물교재 포함 여부·PDF 이용범위. PDF 이메일전달만 확정.
4. 현재 오디오북분류의 영상강좌 정정 경로. 최초 대분류 변경이 제한되면 네이버 확인 필요. 이 영상 관련 별도 고객센터 문의는 아직 발송 승인받지 않았고 미발송.
