## 기존 페이지에서 개선한 문제

- 추상적인 교육철학과 긴 설명이 먼저 나와 상품의 구체적인 학습 경험을 파악하기 어려웠다.
- 책 2권과 카드 포함 세트의 구성 차이가 충분히 빠르게 드러나지 않았다.
- 세트 기존 구성 이미지에 있던 분수 사칙연산 카드 4쪽 인쇄물을 텍스트 구성표에도 명확히 반영했다.
- 카드 단독 상품 리뷰에 처음에는 부모도 사용법을 익혀야 한다는 의견이 있었다. 이를 반영해 카드 두 장 고르기 → 전체 테두리 맞추기 → 칸 세기 → 책에 쓰기로 안내했다.

## 실제 반영한 상세설명

공통 디자인은 최대 848px, 본문 20px/행간 1.85, 큰 제목과 섹션별 여백, 남색·연한 청색·크림색 배경으로 구성했다. HTML 작성란에 본문 요소와 인라인 스타일만 입력했다. meta/style 문서 헤더를 입력하지 않았다.

### 책 2권

첫 문구: **분수의 ‘왜?’를 / 그림으로 이해하는 시간**

상품 구성 → 1/2=3/6 비교 도식 → 실제 카드 활용 본문 → 덧셈·뺄셈/곱셈/나눗셈 예시 → 두 권의 학습 흐름 → 집에서 시작하는 세 단계 → 적합한 학습자 → 책/세트 비교 → 구매 전 질문 순서.

실물 분수카드 미포함을 상단에 표시했다. 실물 카드 사용을 원하는 구매자에게 분수세트로 연결하는 버튼을 넣었다. 기존 책 실물 사진과 실제 1권 카드 활용 문제 이미지를 재사용했다.

### 분수세트

첫 문구: **겹쳐 보는 순간, / 분수의 관계가 보입니다.**

구성은 종이책 1·2권, 파파스 분수카드 1세트, 분수 사칙연산 카드 4쪽 인쇄물로 명시했다. 종이카드와 투명카드를 직접 겹치는 경험, 실제 카드 사진, 부모님이 처음 사용하는 방법을 강조했다. 카드가 이미 있거나 책 중심으로 학습하려는 고객에게 책 2권 상품으로 연결했다.
