# 둘시네 재점검과 주문 회복 실행안

2026-09-11 저녁 스마트스토어 관리화면과 로그인된 PC 네이버 도서 검색을 직접 확인했다. 순위는 이 시점·검색어·지면의 관측값이며 모든 사용자에게 동일한 순위를 보장하지 않는다.

## 핵심 판단

신규주문 0은 현재 판매관리 상태다. 별도의 9/10 판매성과에는 방문62·상품결제5·매출45,700원·구매전환8.1%가 있다. 오늘 전체 주문이 0건인지, 신규고객이 0명인지와는 구분해야 한다. 과거 30일 매출 하락은 실제 문제지만 거래 전체가 중단된 것은 아니다.

최근30일 방문 리포트(8/12~9/10)는 방문254·귀속 상품결제15·매출250,300원·전환5.9%였다. 판매 리포트와 집계 기준이 다르므로 전체 매출로 치환하지 않는다. 운영자 작업에 따른 방문 포함 여부 및 신규고객 수는 미확인이다.

브랜드 수학감각을 분수편2권·분수세트·덧뺄셈·수세기 4개에 입력하고 저장값 확인. 제조사/대상연령/교육속성은 근거 없이 채우지 않았다. 주요정보 검토대상15개는 모두 읽었지만 전부 수정 완료한 것은 아니다. 나눗셈PDF, 카드3종, 영상7종 등의 브랜드/제조사와 일부 속성은 추가 확인 대상이다. 주요정보 권고는 필수 수정이나 상위노출 보장이 아니다.

## 우선순위와 7일 실행안

### 1. 현재 구매가 발생하는 수학 상품을 우선 노출

- 검색 복구 대기 중인 분수세트를 기다리는 동안 검색 가능한 분수편2권과 소수PDF를 대표 진입상품으로 활용한다.
- 분수편 상세 첫화면: ‘분수의 뜻부터 사칙연산까지, 종이책 2권으로 차근차근.’ 실제 내지2~3장, 책2권/책+카드 비교, 현재 배송 포함가격을 같은 화면에서 제시한다.
- 세트는 ‘교재로 익히고 카드로 설명해 보기’에 집중. 복구 요청은 이미 3건 접수중이며, 다음 영업일 담당부서의 구체적인 대분류 정정 경로를 확인한다. 기존 리뷰/상품번호는 유지한다.
- 소수PDF는 3쪽 실제 샘플, 출력 가능 범위, 전달시간, PDF형식과 서점 전자책의 차이를 먼저 보여준다. 할인부터 시행하지 않는다.

### 2. 관심고객에게 구체적인 이유로 재방문 기회 제공

알림고객987명은 잠재 자산이다. 다만 수학·고전 관심을 구분하고 광고성 수신 동의·실제 대상·무료발송 한도를 확인해야 한다. 발송은 아직 하지 않았으며 사용자 승인이 필요하다.

수학 메시지 초안:
‘분수 계산 전에, 분수의 뜻부터 다시 살펴보세요. 수학감각 종이책 2권과 카드 포함 세트의 차이를 정리했습니다. 아이에게 맞는 구성을 확인해 보세요.’
연결은 분수편 상세1개. 확정되지 않은 할인·무료자료를 약속하지 않는다. 샘플을 실제 게시한 뒤 샘플 소구 문구로 개선한다.

고전 메시지는 오뒷세이아 공개 체험강의와 워크북 샘플 준비 후 고전 관심대상에게만 별도 제안한다. 987명 전원 일괄 발송은 제안하지 않는다.

### 3. 강좌는 체험과 전달 신뢰를 먼저 개선

‘35시간’만 강조하면 부담이 될 수 있다. 첫 수강 10분의 볼거리, 읽기 범위, 워크북 질문1개를 소개한다. 이미 공개된 강의11/18의 실제 URL과 이용권한을 확인하여 샘플로 연결하고, 비공개 재생목록을 공개하지 않는다. 이메일 수신 방법·1일 내 전달·평생시청·문의처를 구매 전 확인할 수 있게 한다. 샘플 영상/자료의 실제 게시와 모바일 검수는 아직 미완료다.

### 4. 광고 확대보다 기존 30,000원 시험의 검증

오뒷세이아 소재는 앞서 표시URL 문제 정정 후 심사중이었다. 승인/실노출/귀속주문을 확인한 뒤 평가한다. 승인된 예산을 수학광고에 임의 전용하지 않는다. 도서 광고는 상품형별 취급 제한이 다르므로 쇼핑광고를 당연히 실행할 수 있다고 가정하지 않는다.
