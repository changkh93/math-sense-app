# Parent Dashboard 실시간 연동 현황 및 트러블슈팅 (2026-04-01)

학부모 대시보드에서 자녀의 학습 활동(특히 미완료 동영상)이 실시간으로 반영되지 않는 문제에 대한 현재까지의 수정 내역과 기술적 분석을 정리합니다.

## 1. 현재 적용된 시스템 구조

### 1-1. 실시간 데이터 스트리밍 (`useLearningHistory` 훅)
기존의 일회성 데이터 호출 방식이 아닌, Firebase의 `onSnapshot` 리스너를 통해 5개 컬렉션을 실시간으로 감시합니다.
- `history`: 완료된 퀴즈/영상 기록
- `crystal_transactions`: 보상 획득 기록
- `activityLogs`: 단순 활동 로그
- `assignments`: 과제 제출 현황
- `learning_progress` (LP): **[핵심]** 퀴즈 진행 중 상태 및 동영상 시정 시간(초 단위)

### 1-2. 데이터 통합 및 중복 제거 (Aggregation)
각 소스에서 들어온 데이터를 타임라인 형태로 병합하며, 중복을 제거합니다.
- 영상의 경우: `history`(완료)에 데이터가 있으면 `lp`(진행 중) 데이터보다 우선순위를 가집니다.
- 단, 한 단원에 여러 영상(`transmissionId`)이 있는 경우 각각 독립적으로 추적하도록 개선되었습니다.

---

## 2. 최근 수정 사항 (v1.2 ~ v1.3)

### 2-1. 미완료 동영상 반영 로직 강화
- 영상 시청 중 "오늘은 여기까지"를 누르거나 창을 닫으면 시청한 시점까지의 `stampedSeconds`와 `updatedAt`이 Firestore에 저장됩니다.
- 대시보드는 이를 감지하여 **"🎬 영상 학습 진행: [제목]"** (시청 시간 표시) 항목을 타임라인에 즉시 추가합니다.

### 2-2. UI 개선 (점수 표시 및 시정 시간)
- **오류 수정**: 동영상과 데이터 로그 활동에서 의미 없는 "점수: 100점"이 표시되던 문제를 수정했습니다.
- **정보 추가**: 동영상 활동의 경우 점수 대신 **"시청 시간: X분 Y초"**가 표시됩니다.
- 점수는 오직 **현장 탐사(퀴즈)** 활동에서만 나타납니다.

## 3. 남아있는 문제 및 기술적 가설

사용자가 "오늘은 여기까지"를 눌러도 대시보드에 **전혀 반영되지 않는 현상**에 대해 다음의 기술적 원인을 추정하고 있습니다.

### 가설 A: Firestore 로컬 스냅샷의 `serverTimestamp()` 지연
- **원인**: `MissionHub`에서 저장 시 `serverTimestamp()`를 사용하는데, 데이터가 저장되자마자 발생하는 로컬 스냅샷에서는 이 값이 잠시 `null`로 보일 수 있습니다.
- **현상**: `useLearningHistory` 훅이 `updatedAt`이 `null`인 문서를 "오늘의 활동"이 아닌 것으로 간주하여 필터링해버렸을 가능성이 큽니다.
- **대책**: `updatedAt`이 `null`인 경우(로컬 쓰기 진행 중) 현재 시각으로 간주하여 처리하도록 로직 보강이 필요합니다.

### 가설 B: 시간대(Timezone) 필터 불일치
- **원인**: 클라이언트 장치의 로컬 시각과 Firestore 서버 시각의 미세한 차이로 인해, 밤 12시 근처에서 데이터가 어제의 시각으로 분류될 수 있습니다.
- **현상**: 데이터는 저장되었으나 대시보드가 "오늘"로 인식하는 밤 12시 이전/이후 범위에서 벗어남.

### 가설 C: `onNonQuizActivityComplete`의 사이드 이펙트
- **원인**: "오늘은 여기까지" 클릭 시 `lp` 문서 저장과 별개로 `onNonQuizActivityComplete`가 호출되어 `history` 등에 빈 기록을 남길 수 있습니다.
- **현상**: 이 빈 기록이 중복 제거 로직에서 `lp`의 실제 진행 데이터를 가릴 위험이 있습니다.

## 4. 내일의 체크리스트

- [ ] `useLearningHistory.js`에서 `updatedAt`이 `null`일 때 `new Date()`를 대용하여 로컬 업데이트를 즉시 반영하는지 검증.
- [ ] 브라우저 개발자 도구의 Network 탭에서 `setDoc` 요청이 실제로 성공적으로 나가는지 확인.
- [ ] 학부모 대시보드 상단에 표시되는 `오늘의 학습 (YYYY-MM-DD)` 기준일자와 실제 데이터의 일자가 일치하는지 재확인.
