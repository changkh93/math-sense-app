# 메타센스 숏폼 홍보 영상 패키지

## 1. 영상 전체 스크립트

총 길이: 42초  
비율: 9:16 세로형  
해상도: 1080x1920  
톤: 빠른 SNS 밈 광고, 코믹한 말풍선, 짧은 자막, 친근한 가족 공감

0-6초: 부모의 잔소리 말풍선이 화면에 쏟아진다. 아이는 책상 앞에서 지친 표정이다.  
부모: "숙제했어?" "문제 풀었어?" "틀린 거 다시 봤어?" "공부 좀 해라!"  
아이: "아... 또 시작이야..."

6-12초: 화면이 멈추고 잔소리 말풍선이 떨어진다.  
자막: "냅둬유."  
자막: "스스로 알아서 하게."  
부모: "냅두라고요?"  
내레이션: "진짜 공부는, 시켜서 하는 게 아니라 스스로 움직일 때 시작됩니다."

12-20초: 메타센스 앱 화면이 등장한다. 아이가 문제를 풀고, 오답 피드백을 보고, 힌트와 다시 도전을 선택한다.  
자막: "그래서, 메타센스."  
내레이션: "메타센스는 아이가 문제를 풀고, 틀리고, 다시 생각하고, 스스로 이해하게 돕는 학습 플랫폼입니다."  
자막: "정답만 알려주는 공부? 아니요."  
자막: "정답만 알려주는 공부가 아니라, 생각하게 만드는 공부."

20-30초: 처음엔 억지로 하던 아이가 점점 몰입한다.  
아이: "어? 왜 틀렸지?" "아하! 이거였네!" "한 문제만 더!"  
부모: "어... 내가 안 시켰는데?"  
자막: "시키는 공부 말고, 스스로 하는 공부."  
내레이션: "메타센스는 아이에게 답을 떠먹여 주지 않습니다. 스스로 생각하는 힘을 키웁니다."

30-37초: 가족 반응 컷. 부모는 놀라고 아이는 집중한다.  
부모: "우리 애가... 스스로 공부를?"  
아이: "쉿. 지금 집중 중이야."  
자막: "냅둬유. 스스로 크는 중이니까."

37-42초: 브랜드 엔딩.  
자막: "아이의 공부 감각을 깨우다"  
자막: "메타센스"  
자막: "msense.me"  
내레이션: "공부하라고 말하기 전에, 스스로 하게 만들어 주세요. 메타센스."  
마지막 문구: "냅둬유, 메타센스가 생각하게 합니다."

## 5. 필요한 이미지/영상 소스 목록

이번 버전은 저작권 리스크를 줄이기 위해 외부 촬영 영상이나 스톡 이미지를 쓰지 않는다. Remotion 코드로 아래 에셋을 직접 그린다.

- 부모 캐릭터: React/CSS 도형
- 아이 캐릭터: React/CSS 도형
- 책상/종이: React/CSS 도형
- 말풍선: React/CSS 도형
- 메타센스 퀴즈 앱 화면: React/CSS 도형
- 배경 패턴: React/CSS 도형
- 효과음: FFmpeg로 생성한 로컬 WAV 파일

향후 실사 버전으로 확장할 경우 필요한 촬영 소스:

- 책상 앞에서 지친 아이 컷
- 부모가 뒤에서 말하는 컷
- 아이가 태블릿/노트북으로 퀴즈 푸는 컷
- 부모가 놀라며 뒤로 물러나는 컷
- 메타센스 실제 UI 캡처 또는 데모 녹화

## 8. FFmpeg 최종 mp4 렌더링 명령어

Remotion 원본 렌더:

```bash
npx remotion render video/index.jsx MetasenseShort out/metasense-promo-raw.mp4 --codec=h264 --pixel-format=yuv420p
```

SNS 업로드용 최종 압축:

```bash
ffmpeg -y -i out/metasense-promo-raw.mp4 -vf "scale=1080:1920:flags=lanczos,fps=30" -c:v libx264 -profile:v high -level 4.1 -pix_fmt yuv420p -crf 18 -preset medium -movflags +faststart -c:a aac -b:a 192k out/metasense-promo-final.mp4
```

로컬 시스템 음성으로 내레이션 생성:

```bash
say -v Yuna -r 184 -f public/metasense-promo/voiceover.txt -o public/metasense-promo/voiceover.aiff
```

효과음과 내레이션 믹싱:

```bash
ffmpeg -y -i out/metasense-promo-final.mp4 -i public/metasense-promo/voiceover.aiff -filter_complex "[0:a]volume=0.72[base];[1:a]adelay=6000|6000,volume=1.05[vo];[base][vo]amix=inputs=2:duration=first:dropout_transition=0[a]" -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k out/metasense-promo-final-voice.mp4
```

썸네일 추출:

```bash
ffmpeg -y -ss 00:00:08 -i out/metasense-promo-final.mp4 -frames:v 1 out/metasense-thumbnail.png
```
