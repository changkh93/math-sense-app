# 프론티어 비행·해양 탐험 구현 기록

2026-09-06. 로컬 구현 및 검증 완료. 운영 배포 전.

## 이용 방법

- 탐험 화면 왼쪽의 **장비**에서 산책 / 호버팩 / 잠수복을 선택한다. 기본 장비는 무료이며 세션 동안 사용한다.
- 호버팩: 이륙 버튼 또는 H. Space로 상승, C로 하강. 입력을 놓으면 정지 비행한다. 다시 H를 누르면 현재 위치에서 완만하게 내려온다.
- 조감: 조감 버튼 또는 B. 드래그 회전, 휠 줌, 다시 B로 캐릭터 시점 복귀. 조감은 캐릭터 이동·보상 획득과 독립적이다.
- 물에서는 장비 없이 수면 수영한다. 잠수복은 오리발·탱크 외형과 더 빠른 수중 이동, 상승·하강 기능을 제공한다.
- 동쪽 섬 바깥 바다의 산호 군락에 6종, 총 24마리 물고기가 있다. 가까이 접근하면 관찰 기록 버튼이 나타난다.
- 도감은 사용자 키별로 **현재 브라우저**에 저장한다. 새로고침 후 기록을 복원한다. 서버 재화·희귀 보상을 지급하지 않는다.
- 안전 귀환은 마지막으로 확인된 지상 위치로 돌아간다. 일반 착륙과 구분한다. 장비 해제는 공중에서는 완만한 착륙, 물속에서는 수면 수영으로 전환한다.
- 모바일은 조이스틱과 상승/하강 누름 버튼을 사용한다. 포인터 취소·포커스 상실·일시정지 시 입력을 해제한다.

## 구현 범위

기존 지상 점프·계단 로직을 유지하면서 비행 / 착륙 / 수영 / 잠수의 수직 이동 해결기를 분리했다. 4cm 이하 수직 소단계 충돌로 얇은 천장 통과를 방지한다. 수평 이동은 기존 소단계와 벽 미끄러짐을 사용하되 비행 높이를 보존한다. 시설·자연물 충돌은 높이를 고려하고, 물 진입을 막던 강의 보행 장벽은 수영 상태로 대체했다.

비행 상한 18, 해저 -3.6, 탐험 반경은 섬 반경+6과 31 중 작은 값이다. 기존 RTDB 좌표 범위를 유지한다. 바다 수면을 양면 반투명으로 만들고 해저·산호·수중 안개·보조광·수중 카메라 거리를 추가했다.

물고기 모델은 공통 지오메트리와 InstancedMesh 한 개를 사용한다. 유영은 로컬 계산이며 위치를 서버에 전송하지 않는다. 기존 위치 변화 임계값과 전송 간격을 유지하고 equipment/movementMode 변경만 추가로 감지한다.

원격 캐릭터에도 장비 외형을 표시한다. 기존 rules 파일은 y/scale을 허용하지 않는 상태였으므로 범위를 명시하고 장비·이동 상태는 허용 목록으로 검증했다. 구형 클라이언트의 해당 필드 생략도 지원한다. 근접 상호작용·픽업 및 서버 대화 거리에 높이를 반영했다.

## 검증

- `npm run test:frontier-exploration`: 비행 상한·정지·일시정지·충돌·착륙·수영·잠수 바닥·물 경계·관찰 거리.
- `npm run test:astra-builder`, `npm run test:galaxy-terrain`, `npm run test:galaxy-navigation`: 기존 동작 회귀.
- `node --test functions/galaxyGame.builder.test.cjs functions/galaxyGame.live.test.cjs functions/galaxyGame.worldObject.test.cjs`: 서버 회귀.
- `npm run test:astra-builder:performance`: 500/1,000/2,500부재 CPU 벤치마크 통과. 실제 휴대폰 GPU FPS와 구분한다.
- `npm run build`: 프로덕션 번들 생성 통과. 기존 500KB 초과 청크 경고는 남아 있다.
- 변경 코드 ESLint: 오류 없음. 기존 GalaxyWorld3D의 seed 의존성 경고 1개는 별도 사항이다.
- 실제 브라우저: 장비 장착 → 이륙 → 조감, 추가 상승 → 완만한 착륙 → 지상 복귀, 수영 → 잠수복 → 하강, 수중 일시정지 → 안전 귀환, 도감 기록 및 재로드 복원을 확인했다.
- 390×844 화면에서 장비·조감·도감과 조이스틱 노출을 확인하고, 미니맵 크기를 줄였다. 실제 터치 기기 장시간 조작과 다중 사용자 운영 부하 측정은 후속 검증이다.
- 로컬 RTDB 에뮬레이터에서 정상 비행/착륙/잠수 저장, 구형 필드 생략, 잘못된 좌표·장비·상태·타인 쓰기 거절을 확인했다. 의도적 거절 테스트의 permission_denied 로그는 정상 결과다.

## 로컬 QA

`npm run dev -- --host 127.0.0.1` 실행 후 `/dev/frontier-exploration`에서 같은 GalaxyWorld3D를 테스트한다. 산호 위치 이동과 1초 상승/하강 입력 버튼은 개발 모드에서만 활성화되며 운영 라우트에는 포함되지 않는다.

권한 테스트는 로컬 RTDB 에뮬레이터를 실행하고 다음 명령을 사용한다.

```sh
FIREBASE_DATABASE_EMULATOR_HOST=127.0.0.1:9009 node scripts/test-frontier-presence-rules.mjs
```

테스트는 demo-frontier 네임스페이스만 사용하고 127.0.0.1 이외의 호스트를 거절한다. 최신 firebase CLI는 Java 21을 요구하지만 이 환경은 Java 17이므로 이미 설치된 RTDB emulator v4.11.2 JAR를 직접 실행해 검증했다.

## 운영 반영 순서와 후속 범위

1. `database.rules.json`을 먼저 반영한다. 새 클라이언트는 장비/상태 필드를 전송하므로 구형 규칙만 남으면 위치 갱신이 거절된다.
2. `sendGalaxyWorldSpeech` 서버 함수의 높이 기반 거리 검증을 반영한다.
3. 웹 번들을 반영하고 방문자 간 위치·장비 표시와 저장 오류를 관찰한다.

이번 구현은 계획서의 비행·조감·수영·잠수·초기 생태계에 해당한다. 설계도 공유·대칭/영역 건축 도구, 서버 도감과 보상, 수족관 가구, 심해·동굴, 공유 물고기 포획, 유료 장비/인벤토리 영속화, 운영 비용 대시보드는 아직 구현하지 않았다. 기본 장비의 무료 제공과 로컬 도감은 이 단계의 명시적 제품 정책이다.


## 예기치 않은 수동 종료 수정

마우스 잠금 해제를 Escape에 의한 종료 의사로 추정하던 Astronaut의 이벤트 처리 때문에 UI 조작이나 브라우저 상태 변화가 `manual_exit`으로 이어질 수 있었다. 잠금 이벤트에서 세션 종료 콜백으로 이어지는 경로를 제거했다. 이제 잠금 해제는 카메라/이동 입력만 초기화한다. Esc는 장비·도감 등 열린 패널을 한 단계씩 닫거나 커서를 해제하며, 수동 세션 종료는 명시적인 귀환 버튼으로만 실행한다. 시간·유휴·연결 만료 정책은 변경하지 않았다.

`npm run test:frontier-pointer-lock`은 정상/비정상 잠금 해제, 포커스 상실, 이벤트 재등록/해제, 입력 초기화 및 종료 경로의 분리를 검증한다. 브라우저에서는 잠수복 선택→도감 열기→Esc로 도감 닫기→Esc로 장비 패널 닫기→추가 Esc 이후에도 탐험이 유지됨을 확인했다.
