# 메타센스 브랜드 필름: 재구성 인터뷰

## 1. 90초 브랜드 필름 전체 대본

형식: 16:9 영화형 브랜드 필름  
톤: 학부모 고민을 바탕으로 재구성한 인터뷰형 영상  
고지: 실제 후기처럼 보이지 않도록 첫 장면에 "학부모 고민을 바탕으로 재구성한 인터뷰형 브랜드 필름"을 표시한다.

0-10초  
검은 화면에서 조용한 집 안 소리, 낮은 피아노. 식탁 위 문제집, 지워진 연필 자국, 닫힌 방문.  
자막: "아이에게 공부하라고 말하는 일이... 언제부터 이렇게 어려워졌을까요."  
인터뷰: "공부를 안 하는 아이는 아닌데요... 혼자서는 안 해요."

10-35초  
여러 학부모의 짧은 증언. 얼굴을 정면으로 소비하지 않고 손, 시선, 문제집, 침묵을 섞는다.  
인터뷰: "수학 문제만 보면 표정이 딱 굳어요."  
인터뷰: "틀리면 다시 생각하는 게 아니라, 그냥 덮어버려요."  
인터뷰: "학교 가기 싫다고 말한 날도 있었어요."  
인터뷰: "퇴근하고 오면 저도 지쳐 있는데, 또 공부 얘기를 하게 돼요."

35-50초  
닫힌 방문과 식탁. 부모의 말이 잔소리가 되는 순간을 보여준다.  
자막: "공부는 해야 하는데, 아이 마음은 점점 멀어지고."  
자막: "부모의 말은 잔소리가 됩니다."  
인터뷰: "저도 잔소리하고 싶어서 하는 게 아니거든요. 불안해서 하는 거죠."

50-65초  
조금 따뜻한 빛. 부모의 깨달음.  
인터뷰: "제가 더 세게 말하면 될 줄 알았어요."  
인터뷰: "그런데 아니더라고요."  
자막: "아이에게 필요한 건 더 많은 지시가 아니라, 다시 생각해볼 수 있는 시간."

65-78초  
메타센스가 조용히 등장한다. 아이가 틀린 문제를 다시 열고, 힌트를 보고, 다시 도전한다.  
자막: "시키는 공부에서, 생각하는 공부로."  
내레이션: "메타센스는 아이에게 정답을 떠먹여 주지 않습니다. 스스로 생각하고, 다시 보고, 도전하게 합니다."

78-88초  
아이가 작은 목소리로 다시 움직인다.  
아이: "잠깐만... 왜 틀렸지?"  
아이: "아, 이거 다시 해볼래."  
아이: "엄마, 나 이거 하나만 더 하고."  
인터뷰: "처음엔 별거 아닌 줄 알았어요. 그런데 아이가 다시 보더라고요."

88-90초  
부모가 문 앞에서 멈춘다.  
자막: "냅둬유. 스스로 알아서 하게."  
내레이션: "방치가 아닙니다. 아이 안의 생각하는 힘을 믿는 것입니다."  
엔딩: "시키는 공부 말고, 스스로 생각하는 공부. 메타센스. msense.me."

## 9. 카메라 움직임 지시

- 낮은 조도에서 천천히 밀고 들어가는 슬로우 푸시인
- 정면 인터뷰보다 옆모습, 손, 시선, 침묵을 우선
- 문제집과 연필 자국은 얕은 심도로 촬영
- 닫힌 방문은 고정 프레임으로 오래 버틴다
- 메타센스 화면은 기능 소개가 아니라 아이 손의 움직임 뒤에 조용히 등장
- 엔딩은 부모가 문 앞에서 멈춘 뒤 카메라가 더 들어가지 않는다

## 10. 표정과 연기 지시

- 학부모: 피곤함, 미안함, 불안함, 답답함, 조심스러운 희망
- 아이: 무기력함, 긴장, 회피, 이후 조용한 집중
- 웃음은 거의 쓰지 않는다
- 감동 연기를 하지 않는다
- 한숨과 침묵을 장면으로 인정한다

## 11. 음악/효과음 지시

- 초반: 낮은 피아노, 방 안의 공기음, 종이 소리
- 중반: 낮은 피아노 위에 따뜻한 스트링이 아주 천천히 들어온다
- 후반: 해소감은 만들되 과하게 밝아지지 않는다
- 효과음: 연필, 페이지 넘김, 키보드 클릭 정도만 사용
- 과장된 전환음, 팝업음, 광고식 히트음 금지

## 12. 필요한 영상 소스 목록

현재 Remotion 버전은 저작권/허위 후기 리스크를 줄이기 위해 실사 스톡 대신 영화적 그래픽 재구성으로 제작했다. 실사 촬영 확장 시 필요한 소스:

- 밤 거실 식탁 위 문제집
- 지워진 연필 자국과 지우개 가루
- 닫힌 아이 방문
- 학부모의 손과 옆얼굴
- 아이가 문제를 다시 보는 뒷모습
- 태블릿/노트북의 메타센스 화면
- 문 앞에서 멈추는 부모의 뒷모습

## 15. FFmpeg 렌더링 명령어

Remotion 원본 렌더:

```bash
npm run video:render:docu
```

업로드용 최종 압축:

```bash
ffmpeg -y -i out/metasense-docu-brand-film-raw.mp4 -vf "scale=1920:1080:flags=lanczos,fps=30" -c:v libx264 -profile:v high -level 4.1 -pix_fmt yuv420p -crf 18 -preset medium -movflags +faststart -c:a aac -b:a 192k out/metasense-docu-brand-film-final.mp4
```
