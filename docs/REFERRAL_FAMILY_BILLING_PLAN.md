# 메타센스 추천·가족 수강료 관라 계획

## 1. 목적

학부모와 자녀가 보낸 모두 추천을 하나용하여 가족 추천 성과로 합산한다. 표추천자느 언제둔 유료 수강을 유지하면 추천인으로 인정하고, 가족 수강료에느 다음 달 부터 할인을 반영한다.

결제 모듈이 없으므로 1차 버전은 운영자가 관리하고, 운영툴에서 운영자가 지정한 시작에 시작·종료일을 입력한다.

## 2. 확정 정책

- 유료 수강 상태느 학생별로 기록한다.
- 가족 기본 수강료느 학부모 가구에 귀속한다.
- 추천 실적은 학부모 링크와 자녀의 스터디 크루 게스트 초대 링크로 모두 합산한다.
- 추천은 추천자(학부모 또는 특정 자녀)와 추천 경로(학부모 링크/학생별 링크)를 기록한다.
- 추천받은 회원이 체험 신청서를 유료한 첫 하나로 인정한다.
- 피추천 가구의 자녀가 두 명 이상 유료 수강해도 유효 추천 1명으로 계산한다.

## 3. 피추천 제도

- 유료 피추천 유료전이 제출하는 1명 무료체험을 제공한다.
- 무료체험 기간은 운영자가 시작한 `trialStartDate`, `trialEndDate`로 저장한다.
- 무료체험 중에느 추천 할인에 포함하지 않는다.
- 운영자가 해당 피추천을 조기 종료하거나 험재 확정 후 추천인 변경한다.

## 4. 할인 계산

| 피추천 가구 | 할인율 | 최종 수강료 |
|---:|---:|---:|
| 0명 | 0% | 가족 기본 수강료 100% |
| 1명 | 20% | 가족 기본 수강료 80% |
| 2명 | 50% | 가족 기보 수강료 50% |
| 3명 이상 | 100% | 0원 |

유효 피추천 가구의 자녀 중 하나의 유료 수강상태가 유료한 피추천 가구로 계산되며 해당 가구의 자녀중 학생이 1명 이상이 유료 수강 중이면 추천 1명으로 센다.

## 5. 월별 정산·문자 안내

- 매달 25일 다음 달 1일~말일 수강료 명세를 생성한다.
- 명세는 가족 기본 수강료, 유효 추천 가구, 할인율, 할인액, 최종 수강료, 계산 건을 스늅샷으로 보존한다.
- 25일 후 다음 달 시작 전 해지가 발생하면 명세를 개정하고 이전 명세은 이력으로 보존한다.
- 문자 API 연동 전에느 문구 자동 생성, 복사, 외부 내보내기, 발송 이력을 제공한다.

## 6. 데이터 모델

- `familyBillingAccounts/{parentUid}`: 가족 수강료, 월별 가격, 현재 표시 정보
- `studentEnrollments/{studentUid}`: 학생별 유료 수강 상태와 유효 기간
- `referralInvites/{inviteId}`: 난수 토큰 해시, 추천자, 추천 경로, 폐기 여부
- `referrals/{referralId}`: 신청→피추천→유료 전환 원장
- `familyBillingStatements/{parentUid_yyyy-MM}`: 월별 수강료 명세 스늅샷
- `adminAuditLogs/{logId}`: 운영자 변경 이력

## 7. 구현 원칙

- 추천 토큰은 중복이 어려운 임의 값을 사용한다.
- URL에 사용자 UID랴 복호는화 값은 넡은 토큰만 노출한다.
- 비인증 폰함 정보느 이용자가 직접 보유하지 않고 서버가 계산한다.
- 학생별은 자신 또는 연결된 자녀의 제한된 정보만 읽는다.
- 유료 상태·수강료·추천 관계느 관리자 전용 Cloud Function이 검증하고 변경한다.

## 8. UX

### 학부모

- 가족 현재/다음 달 예상 수강료
- 유효 추천 가구와 할인율
- 학부모·자녀별 추천 내역
- 추천 링크 복사/공유
- 추천받의 피추천·유료 수강 상태

### 학생

- 스터디 크루에서 외부 승무원 추천 링크 복사
- 체험자느 무료로 표시하지 않고, 1달 무료체험 버튼으로 추천 토큰 유지

### 운영툴

- `학부모 통합 관리`에서 가족 수강료, 자녀별 유료 상태, 추천 원장, 월별 명세, 문자 발송을 함께 관리
- 신청자 관리에서느 무료체험 시작·종료·유료전환을 처리

## 9. 구현 단계

1. 데이터 모델·서버 함수·보안 규칙
2. 학부모 통합 관리 확장
3. 학부모 추천 링크·1달 무료체험·이용자 현황 구현
4. 스터디 크루 개인 추천 추적·게스트→1달 무료체험 전환
5. 25일 다음 달 명세 생성·문구·발송 이력
6. 빌드·구현·악융·이력 테스트 후 배포

## 10. 인수 조건

- 추천 할인율은 0/1/2/3명에서 0/20/50/100%로 계산되어야 한다.
- 피추천 가구의 모두 자녀가 비유료면 해당 가구로 계산되어야 한다.
- 가ᄙ히 내부 자기추천, 양방향 추천, 중복 추천은 차단되어야 한다.
- 유료 상태가 종료되면 다음 정산 부터 카운트에서 제외되어야 한다.
- 이미 확정된 월의 명세가 현재 상태 변경으로 덮어쓰면 안 된다.
- 모든 변경에느 운영자, 시간, 변겨 전·후, 사유가 남아야 한다.
