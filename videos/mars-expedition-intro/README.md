# 화성 탐사대: 신호 복구 — 학생용 소개 영상

우주 방어대 영상과 같은 목적의 1분 소개 영상입니다. 화성 탐사대의 실제 최종 코드를 실행한 장면 위에 한글 애니메이션 설명을 더했습니다.

- 완성본: `out/mars-expedition-intro.mp4` (1920×1080, 30 fps, H.264 / AAC)
- 썸네일: `out/thumbnail.png`
- 편집 소스: `src/Composition.tsx`, `src/scenes/`, `src/style.tsx`
- 실제 플레이: `public/gameplay.mp4`
- 촬영 기록: `out/capture-report.json` (코드 해시, 상태 변화, 효과음/음악 호출, 위치)

## 실제 코드와 촬영

`content/mars-expedition/checkpoints/final-main.py`를 변경 없이 실행했습니다.
SHA-256: `e4c5c946a5be8bc2977cfe57a3242555354062801dfc9525d21fa45ec4f7882b`

자동 키보드 입력과 일정한 60Hz 시계를 사용하고, SDL 화면을 30fps로 기록합니다. 게임 객체, 점수, 에너지, 시간 제한을 직접 변경하지 않습니다. `pygame.mixer.Sound.play`와 `pygame.mixer.music`의 실제 호출 시점에 원래 게임 효과음·배경음악을 합성합니다. 음성 해설은 없습니다.

65초를 연속 촬영했습니다. 영상은 첫 41초와 54–60초를 사용합니다. 후반부에는 ‘이후 탐사의 게임오버 / 재시작 장면’이라고 표시하며, 모든 플레이는 1배속입니다.

주요 실제 사건(원본 촬영 시간):
- 4.60초: 이동문 효과음 / 공간 이동.
- 14.18초: 로봇 제거, 점수 25.
- 16.95초: 결정 회수, 점수 125 / 에너지 90.
- 32.00초: 30초 탐사 완료, 신호 복구 안내.
- 34.017초: 탐사 2 시작.
- 55.983초: 에너지 0으로 종료.
- 58.00초: 점수 0 / 에너지 100 / 탐사 1로 재시작.

## 편집과 렌더링

이 폴더에서 실행합니다.

```sh
npm ci
npm run dev -- --no-open --port=3106
npm run lint
npx remotion render MarsExpeditionIntro out/mars-expedition-intro.mp4 --codec=h264 --crf=18 --concurrency=4
```

현재 로컬 작업에서는 설치된 형제 영상 프로젝트의 `node_modules`를 심볼릭 링크로 재사용합니다. 다른 컴퓨터에서는 이 링크를 제거하고 `npm ci`로 독립 설치합니다. 기존 우주 방어대 영상 소스와 의존성은 수정하지 않았습니다.

다시 촬영하려면 이 저장소의 게임 코드와 에셋, Python의 pygame/numpy, 시스템 ffmpeg가 필요합니다.

```sh
python3 capture_gameplay.py --record --seed 8
```

이미지·효과음·배경음악은 화성 탐사대 커리큘럼 에셋을 사용합니다. 한글 폰트 Do Hyeon의 SIL OFL 원문은 `public/OFL-DoHyeon.txt`에 포함되어 있습니다.

검증 기록은 해당 협업 작업의 STATE.md에 남깁니다. 운영 사이트에는 게시하지 않았습니다.
