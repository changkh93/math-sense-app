# Data Log 09 - 신호 복구 작전 미리 보기

파이썬 → **코드 스튜디오**에서 실습합니다. 정지 → main.py 수정 → 실행 → 게임 화면 클릭 순서로 진행하세요. 게임 화면에 포커스가 있어야 방향키와 Space가 전달됩니다. 각 단계의 편집을 모두 마친 다음 실행합니다. 게임이 작거나 아래쪽 HUD가 잘리면 게임 화면 오른쪽 위의 **크게 보기** 버튼으로 전체 화면에서 확인하세요.

이전 단원의 마지막 main.py에서 이어갑니다. 누적 코드는 스크롤 창에서 읽거나, 스튜디오의 **화성 탐사대 단계 비교·수업 자료**에서 에셋을 포함한 별도 프로젝트로 열 수 있습니다. 직접 작성한 초안을 먼저 백업하세요.

## 코드를 읽고 작성하는 방법

코드 안의 `#` 뒤 문장은 **이해를 돕는 설명용 주석**입니다. 주석은 따라 적지 않아도 게임이 똑같이 실행됩니다. 먼저 주석을 읽고 그 아래 코드의 목적을 이해한 뒤, 실행되는 코드와 들여쓰기를 작성하세요. 따옴표 안의 글자, 변수 이름, 괄호와 콜론은 주석이 아니므로 생략하면 안 됩니다. 누적 코드에는 길 찾기에 필요한 핵심 주석만 남겼습니다.

각 편집의 ‘왜 이렇게 쓰나요’를 읽고, 입력하기 전에 결과를 예상해 보세요. 이번 단계의 편집을 모두 마친 다음 실행합니다. 중간에 아직 정의하지 않은 이름을 참조할 수 있으므로 편집 하나마다 실행하지 않습니다. 실행 후에는 화면이 맞는지만 보지 말고, **어떤 값이 바뀌어 그 결과가 생겼는지** 한 문장으로 설명해 보세요. 누적 코드는 먼저 직접 시도한 뒤 비교·복구할 때 사용합니다.

## 09-A - 화성 탐사대의 완성 규칙 살펴보기

코드를 더 입력하기 전에 다음 프로젝트의 목표와 객체 역할을 정리합니다.

**이 단계의 연결:** 출발 코드는 **08-B**의 누적 코드입니다. 아래 편집은 위에서부터 모두 적용합니다. 이미 완성한 나머지 메서드는 지정된 교체 범위 밖이면 그대로 둡니다.


### 입력 전에 결과를 예상해 보세요

로봇 회수와 신호 결정 회수는 같은 사건인가요?

먼저 답을 한 문장으로 적고 아래 해설과 비교하세요.

**생각 확인:** 아닙니다. 로봇 회수는 25점과 결정 생성이고, 결정 회수는 100점과 에너지 10 회복입니다. 처음 게임 규칙을 두 단계의 보상 흐름으로 그려 보세요.

### 수정 위치와 입력할 코드

정식 코드 변경은 없습니다. 아래 실행 관찰을 순서대로 확인합니다.

### 코드가 하는 일

방향키로 이동, Space로 점프, 위쪽키로 펄스를 발사합니다. 펄스에 맞은 로봇은 멈추고, 멈춘 로봇에 닿아 처리하면25점과 신호 결정이 생깁니다. 정지 후 기다리면 로봇이 재부팅됩니다. 결정을 탐사원이 회수하면100점과 에너지10을 얻고 최대100을 넘지 않습니다. 움직이는 로봇이 먼저 회수하면 로봇이 하나 늘어납니다. 피격은 에너지20 감소, 각 탐사는30초 생존입니다. 같은 색 게이트는 대각선 반대편으로 이어집니다.

### 여기서 실행하세요

스튜디오 단계 비교에서 완성 게임을 별도 프로젝트로 열어 조작과 규칙을 관찰합니다. 먼저 기초 실험 프로젝트를 백업하세요. 완성본을 관찰한 뒤 다음 단원에서 빈 본 게임 프로젝트를 준비합니다.

**이 시점의 정상 상태:** 이 단계의 누적 코드는 완성된 기초 실험입니다. 본 게임 완성 비교는 final-main을 선택합니다.

**예상과 다를 때:** 공격만으로 로봇이 제거되지 않는 것은 규칙입니다. 정지한 로봇에 직접 닿아야 합니다.
