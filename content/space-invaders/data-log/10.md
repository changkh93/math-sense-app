### main.py 수정 위치와 입력 코드

**편집 1.** `class Mission` 안의 `def reset_game`부터 그 메서드 본문 끝까지 **전체 교체**합니다. 다음 def나 다음 class는 지우지 않습니다. def 앞4칸, 본문 앞8칸을 유지합니다.

```python
    # 종료 또는 재시작에 필요한 게임 상태를 처리합니다.
    def reset_game(self):
        self.pause_game(f'최종 점수: {self.score}', 'Enter 키를 눌러 다시 도전하세요')
        self.state = 'game_over'
```


**편집 2.** `class Mission`의 마지막 메서드 아래, 다음 class 직전에 **새 메서드로 추가**합니다. def 앞4칸, 본문 앞8칸을 유지합니다.

**왜 이렇게 쓰나요 — 이 편집을 읽는 순서**

- **이 그룹의 현재 객체들을 정리합니다.** empty는 해당 Group의 구성원을 모두 빼는 동작입니다. 점수나 생명 같은 별도 변수까지 초기화하지 않습니다. 다음 라운드와 새 게임에서 무엇을 유지하고 무엇을 지울지 각각 결정해야 합니다. 함수 이름이 reset이라고 해서 모든 값이 자동 복구되는 것은 아닙니다.

```python
    # 게임오버 후 점수·생명·라운드를 새 게임 값으로 돌립니다.
    def restart_game(self):
        self.score = 0
        self.round_number = 1
        self.scout.lives = 5
        # 이 그룹의 현재 객체들을 정리합니다.
        self.raiders.empty()
        # 이 그룹의 현재 객체들을 정리합니다.
        self.scout_pulses.empty()
        # 이 그룹의 현재 객체들을 정리합니다.
        self.raider_pulses.empty()
        self.scout.reset()
        self.start_new_round()
        self.state = 'playing'
```


**편집 3.** `running = True`부터 파일 마지막 `pygame.quit()`까지의 메인 루프 전체를 **교체**합니다. 아래 코드를 다른 함수나 클래스 안에 넣지 않습니다.

**왜 이렇게 쓰나요 — 이 편집을 읽는 순서**

- **입력과 상태 변화, 그리기를 매 프레임 반복합니다.** 한 프레임은 게임을 한 번 갱신해서 표시하는 주기입니다. 준비 코드·그룹 생성은 while 위에서 한 번만 실행하고, 입력과 이동·그리기는 while 안에서 반복합니다. 물체를 매 프레임 새로 생성하면 위치가 초기화되거나 개수가 계속 늘어납니다. 반복문의 들여쓰기가 게임의 시간 구조를 정합니다.

- **지난 프레임 이후 쌓인 입력 이벤트를 처리합니다.** `event.get()`은 이번에 도착한 사건들을 꺼냅니다. KEYDOWN은 누르기 시작한 사건이고 `key.get_pressed()`는 지금 계속 누르고 있는 상태입니다. 점프·발사 한 번은 이벤트로, 연속 좌우 이동은 누름 상태로 처리하는 이유가 여기에 있습니다. 스튜디오 게임 화면을 클릭해야 입력이 게임으로 전달됩니다.

- **그룹의 image와 rect를 사용해 화면에 그립니다.** 그룹의 `update()`는 각 객체의 update를 호출하고, `draw(screen)`은 image를 rect 위치에 그립니다. update만 하면 값만 바뀌고, draw만 하면 같은 그림이 같은 위치에 남습니다. 배경 → 물체 → HUD/안내 순서로 그려야 뒤에 그린 배경이 물체를 덮지 않습니다. 마지막 display.update가 그린 화면을 표시합니다.

```python
running = True
# 입력과 상태 변화, 그리기를 매 프레임 반복합니다.
while running:
    # 지난 프레임 이후 쌓인 입력 이벤트를 처리합니다.
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_SPACE and mission.state == 'playing':
                scout.fire()
            if event.key == pygame.K_RETURN:
                if mission.state == 'game_over':
                    mission.restart_game()
                elif mission.state == 'paused':
                    mission.state = 'playing'

    if not running:
        break

    screen.fill((9, 17, 37))

    if mission.state == 'playing':
        scouts.update()
        raiders.update()
        scout_pulses.update()
        raider_pulses.update()
        mission.update()

    # 그룹의 image와 rect를 사용해 화면에 그립니다.
    scouts.draw(screen)
    # 그룹의 image와 rect를 사용해 화면에 그립니다.
    raiders.draw(screen)
    # 그룹의 image와 rect를 사용해 화면에 그립니다.
    scout_pulses.draw(screen)
    # 그룹의 image와 rect를 사용해 화면에 그립니다.
    raider_pulses.draw(screen)
    mission.draw()

    pygame.display.update()
    clock.tick(FPS)

pygame.quit()
```


### 코드가 하는 일

reset_game은 최종 점수 문구와 game_over만 설정합니다. restart_game은 Enter를 눌렀을 때 점수0/라운드1/생명5, 그룹/기체 위치를 초기화하고 새 편대를 만듭니다. start_new_round가 paused를 설정하므로 마지막 state=playing으로 Enter 한 번에 새 게임을 시작합니다. 일반 paused의 Enter는 초기화 없이 계속합니다. QUIT은 반복을 다시 True로 만들지 않습니다.

## 10-B - 아군 탄환과 적의 충돌·점수

충돌 후 제거할 그룹과 점수를 정합니다. 탄환 한 발이 적 둘과 겹치면 점수를 한 번만 더해도 될까요?

**이 단계의 연결:** 출발 코드는 **10-A**의 누적 코드입니다. 아래 편집은 위에서부터 모두 적용합니다. 이미 완성한 나머지 메서드는 지정된 교체 범위 밖이면 그대로 둡니다.


### 입력 전에 결과를 예상해 보세요

탄환 하나가 적 두 기와 동시에 겹치면 점수를 어떻게 계산하나요?

먼저 답을 한 문장으로 적고 아래 해설과 비교하세요.

**생각 확인:** 충돌 결과 목록 길이가 2이면 100×2=200점입니다. 결과 딕셔너리의 열쇠 수만 세면 탄환 수만 세어 격추 수를 놓칩니다.

### main.py 수정 위치와 입력 코드

**편집 1.** `class Mission` 안의 `def check_collisions`부터 그 메서드 본문 끝까지 **전체 교체**합니다. 다음 def나 다음 class는 지우지 않습니다. def 앞4칸, 본문 앞8칸을 유지합니다.

**왜 이렇게 쓰나요 — 이 편집을 읽는 순서**

- **두 그룹의 충돌 결과를 받아 맞힌 대상 수를 셉니다.** `groupcollide(A, B, 지울A, 지울B)`는 A의 객체를 열쇠로, 그 객체가 맞힌 B 목록을 값으로 돌려줍니다. 두 True/False는 각각 어느 쪽을 그룹에서 제거할지 정합니다. 우주 방어대는 양쪽 제거, 화성의 로봇 피격은 펄스만 제거하고 로봇을 남겨 상태를 바꿉니다. values()로 얻는 것은 객체 하나가 아니라 대상 목록이라는 점에 주의하세요.

```python
    # 접촉 대상을 검사하고 이 단계의 충돌 규칙을 적용합니다.
    def check_collisions(self):
        # 두 그룹의 충돌 결과를 받아 맞힌 대상 수를 셉니다.
        hits = pygame.sprite.groupcollide(self.scout_pulses, self.raiders, True, True)
        if hits:
            self.raider_break_sound.play()
            for killed_raiders in hits.values():
                self.score += 100 * len(killed_raiders)
```


### 코드가 하는 일

groupcollide(아군탄환,적,True,True)는 겹친 양쪽 Sprite를 소속 그룹에서 제거합니다. 결과 딕셔너리의 각 값은 그 탄환이 맞힌 적 목록입니다. 목록 길이에100을 곱해 실제 격추 수만큼 더합니다. 결과가 있을 때만 격추음을 냅니다. 사각형 Rect 기준 충돌이며 투명 이미지 윤곽 그대로의 픽셀 판정은 아닙니다.

Enter로 시작하고 적을 향해 발사합니다. 맞은 적과 탄환이 사라지고 적 한 기당100점이 증가합니다. 파편 애니메이션은 없습니다.

**이 시점의 정상 상태:** 적 탄환이 아군을 통과하는 것은 아직 정상입니다.

**예상과 다를 때:** 명중해도 그대로면 check_collisions가 Mission.update에 연결됐는지 확인합니다. 항상100만 늘면 killed_raiders 길이 계산을 확인합니다.

### 잠깐 바꿔 보고 원래 상태로 복원하기

정지한 뒤 `running = True` 바로 위에 다음 시험 코드만 추가합니다. 들여쓰기 없이 시작하며 for 본문만4칸입니다. 클래스/메서드 안에 넣지 않습니다.

### main.py 수정 위치와 입력 코드

**편집 1.** `class Mission` 안의 `def check_collisions`부터 그 메서드 본문 끝까지 **전체 교체**합니다. 다음 def나 다음 class는 지우지 않습니다. def 앞4칸, 본문 앞8칸을 유지합니다.

**왜 이렇게 쓰나요 — 이 편집을 읽는 순서**

- **두 그룹의 충돌 결과를 받아 맞힌 대상 수를 셉니다.** `groupcollide(A, B, 지울A, 지울B)`는 A의 객체를 열쇠로, 그 객체가 맞힌 B 목록을 값으로 돌려줍니다. 두 True/False는 각각 어느 쪽을 그룹에서 제거할지 정합니다. 우주 방어대는 양쪽 제거, 화성의 로봇 피격은 펄스만 제거하고 로봇을 남겨 상태를 바꿉니다. values()로 얻는 것은 객체 하나가 아니라 대상 목록이라는 점에 주의하세요.

- **객체 하나와 그룹을 비교하고 충돌한 대상 목록을 받습니다.** `spritecollide(객체, 그룹, 제거여부)`는 겹친 대상들의 리스트를 반환합니다. 빈 리스트는 if에서 거짓, 한 개 이상은 참입니다. if 본문을 한 번 실행하는 규칙과 len(목록)만큼 보상을 계산하는 규칙은 다릅니다. 여러 탄환 피격은 생명 한 번 차감, 결정 여러 개 회수는 개수별 보상이라는 해당 단계의 의도를 읽으세요.

```python
    # 접촉 대상을 검사하고 이 단계의 충돌 규칙을 적용합니다.
    def check_collisions(self):
        # 두 그룹의 충돌 결과를 받아 맞힌 대상 수를 셉니다.
        hits = pygame.sprite.groupcollide(self.scout_pulses, self.raiders, True, True)
        if hits:
            self.raider_break_sound.play()
            for killed_raiders in hits.values():
                self.score += 100 * len(killed_raiders)

        # 객체 하나와 그룹을 비교하고 충돌한 대상 목록을 받습니다.
        if pygame.sprite.spritecollide(self.scout, self.raider_pulses, True):
            self.shield_hit_sound.play()
            self.scout.lives -= 1
            self.check_game_status('기체가 피격되었습니다!', 'Enter 키를 눌러 계속하세요')
```


### 코드가 하는 일

spritecollide는 기체 하나와 적 탄환 그룹을 비교합니다. True로 충돌한 탄환을 제거합니다. 결과 목록이 비어 있지 않을 때 if 본문이 한 번 실행되므로 같은 검사에서 여러 탄환에 맞아도 생명은1만 줄어듭니다. 피격음→생명감소→check_game_status로 정돈하고 대기/게임오버를 정합니다. Mission.update의 return 검사가 이 상태 전환을 보호합니다.
