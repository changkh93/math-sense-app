## 코드를 읽고 작성하는 방법

코드 안의 `#` 뒤 문장은 **이해를 돕는 설명용 주석**입니다. 주석은 따라 적지 않아도 게임이 똑같이 실행됩니다. 먼저 주석을 읽고 그 아래 코드의 목적을 이해한 뒤, 실행되는 코드와 들여쓰기를 작성하세요. 따옴표 안의 글자, 변수 이름, 괄호와 콜론은 주석이 아니므로 생략하면 안 됩니다. 누적 코드에는 길 찾기에 필요한 핵심 주석만 남겼습니다.

각 편집의 ‘왜 이렇게 쓰나요’를 읽고, 입력하기 전에 결과를 예상해 보세요. 이번 단계의 편집을 모두 마친 다음 실행합니다. 중간에 아직 정의하지 않은 이름을 참조할 수 있으므로 편집 하나마다 실행하지 않습니다. 실행 후에는 화면이 맞는지만 보지 말고, **어떤 값이 바뀌어 그 결과가 생겼는지** 한 문장으로 설명해 보세요. 누적 코드는 먼저 직접 시도한 뒤 비교·복구할 때 사용합니다.


## 08-A - 전체 편대를 함께 반전시키기

경계 도달 여부를 먼저 모두 조사하고, 그 결과로 전체를 움직입니다. 각 적이 따로 방향을 바꾸면 배열은 어떻게 될까요?

**이 단계의 연결:** 출발 코드는 **07-E**의 누적 코드입니다. 아래 편집은 위에서부터 모두 적용합니다. 이미 완성한 나머지 메서드는 지정된 교체 범위 밖이면 그대로 둡니다.


### 입력 전에 결과를 예상해 보세요

여러 적이 동시에 벽에 닿아도 direction을 한 번만 뒤집어야 하는 이유는 무엇인가요?

먼저 답을 한 문장으로 적고 아래 해설과 비교하세요.

**생각 확인:** -1을 두 번 곱하면 원래 방향으로 돌아옵니다. 경계 조사에서 표시만 하고, 조사 후 별도 반복에서 모든 적을 한 번씩 움직여야 합니다.

### main.py 수정 위치와 입력 코드

**편집 1.** `class Mission` 안의 `def shift_raiders`부터 그 메서드 본문 끝까지 **전체 교체**합니다. 다음 def나 다음 class는 지우지 않습니다. def 앞4칸, 본문 앞8칸을 유지합니다.

```python
    # 경계에 닿은 적이 있는지 조사한 뒤 편대 전체에 반영합니다.
    def shift_raiders(self):
        shift = False
        for raider in self.raiders:
            if raider.rect.left <= 0 or raider.rect.right >= SCREEN_WIDTH:
                shift = True

        if shift:
            for raider in self.raiders:
                raider.rect.y += 10 * self.round_number
                raider.direction *= -1
                raider.rect.x += raider.direction * raider.velocity
```


### 코드가 하는 일

shift=False로 시작해 한 기라도 left<=0 또는 right>=1200이면 True로 둡니다. 그 뒤 별도 반복문으로 모두 y를10×라운드만큼 늘리고 direction에-1을 곱합니다. 마지막 x 보정으로 경계에서 한 걸음 떨어져 다음 프레임에 같은 경계를 다시 감지하는 일을 줄입니다. 첫 적을 조사하자마자 전체를 움직이지 않고 조사와 이동을 분리합니다.

### 여기서 실행하세요

정지 → 위 코드 수정 → 실행 → 게임 화면 클릭 순서로 진행합니다.

편대가 오른쪽 끝에 닿으면 모두 아래10픽셀로 내려오고 왼쪽으로 움직입니다. 왼쪽 끝에서도 함께 반전합니다.

**이 시점의 정상 상태:** 아직 방어선을 넘어도 생명이 줄지 않습니다.

**예상과 다를 때:** 일부 적만 반전하면 두 번째 for가 첫 번째 for 안에 들어갔는지 확인합니다. 즉시 계속 내려가면 경계 보정 줄을 확인합니다.

### 잠깐 바꿔 보고 원래 상태로 복원하기

정지한 뒤 `running = True` 바로 위에 다음 시험 코드만 추가합니다. 들여쓰기 없이 시작하며 for 본문만4칸입니다. 클래스/메서드 안에 넣지 않습니다.


## 08-B - 침범을 한 번의 사건으로 처리하기

한 번의 하강에서 여러 적이 선을 넘더라도 생명을 여러 번 빼면 안 됩니다. 감지용 변수를 먼저 모읍니다.

**이 단계의 연결:** 출발 코드는 **08-A**의 누적 코드입니다. 아래 편집은 위에서부터 모두 적용합니다. 이미 완성한 나머지 메서드는 지정된 교체 범위 밖이면 그대로 둡니다.


### 입력 전에 결과를 예상해 보세요

침범한 적이 5기라면 생명을 5개 빼야 할까요?

먼저 답을 한 문장으로 적고 아래 해설과 비교하세요.

**생각 확인:** 이 게임 규칙은 편대 침범 한 사건당 1개입니다. breach 표시를 모은 뒤 for 바깥에서 생명을 한 번 차감합니다. 후속 정돈은 다음 단원에서 구현합니다.

### main.py 수정 위치와 입력 코드

**편집 1.** `class Mission` 안의 `def shift_raiders`부터 그 메서드 본문 끝까지 **전체 교체**합니다. 다음 def나 다음 class는 지우지 않습니다. def 앞4칸, 본문 앞8칸을 유지합니다.

```python
    # 경계에 닿은 적이 있는지 조사한 뒤 편대 전체에 반영합니다.
    def shift_raiders(self):
        shift = False
        for raider in self.raiders:
            if raider.rect.left <= 0 or raider.rect.right >= SCREEN_WIDTH:
                shift = True

        if shift:
            breach = False
            for raider in self.raiders:
                raider.rect.y += 10 * self.round_number
                raider.direction *= -1
                raider.rect.x += raider.direction * raider.velocity
                if raider.rect.bottom >= SCREEN_HEIGHT - 100:
                    breach = True

            if breach:
                self.breach_sound.play()
                self.scout.lives -= 1
                self.check_game_status('외계 함선이 방어선을 침범했습니다!', 'Enter 키를 눌러 계속하세요')
```


### 코드가 하는 일

breach=False에서 시작하고 내려온 적의 bottom>=600이면 True로 둡니다. 생명 차감과 소리는 for 바깥에서 한 번 실행합니다. check_game_status로 후속 정리를 맡기지만 아직 pass입니다. 따라서 이후 다른 경계에 닿아 다시 하강하면 생명이 또 줄 수 있습니다.

### 여기서 실행하세요

정지 → 위 코드 수정 → 실행 → 게임 화면 클릭 순서로 진행합니다.

아래 빠른 시험에서 침범음과 생명5→4를 확인합니다. 기본 속도로 오래 기다릴 필요가 없습니다.

**이 시점의 정상 상태:** 침범 후 위치 복원과 일시정지는09에서 구현하므로 적이 계속 이동합니다. 이 시점에 게임오버가 없는 것도 정상입니다.

**예상과 다를 때:** 한 번에 생명이 여러 개 줄면 lives-=1이 for 안인지 확인합니다. 전혀 줄지 않으면 bottom과 방어선600 비교를 확인합니다.

### 잠깐 바꿔 보고 원래 상태로 복원하기

정지한 뒤 `running = True` 바로 위에 다음 시험 코드만 추가합니다. 들여쓰기 없이 시작하며 for 본문만4칸입니다. 클래스/메서드 안에 넣지 않습니다.


**복원:** 정지 → 방금 추가한 시험 블록 전체 삭제 → 다시 실행합니다. 이 시험 블록은 다음 단계의 정식 코드에 포함하지 않습니다.
