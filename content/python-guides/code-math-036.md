## 이 코드가 놓인 수업

**파이썬 수학 → 기초 자료형과 제어문 (1 ~ 10) → for반복문**에서 가져온 ‘세트 3: 리스트 문장 반복과 split 단어 반복’ 코드입니다. 단원 전체를 요약하는 대신 이 단계가 담당하는 작업을 한 가지씩 읽습니다. 코드 속 이름·점수·예시 자료는 교재의 연습 데이터이며 실제 학생의 기록이나 성과를 소개하는 자료가 아닙니다.

학습 목표는 코드를 그대로 입력하는 데서 멈추지 않고, 어떤 값이 준비되고 어떤 조건에서 결과가 달라지는지를 설명하는 것입니다. 다음 질문에 먼저 답을 적고 코드와 대조해 보세요.

> `my_list`의 첫 값과 마지막 값을 구분하고, `i`가 어느 순서로 바뀌는지 말해 보세요.

## 원본 코드와 핵심 줄

```python
my_list = ['왕새우는 천재다!!!', '게다가 잘생겼어', '성격도 짱']

print('--- 문장 세 번씩 외치기 ---')

for i in my_list:
    print(i * 3)

sentence = '나는 파이썬을 배우고 있습니다.'
words = sentence.split()

print('--- 단어 하나씩 보기 ---')

for word in words:
    print(word)
```

아래 행 번호는 위 코드 블록의 첫 줄을 1행으로 셉니다. 긴 예제에서는 주요 문장 10개까지 짚었습니다. 함수 안의 줄은 함수를 호출할 때 실행되므로, 행 번호 순서와 실제 실행 순서가 항상 같은 것은 아닙니다.

- **1행**: `my_list`에 `['왕새우는 천재다!!!', '게다가 잘생겼어', '성격도 짱']`의 값을 저장합니다.
- **3행**: `print('--- 문장 세 번씩 외치기 ---')`를 호출합니다. 괄호 안의 값을 화면 출력과 연결해 읽으세요.
- **5행**: `my_list`에서 값을 하나씩 꺼내 `i`로 읽습니다. 들여쓴 본문이 반복 범위입니다.
- **6행**: `print(i * 3)`를 호출합니다. 괄호 안의 값을 화면 출력과 연결해 읽으세요.
- **8행**: `sentence`에 `'나는 파이썬을 배우고 있습니다.'`의 값을 저장합니다.
- **9행**: `words`에 `sentence.split()`의 값을 저장합니다.
- **11행**: `print('--- 단어 하나씩 보기 ---')`를 호출합니다. 괄호 안의 값을 화면 출력과 연결해 읽으세요.
- **13행**: `words`에서 값을 하나씩 꺼내 `word`로 읽습니다. 들여쓴 본문이 반복 범위입니다.
- **14행**: `print(word)`를 호출합니다. 괄호 안의 값을 화면 출력과 연결해 읽으세요.

## 결과를 이해하는 확인 활동

### 반복의 범위를 읽습니다

반복문은 같은 문장을 여러 번 실행합니다. 반복 바깥에 둔 문장은 반복 횟수와 별개로 실행됩니다. 들여쓰기를 먼저 표시하면 결과가 여러 번 나오는 이유를 확인할 수 있습니다.

**확인 활동:** 반복 안과 밖의 출력이 각각 몇 번 실행될지 먼저 적고 확인하세요.

4. ‘작동했다’ 대신 **바꾼 줄 → 관찰한 결과 → 그렇게 된 이유**를 남깁니다. 예상과 다르면 마지막 오류 메시지와 관련된 줄을 함께 가져와 질문합니다.
