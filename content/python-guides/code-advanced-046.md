학습 목표는 코드를 그대로 입력하는 데서 멈추지 않고, 어떤 값이 준비되고 어떤 조건에서 결과가 달라지는지를 설명하는 것입니다. 다음 질문에 먼저 답을 적고 코드와 대조해 보세요.

> `num_names`의 첫 값과 마지막 값을 구분하고, `(i, name)`가 어느 순서로 바뀌는지 말해 보세요.

## 원본 코드와 핵심 줄

```python
nums = [1, 2, 3, 4]
names = ['왕새우', '박명수', '유재석', '이명박']
my_zip = zip(nums, names)
num_names = list(my_zip)
print(num_names)

for i, name in num_names:
    print(f'번호: {i}, 이름: {name}')
```

아래 행 번호는 위 코드 블록의 첫 줄을 1행으로 셉니다. 긴 예제에서는 주요 문장 10개까지 짚었습니다. 함수 안의 줄은 함수를 호출할 때 실행되므로, 행 번호 순서와 실제 실행 순서가 항상 같은 것은 아닙니다.

- **1행**: `nums`에 `[1, 2, 3, 4]`의 값을 저장합니다.
- **2행**: `names`에 `['왕새우', '박명수', '유재석', '이명박']`의 값을 저장합니다.
- **3행**: `my_zip`에 `zip(nums, names)`의 값을 저장합니다.
- **4행**: `num_names`에 `list(my_zip)`의 값을 저장합니다.
- **5행**: `print(num_names)`를 호출합니다. 괄호 안의 값을 화면 출력과 연결해 읽으세요.
- **7행**: `num_names`에서 값을 하나씩 꺼내 `(i, name)`로 읽습니다. 들여쓴 본문이 반복 범위입니다.
- **8행**: `print(f'번호: {i}, 이름: {name}')`를 호출합니다. 괄호 안의 값을 화면 출력과 연결해 읽으세요.
