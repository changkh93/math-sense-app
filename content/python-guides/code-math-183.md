학습 목표는 코드를 그대로 입력하는 데서 멈추지 않고, 어떤 값이 준비되고 어떤 조건에서 결과가 달라지는지를 설명하는 것입니다. 다음 질문에 먼저 답을 적고 코드와 대조해 보세요.

> 조건 `20 <= i < 25`가 참일 때와 거짓일 때, 다음에 실행되는 줄은 무엇인가요?

## 원본 코드와 핵심 줄

```python
import pandas as pd
import numpy as np

weight = np.random.randint(20, 51, 24)

print('무작위 몸무게 데이터 24명')
print(weight)

hist = np.zeros(6)

for i in weight:
    if 20 <= i < 25:
        hist[0] += 1
    elif 25 <= i < 30:
        hist[1] += 1
    elif 30 <= i < 35:
        hist[2] += 1
    elif 35 <= i < 40:
        hist[3] += 1
    elif 40 <= i < 45:
        hist[4] += 1
    else:
        hist[5] += 1

bins = ['20~25kg', '25~30kg', '30~35kg', '35~40kg', '40~45kg', '45~50kg']
s_weight = pd.Series(hist, index=bins, dtype=int)

print('몸무게 도수분포표')
print(s_weight)
```

아래 행 번호는 위 코드 블록의 첫 줄을 1행으로 셉니다. 긴 예제에서는 주요 문장 10개까지 짚었습니다. 함수 안의 줄은 함수를 호출할 때 실행되므로, 행 번호 순서와 실제 실행 순서가 항상 같은 것은 아닙니다.

- **4행**: `weight`에 `np.random.randint(20, 51, 24)`의 값을 저장합니다.
- **6행**: `print('무작위 몸무게 데이터 24명')`를 호출합니다. 괄호 안의 값을 화면 출력과 연결해 읽으세요.
- **7행**: `print(weight)`를 호출합니다. 괄호 안의 값을 화면 출력과 연결해 읽으세요.
- **9행**: `hist`에 `np.zeros(6)`의 값을 저장합니다.
- **11행**: `weight`에서 값을 하나씩 꺼내 `i`로 읽습니다. 들여쓴 본문이 반복 범위입니다.
- **12행**: `20 <= i < 25`를 검사합니다. 참인 경로와 그렇지 않은 경로에서 바뀌는 값을 나누어 보세요.
- **13행**: `hist[0]`의 기존 값에 `1`를 사용해 `+` 연산 결과를 반영합니다.
- **14행**: `25 <= i < 30`를 검사합니다. 참인 경로와 그렇지 않은 경로에서 바뀌는 값을 나누어 보세요.
- **15행**: `hist[1]`의 기존 값에 `1`를 사용해 `+` 연산 결과를 반영합니다.
- **16행**: `30 <= i < 35`를 검사합니다. 참인 경로와 그렇지 않은 경로에서 바뀌는 값을 나누어 보세요.

## 결과를 이해하는 확인 활동

### 이름표에 맞추는 계산

Series는 값과 인덱스를 함께 가집니다. 두 Series를 더할 때 순서만 보는 것이 아니라 인덱스를 맞춥니다. 한쪽에만 있는 이름표에서는 결측값이 나올 수 있습니다.

**확인 활동:** 인덱스 순서를 바꾸어도 같은 이름표끼리 더해지는지 확인하세요. 위치로 고를 때와 이름표로 고를 때를 구분합니다.
