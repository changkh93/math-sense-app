**파이썬 수학 → 데이터 분석 기초 (61 ~ 70) → itertools 확률**에서 가져온 ‘세트 4: 소수 판별 함수로 주사위 합 검사하기’ 코드입니다. 단원 전체를 요약하는 대신 이 단계가 담당하는 작업을 한 가지씩 읽습니다. 코드 속 이름·점수·예시 자료는 교재의 연습 데이터이며 실제 학생의 기록이나 성과를 소개하는 자료가 아닙니다.

학습 목표는 코드를 그대로 입력하는 데서 멈추지 않고, 어떤 값이 준비되고 어떤 조건에서 결과가 달라지는지를 설명하는 것입니다. 다음 질문에 먼저 답을 적고 코드와 대조해 보세요.

> 조건 `n < 2`가 참일 때와 거짓일 때, 다음에 실행되는 줄은 무엇인가요?

## 원본 코드와 핵심 줄

```python
import itertools

def is_prime(n):
    if n < 2:
        return False

    for i in range(2, n):
        if n % i == 0:
            return False

    return True

total_event = list(itertools.product(range(1, 7), range(1, 7)))
prime_sum_events = [i for i in total_event if is_prime(sum(i))]

print('두 눈의 합이 소수인 경우들')
print(prime_sum_events)
print(f'경우의 수: {len(prime_sum_events)}가지')
```

아래 행 번호는 위 코드 블록의 첫 줄을 1행으로 셉니다. 긴 예제에서는 주요 문장 10개까지 짚었습니다. 함수 안의 줄은 함수를 호출할 때 실행되므로, 행 번호 순서와 실제 실행 순서가 항상 같은 것은 아닙니다.

- **3행**: `is_prime(n)` 함수를 정의합니다. 정의와 실제 호출 시점은 구분합니다.
- **4행**: `n < 2`를 검사합니다. 참인 경로와 그렇지 않은 경로에서 바뀌는 값을 나누어 보세요.
- **5행**: `False`을 호출한 곳으로 돌려주고 이번 함수 실행을 끝냅니다.
- **7행**: `range(2, n)`에서 값을 하나씩 꺼내 `i`로 읽습니다. 들여쓴 본문이 반복 범위입니다.
- **8행**: `n % i == 0`를 검사합니다. 참인 경로와 그렇지 않은 경로에서 바뀌는 값을 나누어 보세요.
- **9행**: `False`을 호출한 곳으로 돌려주고 이번 함수 실행을 끝냅니다.
- **11행**: `True`을 호출한 곳으로 돌려주고 이번 함수 실행을 끝냅니다.
- **13행**: `total_event`에 `list(itertools.product(range(1, 7), range(1, 7)))`의 값을 저장합니다.
- **14행**: `prime_sum_events`에 `[i for i in total_event if is_prime(sum(i))]`의 값을 저장합니다.
- **16행**: `print('두 눈의 합이 소수인 경우들')`를 호출합니다. 괄호 안의 값을 화면 출력과 연결해 읽으세요.

## 결과를 이해하는 확인 활동

### 시작과 끝의 포함 여부

range의 끝값은 포함되지 않습니다. 반복 횟수를 정할 때 마지막으로 필요한 값과 끝 인자를 구분합니다. 간격이 음수이면 시작값과 끝값의 방향도 맞아야 합니다.

**확인 활동:** 작은 범위로 바꾸어 list(range(...))를 먼저 확인한 뒤 반복 횟수의 예측과 대조하세요.

### 소수 판별의 반례

1은 소수가 아닙니다. 2는 가장 작은 소수이고, 9처럼 작은 수의 제곱은 반드시 제외해야 합니다. 나누어떨어지는 수를 하나 찾았다는 사실과 끝까지 찾지 못했다는 사실을 서로 다른 반환 경로로 읽습니다.

**확인 활동:** 함수 정의가 준비되면 1·2·9·11을 각각 넣어 False·True·False·True가 나오는지 대조하세요. 작은 표본의 통과가 모든 입력의 검증을 대신하지는 않습니다.

### 주사위 두 개를 구별해서 셉니다

product는 각 주사위에서 하나씩 고른 순서쌍을 만듭니다. 두 공정한 주사위에서는 36개 순서쌍의 가능성이 같습니다. (1,2)와 (2,1)을 같은 경우로 합치면 확률의 분모가 달라집니다.

**확인 활동:** 전체 경우가 36개인지 확인하고, 원하는 사건의 개수를 36으로 나누세요. 이 가정은 공정한 주사위에 해당합니다.
