## 이 코드가 놓인 수업

**파이썬 수학 → 클래스와 배열 (41 ~ 50) → class은행계좌**에서 가져온 ‘세트 1: input과 Circle 클래스로 원 계산하기’ 코드입니다. 단원 전체를 요약하는 대신 이 단계가 담당하는 작업을 한 가지씩 읽습니다. 코드 속 이름·점수·예시 자료는 교재의 연습 데이터이며 실제 학생의 기록이나 성과를 소개하는 자료가 아닙니다.

학습 목표는 코드를 그대로 입력하는 데서 멈추지 않고, 어떤 값이 준비되고 어떤 조건에서 결과가 달라지는지를 설명하는 것입니다. 다음 질문에 먼저 답을 적고 코드와 대조해 보세요.

> `pi`에 들어갈 값은 무엇이며, 그 값을 확인하려면 어디에 print를 놓으면 좋을까요?

## 원본 코드와 핵심 줄

```python
class Circle:
    pi = 3.14

    def __init__(self, r):
        self.r = r

    def get_area(self):
        return round(self.r ** 2 * Circle.pi, 2)

    def get_circum(self):
        return round(self.r * 2 * Circle.pi, 2)

try:
    radius_input = input('원하는 크기의 원의 반지름을 입력하세요: ')
    radius = int(radius_input)

    my_circle = Circle(radius)
    my_circle_area = my_circle.get_area()
    my_circle_circum = my_circle.get_circum()

    print(f'반지름이 {radius}인 원의 넓이는 {my_circle_area}')
    print(f'원의 둘레는 {my_circle_circum}')
except ValueError:
    print('앗! 숫자를 입력해야 해요!')
```

아래 행 번호는 위 코드 블록의 첫 줄을 1행으로 셉니다. 긴 예제에서는 주요 문장 10개까지 짚었습니다. 함수 안의 줄은 함수를 호출할 때 실행되므로, 행 번호 순서와 실제 실행 순서가 항상 같은 것은 아닙니다.

- **1행**: `Circle` 클래스에 상태와 행동을 묶습니다. 이 이름으로 만든 객체의 값은 객체마다 달라질 수 있습니다.
- **2행**: `pi`에 `3.14`의 값을 저장합니다.
- **4행**: `__init__(self, r)` 함수를 정의합니다. 정의와 실제 호출 시점은 구분합니다.
- **5행**: `self.r`에 `r`의 값을 저장합니다.
- **7행**: `get_area(self)` 함수를 정의합니다. 정의와 실제 호출 시점은 구분합니다.
- **8행**: `round(self.r ** 2 * Circle.pi, 2)`을 호출한 곳으로 돌려주고 이번 함수 실행을 끝냅니다.
- **10행**: `get_circum(self)` 함수를 정의합니다. 정의와 실제 호출 시점은 구분합니다.
- **11행**: `round(self.r * 2 * Circle.pi, 2)`을 호출한 곳으로 돌려주고 이번 함수 실행을 끝냅니다.
- **14행**: `radius_input`에 `input('원하는 크기의 원의 반지름을 입력하세요: ')`의 값을 저장합니다.
- **15행**: `radius`에 `int(radius_input)`의 값을 저장합니다.

## 실행 전에 준비할 것과 확인 결과

이 예제는 **앞 단계 코드 또는 별도 실행 환경이 필요한 코드 읽기 자료**입니다. 문법은 확인했지만 이 블록만의 완성 프로그램 실행은 확인하지 않았습니다. 확인한 실행 조건: 입력 또는 외부 작업 필요: input. 거북이 그래픽은 수업에서 사용하는 그래픽 지원 실행 환경이 필요합니다.

## 결과를 이해하는 확인 활동

### 입력한 숫자도 처음에는 문자열입니다

input의 결과는 문자열입니다. 계산하려면 허용할 입력 범위를 정한 뒤 int나 float로 바꾸어야 합니다. 빈칸이나 글자를 넣으면 변환이 실패할 수 있으므로 성공 입력과 실패 입력을 구분해 시험합니다.

**확인 활동:** 숫자 입력 하나와 숫자가 아닌 입력 하나를 비교하고, 변환 오류가 어디서 발생하는지 찾으세요.

### 출력과 반환은 다릅니다

print는 화면에 보여주고 return은 호출한 곳으로 값을 돌려줍니다. 반환한 값이 있어야 다음 계산에 이어 쓸 수 있습니다. 함수 안에서 return에 도달하면 그 호출의 나머지 문장은 실행되지 않습니다.

**확인 활동:** 함수의 반환값을 변수에 담아 type과 값을 확인하고, 화면 출력과 구분해 기록하세요.
