스크래치에서 캐릭터를 움직이던 아이가 파이썬을 만나면, 처음에는 더 어려워졌다고 느낄 수 있습니다. 블록을 끼우던 자리에 글자와 괄호가 들어오기 때문입니다. 블록 코딩에서 배운 생각이 사라진 것은 아닙니다. 같은 생각을 다른 표기로 옮기는 중입니다.

## 이미 알고 있는 생각을 찾아보세요

‘열 번 반복하기’는 파이썬의 반복문과 연결됩니다. ‘점수가 10보다 크면’은 조건문으로, ‘점수’라는 이름에 값을 보관하는 일은 변수로 이어집니다. 시작할 때 문법 이름을 전부 외우게 하기보다, 예전에 만든 작품에서 반복과 조건이 어디에 있었는지 찾아보면 좋습니다.

```python
score = 0
for turn in range(3):
    score = score + 10
print(score)
```

이 코드는 점수에 10을 세 번 더하고 30을 출력합니다. `range(3)`의 값은 0, 1, 2이지만 반복 횟수는 세 번입니다. 숫자가 0에서 시작하는 점은 처음에 헷갈릴 수 있으니, 반복 횟수와 반복 중 사용하는 값을 나누어 보세요.

## 작품 전체를 옮기지 않아도 됩니다

처음부터 스크래치 게임 전체를 파이썬으로 다시 만들려 하면 키 입력·그림·충돌·점수를 한꺼번에 다뤄야 합니다. 먼저 점수가 올라가는 부분만 떼어 실행하세요. 그다음 점수가 일정 값에 도달했을 때 문장을 출력하도록 바꿔 봅니다. 작은 기능이 작동하는 것을 확인하고 다음 기능을 붙이면 오류가 난 위치도 좁힐 수 있습니다.

## 스크래치를 그만둘 필요는 없습니다

아이디어를 빠르게 표현할 때는 블록이 편할 수 있고, 텍스트로 조건을 세밀하게 다룰 때는 파이썬이 편할 수 있습니다. 한쪽을 유치한 단계로 말하면 지금까지 만든 작품의 가치도 작아집니다. “같은 게임의 점수 부분을 다른 방식으로 만들어 볼까?”처럼 연결해 주세요.

## 전환 시점은 이런 장면에서 판단합니다

아이가 자신이 만든 블록의 순서를 설명하고, 반복할 부분을 알아보며, 새로운 표기를 익힐 마음이 있다면 작은 파이썬 활동을 시도할 수 있습니다. 메타센스에서는 입문 과정에서 시작해 기초 이후 프로젝트로 이어집니다. 스크래치 경험이 있다는 이유만으로 게임 프로젝트부터 배정된다고 생각하지 말고, 체험에서 현재 가능한 일을 확인하는 편이 좋습니다.

표기의 차이는 [파이썬 공식 반복문 안내](https://docs.python.org/3/tutorial/controlflow.html)에서도 확인할 수 있습니다.
