# 파이썬 과정 기반 코드 노트

2026-09-22 운영 과정의 단원·코드 연습을 읽기 전용으로 조사했다. 학생 자료는 사용하지 않는다.

- 처음 파이썬 50 / 게임 프로젝트 100 / 파이썬 심화 50 / 파이썬 수학 200.
- `sources.json`: 선택한 원본 코드, 과정·단원·연습 식별자, SHA-256. 원본 DB는 변경하지 않았다.
- `verification.json`: 문맥을 보완한 문법 검사와 보수적인 로컬 실행 결과. 문법 통과는 동작·교육적 정확성 보증이 아니다.
- `scripts/verify-python-guide-examples.py`는 GUI·네트워크·파일 I/O·사용자 입력이 필요한 코드를 자동 실행하지 않는다.
- 앞 단계 변수나 프로젝트 객체가 필요한 예제는 완성 프로그램으로 소개하지 않는다. 공개 글에 준비 조건을 표시한다.
- 공개 이미지가 코드와 정확히 대응하지 않으면 장식용 교재 화면을 붙이지 않는다. 코드와 검증된 출력 자체를 제시한다.
- 계정·학생 정보는 원본에 포함하지 않았다. 코드 속 이름·성적은 교재의 예제 데이터다.
