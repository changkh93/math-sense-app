## 이 코드가 놓인 수업

**파이썬 수학 → 수학 알고리즘 (31 ~ 40) → 유클리드호제법**에서 가져온 ‘세트 4: 재귀 함수로 최대공약수 구하기’ 코드입니다. 단원 전체를 요약하는 대신 이 단계가 담당하는 작업을 한 가지씩 읽습니다. 코드 속 이름·점수·예시 자료는 교재의 연습 데이터이며 실제 학생의 기록이나 성과를 소개하는 자료가 아닙니다.

학습 목표는 코드를 그대로 입력하는 데서 멈추지 않고, 어떤 값이 준비되고 어떤 조건에서 결과가 달라지는지를 설명하는 것입니다. 다음 질문에 먼저 답을 적고 코드와 대조해 보세요.

> 조건 `b == 0`가 참일 때와 거짓일 때, 다음에 실행되는 줄은 무엇인가요?

## 원본 코드와 핵심 줄

```python
def gcd1(a, b):
    print(f'gcd1 함수 호출! a = {a}, b = {b}')

    if b == 0:
        print(f'b가 0이 되었으므로, a={a}를 반환합니다.')
        return a
    else:
        print(f'{b}와 {a % b}로 다시 gcd1 함수를 호출합니다.')
        return gcd1(b, a % b)

result_recursive = gcd1(24, 8)
print('재귀 함수로 찾은 최대공약수는:', result_recursive)
```

아래 행 번호는 위 코드 블록의 첫 줄을 1행으로 셉니다. 긴 예제에서는 주요 문장 10개까지 짚었습니다. 함수 안의 줄은 함수를 호출할 때 실행되므로, 행 번호 순서와 실제 실행 순서가 항상 같은 것은 아닙니다.

- **1행**: `gcd1(a, b)` 함수를 정의합니다. 정의와 실제 호출 시점은 구분합니다.
- **2행**: `print(f'gcd1 함수 호출! a = {a}, b = {b}')`를 호출합니다. 괄호 안의 값을 화면 출력과 연결해 읽으세요.
- **4행**: `b == 0`를 검사합니다. 참인 경로와 그렇지 않은 경로에서 바뀌는 값을 나누어 보세요.
- **5행**: `print(f'b가 0이 되었으므로, a={a}를 반환합니다.')`를 호출합니다. 괄호 안의 값을 화면 출력과 연결해 읽으세요.
- **6행**: `a`을 호출한 곳으로 돌려주고 이번 함수 실행을 끝냅니다.
- **8행**: `print(f'{b}와 {a % b}로 다시 gcd1 함수를 호출합니다.')`를 호출합니다. 괄호 안의 값을 화면 출력과 연결해 읽으세요.
- **9행**: `gcd1(b, a % b)`을 호출한 곳으로 돌려주고 이번 함수 실행을 끝냅니다.
- **11행**: `result_recursive`에 `gcd1(24, 8)`의 값을 저장합니다.
- **12행**: `print('재귀 함수로 찾은 최대공약수는:', result_recursive)`를 호출합니다. 괄호 안의 값을 화면 출력과 연결해 읽으세요.

## 실행 전에 준비할 것과 확인 결과

본문 코드의 로컬 실행에서 오류 없이 끝나는 것을 확인했습니다. 이는 해당 예제의 1회 실행 확인이며 모든 입력·학습 효과를 검증했다는 뜻은 아닙니다. 난수를 사용하는 경우 아래 출력은 seed 7을 고정한 확인 예시입니다.

```text
gcd1 함수 호출! a = 24, b = 8
8와 0로 다시 gcd1 함수를 호출합니다.
gcd1 함수 호출! a = 8, b = 0
b가 0이 되었으므로, a=8를 반환합니다.
재귀 함수로 찾은 최대공약수는: 8
```

## 결과를 이해하는 확인 활동

### 나머지와 최대공약수

양의 정수 a와 b에서 a를 b로 나눈 나머지를 r이라고 하면 gcd(a,b)=gcd(b,r)입니다. 마지막 나머지가 0일 때 남은 수를 반환합니다. 음수까지 허용하려면 반환값의 부호를 별도로 정해야 합니다.

**확인 활동:** 24와 10을 손으로 나누어 나머지 4, 2, 0을 적은 뒤 함수의 변수 이동과 대조하세요.

### 출력과 반환은 다릅니다

print는 화면에 보여주고 return은 호출한 곳으로 값을 돌려줍니다. 반환한 값이 있어야 다음 계산에 이어 쓸 수 있습니다. 함수 안에서 return에 도달하면 그 호출의 나머지 문장은 실행되지 않습니다.

**확인 활동:** 함수의 반환값을 변수에 담아 type과 값을 확인하고, 화면 출력과 구분해 기록하세요.
