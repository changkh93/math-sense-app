## 이 코드가 놓인 수업

**파이썬 수학 → 기초 자료형과 제어문 (1 ~ 10) → list.append 활용, sum(), round()**에서 가져온 ‘세트 5: sum, len, round, append로 평균 추가하기’ 코드입니다. 단원 전체를 요약하는 대신 이 단계가 담당하는 작업을 한 가지씩 읽습니다. 코드 속 이름·점수·예시 자료는 교재의 연습 데이터이며 실제 학생의 기록이나 성과를 소개하는 자료가 아닙니다.

학습 목표는 코드를 그대로 입력하는 데서 멈추지 않고, 어떤 값이 준비되고 어떤 조건에서 결과가 달라지는지를 설명하는 것입니다. 다음 질문에 먼저 답을 적고 코드와 대조해 보세요.

> `my_class`에 들어갈 값은 무엇이며, 그 값을 확인하려면 어디에 print를 놓으면 좋을까요?

## 원본 코드와 핵심 줄

```python
my_class = [
    ['이름', '국어점수', '수학점수', '영어점수', '평균'],
    ['홍길동', 50, 80, 70],
    ['데카르트', 100, 100, 100],
    ['맹구', 10, 20, 10]
]

scores = my_class[1][1:4]
print('홍길동의 점수들:', scores)

total = sum(scores)
avg = total / len(scores)
my_class[1].append(round(avg, 2))
print('홍길동 평균 추가 후:', my_class[1])

m_scores = my_class[3][1:]
m_avg = sum(m_scores) / len(m_scores)
my_class[3].append(round(m_avg, 2))
print('맹구 평균 추가 후:', my_class[3])

print('최종 결과:', my_class)
```

아래 행 번호는 위 코드 블록의 첫 줄을 1행으로 셉니다. 긴 예제에서는 주요 문장 10개까지 짚었습니다. 함수 안의 줄은 함수를 호출할 때 실행되므로, 행 번호 순서와 실제 실행 순서가 항상 같은 것은 아닙니다.

- **1행**: `my_class`에 `[['이름', '국어점수', '수학점수', '영어점수', '평균'], ['홍길동', 50, 80, 70], ['데카르트', 100, 100, 100], ['맹구', 10, 20, 10]]`의 값을 저장합니다.
- **8행**: `scores`에 `my_class[1][1:4]`의 값을 저장합니다.
- **9행**: `print('홍길동의 점수들:', scores)`를 호출합니다. 괄호 안의 값을 화면 출력과 연결해 읽으세요.
- **11행**: `total`에 `sum(scores)`의 값을 저장합니다.
- **12행**: `avg`에 `total / len(scores)`의 값을 저장합니다.
- **13행**: `my_class[1].append(round(avg, 2))`를 호출합니다. 호출 앞뒤로 대상의 상태가 달라지는지 살펴보세요.
- **14행**: `print('홍길동 평균 추가 후:', my_class[1])`를 호출합니다. 괄호 안의 값을 화면 출력과 연결해 읽으세요.
- **16행**: `m_scores`에 `my_class[3][1:]`의 값을 저장합니다.
- **17행**: `m_avg`에 `sum(m_scores) / len(m_scores)`의 값을 저장합니다.
- **18행**: `my_class[3].append(round(m_avg, 2))`를 호출합니다. 호출 앞뒤로 대상의 상태가 달라지는지 살펴보세요.

## 실행 전에 준비할 것과 확인 결과

본문 코드의 로컬 실행에서 오류 없이 끝나는 것을 확인했습니다. 이는 해당 예제의 1회 실행 확인이며 모든 입력·학습 효과를 검증했다는 뜻은 아닙니다. 난수를 사용하는 경우 아래 출력은 seed 7을 고정한 확인 예시입니다.

## 결과를 이해하는 확인 활동

### 목록 뒤에 하나씩 쌓기

append는 현재 목록의 맨 뒤에 항목 하나를 더합니다. 목록 전체를 인자로 주면 여러 항목으로 풀리는 것이 아니라 그 목록 하나가 들어갑니다. 반복 중 어느 시점에 append하는지에 따라 누적 결과가 달라집니다.

**확인 활동:** 반복 한 번 뒤의 목록과 두 번 뒤의 목록을 각각 적고 길이가 어떻게 늘어나는지 확인하세요.
