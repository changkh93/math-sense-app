## 같은 2+3인데, 왜 한 줄만 5일까요?

메타센스 **처음 파이썬 → 1 ~ 10 → 문자열, 숫자형 자료 구분**의 ‘화면에 글자와 숫자 출력하기’ 예제입니다. 실행 전에 마지막 두 줄의 결과를 각각 적어보세요. 둘 다 5가 나올까요?

## 수업 원본 코드와 실제 출력

```python
print('Hello World!')
print('왕새우')
print(2+3)
print('2+3')
```

Python 3에서 위 코드를 실행한 결과입니다. 별도 라이브러리나 입력은 필요하지 않습니다.

```text
Hello World!
왕새우
5
2+3
```

첫째·둘째 줄은 따옴표 안의 글자를 출력합니다. ‘왕새우’는 수업 예제의 글자입니다. 셋째 줄은 숫자 2와 3을 더한 값 5를 출력합니다. 넷째 줄은 더하기 기호까지 포함한 문자열 '2+3'을 그대로 출력합니다. `print`는 문자열을 감싸는 따옴표 자체를 출력하지 않습니다.

## 따옴표 위치를 바꾸는 확장 실험

다음은 원본을 이해하기 위한 추가 예제입니다. 각각의 +가 따옴표 안에 있는지 밖에 있는지 짚어보세요.

```python
print(2 + 3)
print('2' + '3')
print('2+3')
```

```text
5
23
2+3
```

첫 줄의 +는 숫자 덧셈입니다. 둘째 줄의 +는 두 문자열을 이어 붙입니다. 셋째 줄에서는 + 자체가 문자열의 일부입니다. 따라서 “따옴표가 있으면 무조건 계산을 안 한다”보다 **무엇이 하나의 문자열로 묶여 있는가**를 설명하는 것이 정확합니다.

## 2와 3을 4와 1로 바꾸면?

출력을 보기 전에 아래 세 결과를 예상하고 이유를 적어보세요.

```python
print(4 + 1)
print('4' + '1')
print('4+1')
```

```text
5
41
4+1
```

숫자 덧셈 결과는 다시 5지만, 이어 붙인 문자열은 41이 됩니다. 마지막 줄은 더하기 기호를 포함한 글자 4+1입니다. 숫자가 바뀌어도 같은 구분으로 설명할 수 있는지 확인합니다.

## 아이의 답에 따라 질문을 바꿔보세요

- “모두 5예요”라면: 둘째 줄에서 따옴표로 묶인 두 부분을 각각 손으로 짚게 합니다.
- “둘째 줄도 2+3이에요”라면: 셋째 줄과 비교해 +가 따옴표 안에 있는지 찾게 합니다.
- 세 결과를 맞혔다면: 4와 1로 바꾼 결과를 실행 전에 설명하게 합니다.

오늘의 기록은 **바꾼 부분 → 예상 → 실제 출력 → 이유** 네 가지면 충분합니다. 코드를 많이 복사하는 대신, 같은 기호가 자료에 따라 다르게 쓰이는 한 장면을 남겨보세요.
