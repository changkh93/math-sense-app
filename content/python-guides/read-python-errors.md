실행 버튼을 눌렀는데 빨간 글씨가 나옵니다. 아이가 “망했어”라고 말하는 순간, 부모도 얼른 고쳐주고 싶어집니다. 오류 메시지는 잘못했다는 성적표가 아니라, 파이썬이 진행을 멈춘 이유를 알려주는 단서입니다.

## 마지막 줄부터 읽습니다

오류 메시지가 여러 줄이라면 마지막 줄의 오류 종류와 설명을 먼저 봅니다. 그다음 표시된 줄 번호 주변을 확인합니다. 파이썬이 문제를 발견한 위치와 실제로 원인이 생긴 위치가 같지 않을 때도 있습니다. 괄호를 앞줄에서 닫지 않은 경우 다음 줄에서 멈출 수 있습니다.

```python
score = 10
print(socre)
```

여기서는 `score`를 만들고 `socre`를 읽으려 했습니다. 두 단어를 나란히 비교하면 차이가 보입니다. 코드를 전부 다시 쓰기보다 이름 하나를 바로잡고 다시 실행하면 됩니다.

## 자주 만나는 세 가지

`NameError`라면 이름을 먼저 확인합니다. 대소문자와 철자, 이름을 만들기 전에 사용했는지 살펴보세요. `SyntaxError`라면 괄호·따옴표·콜론처럼 문장을 구성하는 기호를 확인합니다. `IndentationError`라면 반복이나 조건 안쪽 줄의 들여쓰기가 맞는지 봅니다. 오류 이름만 보고 원인을 단정하기보다 메시지와 해당 코드를 함께 읽는 것이 중요합니다.

## 질문할 때 함께 남기면 좋은 것

“안 돼요”만으로는 어느 단계에서 막혔는지 알기 어렵습니다. 무엇을 하려 했는지, 실행했을 때 실제로 무엇이 나왔는지, 오류 마지막 줄이 무엇인지 남겨 보세요. 코드 파일도 함께 있으면 도움받는 사람이 같은 조건에서 확인하기 좋습니다. 캡처에는 이름이나 다른 학생의 대화가 포함되지 않게 합니다.

## 고쳤다면 한 번 더 바꿔 봅니다

오류가 사라진 뒤에는 숫자 하나를 바꿔 예상대로 작동하는지 확인합니다. 우연히 화면이 나오는 상태와 원인을 이해한 상태를 구분하는 작은 점검입니다. 질문 기록에는 “철자가 달랐다”처럼 원인을 남기세요. 다음번에 같은 오류를 만났을 때 자신의 기록이 힌트가 됩니다.

오류의 구분은 [파이썬 공식 오류와 예외 문서](https://docs.python.org/3/tutorial/errors.html)를 참고했습니다.
