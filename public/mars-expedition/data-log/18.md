## 18-A - 탐사원의 물리값과 네 행동 프레임

생성자에 이동 설정과 달리기·대기·점프·발사 이미지를 준비합니다.

**이 단계의 연결:** 출발 코드는 **17-B**의 누적 코드입니다. 아래 편집은 위에서부터 모두 적용합니다. 이미 완성한 나머지 메서드는 지정된 교체 범위 밖이면 그대로 둡니다.


### 입력 전에 결과를 예상해 보세요

start와 position에 같은 Vector 객체를 대입하면 왜 위험한가요?

먼저 답을 한 문장으로 적고 아래 해설과 비교하세요.

**생각 확인:** 현재 위치를 바꾸면서 시작점도 함께 바꿀 수 있습니다. 별도 벡터와 copy를 사용해 복귀 기준을 보호합니다. 생성자에서 준비한 대기시간은 다음 단원들의 기능에 쓰입니다.

### 수정 위치와 입력할 코드

**편집 1.** `class Explorer` 안의 `__init__` 메서드 전체를 아래 코드로 교체합니다. 다음 `def` 직전까지가 교체 범위입니다. `def` 앞 4칸, 본문 앞 8칸을 유지합니다.

**왜 이렇게 쓰나요 — 이 편집을 읽는 순서**

- **부모 Sprite의 내부 준비를 먼저 실행합니다.** `super().__init__()`은 상속받은 Sprite 내부를 준비합니다. 괄호 안에 그룹이 있으면 그 그룹에 이 객체를 바로 등록합니다. `super().__init__(tiles)`는 tiles에 자동 등록하지만 인수가 없는 `super().__init__()`은 자동 등록하지 않으므로 나중에 `그룹.add(객체)`가 필요합니다. 이 차이를 확인하고 중복 생성하지 마세요.

- **그림의 크기와 화면 위치를 담을 상자를 만듭니다.** `image`는 그림이고 `rect`는 그 그림을 놓을 사각형입니다. `get_rect(topleft=(x, y))`는 왼쪽 위, `midbottom=(x, y)`는 발 가운데를 해당 위치에 맞춥니다. 예를 들어 64×64 그림의 midbottom이 (100, 200)이면 왼쪽 위는 (68, 136)입니다. 같은 좌표라도 기준점이 다르면 표시 위치가 달라집니다. Group.draw는 각 객체의 image와 rect를 읽습니다.

- **이동하기 전 위치를 별도로 기억합니다.** 현재 rect를 바로 대입하면 같은 상자를 가리킬 수 있으므로 `.copy()`로 별도 상자를 만듭니다. 이전 발 높이 90, 현재 발 높이 110, 발판 윗면 100이라면 중간에 발판을 통과했다는 것을 알 수 있습니다. 현재 위치만 검사할 때 놓칠 수 있는 빠른 낙하를 이 두 시점으로 잡습니다.

- **위치·속도·가속도를 구별하고 이번 프레임 힘을 준비합니다.** position은 어디 있는지, velocity는 한 기준 프레임 동안 얼마나 움직이는지, acceleration은 속도가 얼마나 변하는지입니다. Vector2는 x와 y를 묶어 두 방향을 함께 계산합니다. 이동 시작마다 가속도를 다시 정해야 이전 프레임의 입력·마찰이 계속 누적되지 않습니다. 중력이 있는 단계에서는 y 가속도에 gravity를 넣습니다.

- **같은 그림을 좌우로 뒤집어 반대 방향 프레임을 준비합니다.** flip(image, True, False)는 가로 방향만 뒤집습니다. 원래 그림을 지우는 것이 아니라 변환된 Surface를 반환합니다. 리스트 안의 각 프레임에 적용하면 같은 동작의 왼쪽 목록을 만들 수 있습니다. 방향 -1과 1은 인덱스가 아니라 선택용 키로 사용합니다.

- **소리 파일을 준비하는 일과 재생하는 일을 구분합니다.** Sound 또는 load_sound는 소리를 사용할 준비입니다. .play()를 호출하는 순간 재생을 시도합니다. 생성자에서 준비하고 실제 발사·충돌 사건에서 재생해야 매 프레임 파일을 읽거나 준비만 했는데 소리가 날 것으로 기대하지 않습니다.

```python
    # 객체를 생성할 때 필요한 초기 값과 참조를 준비합니다.
    def __init__(self, x, y, platforms, gates, pulses):
        # 부모 Sprite의 내부 준비를 먼저 실행합니다.
        super().__init__()
        self.horizontal_acceleration = 2
        self.friction = 0.15
        self.gravity = 0.8
        self.jump_speed = 18
        self.starting_health = 100
        self.frames = {}
        for action in ['run', 'idle', 'jump', 'fire']:
            right = load_frames(f'explorer/{action}')
            self.frames[(action, 1)] = right
            # 같은 그림을 좌우로 뒤집어 반대 방향 프레임을 준비합니다.
            self.frames[(action, -1)] = [pygame.transform.flip(frame, True, False) for frame in right]
        self.facing = 1
        self.action = 'idle'
        self.frame = 0.0
        self.image = self.frames[('idle', 1)][0]
        # 그림의 크기와 화면 위치를 담을 상자를 만듭니다.
        self.rect = self.image.get_rect(midbottom=(x, y))
        self.platforms, self.gates, self.pulses = platforms, gates, pulses
        # 소리 파일을 준비하는 일과 재생하는 일을 구분합니다.
        self.jump_sound = load_sound('jump')
        # 소리 파일을 준비하는 일과 재생하는 일을 구분합니다.
        self.fire_sound = load_sound('pulse')
        # 소리 파일을 준비하는 일과 재생하는 일을 구분합니다.
        self.portal_sound = load_sound('portal')
        # 소리 파일을 준비하는 일과 재생하는 일을 구분합니다.
        self.hit_sound = load_sound('hurt')
        self.start = Vector(x, y)
        self.position = Vector(x, y)
        self.velocity = Vector(0, 0)
        # 위치·속도·가속도를 구별하고 이번 프레임 힘을 준비합니다.
        self.acceleration = Vector(0, self.gravity)
        self.health = self.starting_health
        self.grounded = False
        # 이동하기 전 위치를 별도로 기억합니다.
        self.previous_rect = self.rect.copy()
        self.fire_remaining = 0.0
        self.hurt_remaining = 0.0
        self.portal_remaining = 0.0
```


### 코드가 하는 일

가속도 2, 마찰 0.15, 중력 0.8, 점프 속도 18을 한곳에 모읍니다. 각 행동의 오른쪽 네 장과 뒤집은 왼쪽 네 장을 `(action, facing)` 키로 저장합니다. `health`는 현재 에너지, `starting_health`는 회복 상한입니다. `position`, `velocity`, `acceleration`은 실수 벡터이고 `rect`는 표시용 상자입니다. `start`는 현재 위치와 별개인 복귀 기준입니다. 세 `remaining` 값은 발사·피해·게이트의 재사용 대기시간입니다. 아직 빈 메서드에서 나중에 사용할 값도 생성자에 먼저 정의합니다.
