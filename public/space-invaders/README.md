# 우주 방어대 수업 자료

학생은 메타센스 게임 스튜디오에서 Data Log 01부터 순서대로 코딩합니다.

- data-log/01.md~10.md: 학생용 제작 문서
- checkpoints/: 31개 단계별 누적 코드와 final-main.py
- experiments/: 15개 임시 시험 코드(정식 코드에 시험 블록을 넣은 파일)
- assets/: 새 그림2개, 효과음6개, 한글 도현체
- asset_credits.py / OFL-DoHyeon.txt / ASSETS.md: 출처와 폰트 라이선스
- space-invaders-starter.mspygame.json: 빈 코드+전체 에셋 시작 백업
- space-invaders-final.mspygame.json: 완성 게임 비교 백업
- assessments.json: Code Trace29개와 Field Test/Quiz Battle 공유100문항 및 정답·해설

게임 스튜디오의 내 프로젝트 → 백업 파일 복원에서 .mspygame.json을 엽니다.
처음에는 starter를 사용하고, 기존 프로젝트를 백업한 후에 비교 자료를 엽니다.
내 프로젝트 → 우주 방어대 단계 비교·수업 자료에서 각 단계를 별도 프로젝트로 바로 열 수도 있습니다.
개별 .py는 제공된 에셋이 있는 프로젝트의 main.py 내용과 비교하거나 교체해서 사용합니다.
임시 시험은 Data Log의 복원 안내에 따라 제거한 뒤 다음 단계로 갑니다.

조작: 좌우 방향키, Space 단발, Enter 시작/재개/새 게임. 종료는 스튜디오 정지.
기체5, 아군탄환2/적탄환3,55기 편대,격추100점,보너스1000×현재라운드.
자료 버전:2026-09-10. 강의 순서는 참고하고 문서·코드·에셋은 별도로 구성했습니다.
