## 입력과 실행 약속

각 단계에서 먼저 정지를 누르고 main.py를 수정합니다. 여러 편집이 있으면 전부 마친 후 실행합니다. 실행 후 게임 화면을 클릭해야 키 입력이 게임에 전달됩니다. 코드는 왼쪽 공백까지 입력하며, 잘 모르겠는 이름은 바로 아래 설명에서 확인합니다. 단계 파일은 직접 작성한 코드와 비교·복구할 때 사용합니다.

## 코드를 읽고 작성하는 방법

코드 안의 `#` 뒤 문장은 **이해를 돕는 설명용 주석**입니다. 주석은 따라 적지 않아도 게임이 똑같이 실행됩니다. 먼저 주석을 읽고 그 아래 코드의 목적을 이해한 뒤, 실행되는 코드와 들여쓰기를 작성하세요. 따옴표 안의 글자, 변수 이름, 괄호와 콜론은 주석이 아니므로 생략하면 안 됩니다. 누적 코드에는 길 찾기에 필요한 핵심 주석만 남겼습니다.

각 편집의 ‘왜 이렇게 쓰나요’를 읽고, 입력하기 전에 결과를 예상해 보세요. 이번 단계의 편집을 모두 마친 다음 실행합니다. 중간에 아직 정의하지 않은 이름을 참조할 수 있으므로 편집 하나마다 실행하지 않습니다. 실행 후에는 화면이 맞는지만 보지 말고, **어떤 값이 바뀌어 그 결과가 생겼는지** 한 문장으로 설명해 보세요. 누적 코드는 먼저 직접 시도한 뒤 비교·복구할 때 사용합니다.


## 01-A - 빈 프로젝트에서 Pygame 확인하기

먼저 코드를 입력할 자리와 출력 위치를 확인합니다. 창을 만들기 전에도 print는 실행될까요?

**이 단계의 연결:** 빈 main.py에서 시작합니다. 아래 편집은 위에서부터 모두 적용합니다. 이미 완성한 나머지 메서드는 지정된 교체 범위 밖이면 그대로 둡니다.


### 입력 전에 결과를 예상해 보세요

print가 보이는데 게임 그림은 없는 이유를 설명해 보세요.

먼저 답을 한 문장으로 적고 아래 해설과 비교하세요.

**생각 확인:** 출력 명령만 실행했고 화면 생성/그리기 명령은 아직 없기 때문입니다. 출력 성공은 도구 준비 확인이지 게임 완성이 아닙니다.

### main.py 수정 위치와 입력 코드

**편집 1.** 파일 맨 위부터 `clock = pygame.time.Clock()`까지의 준비 코드(첫 단원은 빈 파일 전체)를 **추가**합니다. 아래 코드를 다른 함수나 클래스 안에 넣지 않습니다.

**왜 이렇게 쓰나요 — 이 편집을 읽는 순서**

- **게임 화면·입력·소리를 다루는 도구를 불러옵니다.** pygame은 게임용 기능을 모아 둔 모듈입니다. `import`는 도구를 쓸 수 있게 하는 준비이고, 화면을 만드는 명령 자체는 아닙니다. 따라서 import만 실행해도 우주선이나 창이 생기지 않습니다.

- **화면과 소리 모듈을 사용하기 전에 초기화합니다.** `pygame.init()`은 여러 Pygame 모듈의 준비를 수행합니다. 함수를 쓰려면 이름 뒤에 `()`를 붙여 호출해야 합니다. 함수 이름만 적으면 그 기능을 실행한 것이 아닙니다.

```python
# 게임 화면·입력·소리를 다루는 도구를 불러옵니다.
import pygame

# 화면과 소리 모듈을 사용하기 전에 초기화합니다.
pygame.init()
print("우주 방어대 수업 준비 완료!")
print("Pygame 버전:", pygame.__version__)
```


### 코드가 하는 일

import pygame은 게임 도구 모음을 불러옵니다. pygame.init()은 표시·소리 등 모듈을 초기화합니다. print의 따옴표 안은 출력할 글이고, pygame.__version__은 준비된 라이브러리 버전입니다. 밑줄은 앞뒤 두 개씩입니다.

### 여기서 실행하세요

정지 → 위 코드 수정 → 실행 → 게임 화면 클릭 순서로 진행합니다.

콘솔에 수업 준비 완료 문구와 실제 Pygame 버전이 한 번씩 나옵니다. 이 코드는 출력 후 끝납니다.

**이 시점의 정상 상태:** 아직 display.set_mode를 작성하지 않아 게임 화면은 만들지 않았습니다.

**예상과 다를 때:** pygame을 못 찾으면 import 철자를 확인합니다. SyntaxError이면 따옴표와 괄호 짝을 확인합니다. 출력이 안 보이면 콘솔 영역을 펼칩니다.
