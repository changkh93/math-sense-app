# 구구단 불빛 카드 음성팩 v1

- 생성 모델: OpenAI `gpt-audio-1.5`
- 음성: `marin`
- 용도: 2단부터 12단까지 구구단 불빛 카드의 정적 학습 음성
- 생성 방식: 각 구절을 한 번 생성하고 텍스트·길이·침묵 구간을 검증한 뒤 단별 MP3 스프라이트로 묶음
- 런타임 동작: 브라우저는 이 파일들을 캐시해 재생하며 문제를 풀 때 OpenAI API를 호출하지 않음
- 고지: 앱 화면에 AI 생성 학습 음성임을 표시함

1~9 곱셈은 한국어 전통 암송형을 따릅니다. 10~12 곱셈은 숫자 경계를 분명히 들려주기 위해 “곱하기”를 넣습니다.
